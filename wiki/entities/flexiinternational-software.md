# FlexiInternational Software, Inc.

> Shelton CT; also known as Flexi Software; received strategic investment from Quality Standard in 2025; survived as niche insurance/financial-sector ERP vendor


## Top observations

- Best-of-breed object-oriented financial CSS targeting complex accounting environments and open-systems migrations — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Direct sales through 8 US offices plus 1 UK office; ~30% of personnel in sales/marketing; pursuing international distributors — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- ~100% year-over-year in 1995; projected to continue at 100% through FY 1996 — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- 50% MS SQL Server, 30% Sybase, 10% IBM DB2, 5% Oracle (+ 5% other) — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- 300%-500% performance advantage over ODBC-based implementations — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Fully object-oriented; 50+ FlexiObjects accessible via API; target of 300+ objects in Release 4 (mid-1997) — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Phase I: HTML/ISAPI query; Phase II (planned): ActiveX/DCOM distributed component apps — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Unique deep IBM integration via DRDA, CAE, DDCS, DARIs; optimized DB2 access on all hardware platforms — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- 3 initial Flexi Industry Partners: Enterprise Systems (hospital materials mgmt), Innovative Computing Corp (transportation/warehousing), Quantra (real estate) — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Aberdeen predicts FlexiInternational will become one of the Financial CSS market leaders in the Enterprise and across the Internet — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Survived as profitable niche insurance/financial-sector accounting vendor; not a broad CSS market leader. Still active in 2025 as Flexi Software after strategic investment from Quality Standard. — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Aberdeen expects FIP program and international distributors to positively impact bottom-line as measurable percentage of revenues in H2 1996 — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Company went public (OTC) and focused on insurance/financial vertical; alternate channel strategy remained limited in scope relative to main competitors — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Aberdeen believes Flexi's success in Windows NT market will continue as Microsoft moves Internet-enabling technologies into Windows NT Server mainstream — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- OOT-based CSS suppliers best positioned for Internet/Intranet distributed component deployment; Flexi among best-prepared for web commerce transition — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Windows desktop look-and-feel controls available at base level — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Screen field add/move/delete, cursor navigation mapping, image inclusion, process flow modification — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Database Definition Repository: table/column/datatype definitions, column-level security, audit trail control — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- OO Foundation Class Toolkit: CASE-driven design, FlexiFinancials class libraries, source-level mods, new application development — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
- Proactive on-site baseline installation for comparative/diagnostic support; dial-in remote access; Aberdeen calls it a support precedent competitors must follow — [[study-aberdeen-1996-flexiinternational-software-financial-acumen-technology]]
