# PHI Professional Services Division (PSD)

> PHI division responsible for design, specification, implementation, and installation of programming and software systems for users and manufacturers.


## Top observations

- PHI PSD composed of four groups: Commercial Programming, Financial Systems, Systems Analysis & Design, Systems Programming — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- Group developed PHI Telecommunications Programming System (TPS), regarded as most comprehensive front-end software for IBM telecom environment; plug-replacement for IBM 2700-series TCU — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- PSD operated 'PHI Interface Laboratory' for testing System/360 channel interfaces for Honeywell H-516, Bunker Ramo, Data General Nova, DEC PDP-11, Tempo 1; nicknamed 'Underwriters Laboratory of the 360 Interface' — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- PHI developed tape/disk utilities for IBM System/360 Model 20 provided as Class A support by IBM — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- PHI developed real-time operating system for Sanders SANDAC 200 communications processor — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- PHI developed System/360-resident simulator for HP 2100 series — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- PHI R&D group helped develop software for new Wang 3300 computer series using third-generation computer technology — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
