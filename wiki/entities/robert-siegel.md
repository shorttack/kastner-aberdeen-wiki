# Robert A. Siegel

> PHI Supervisory Analyst at Systems Analysis & Design Group; later led Wang VS minicomputer development. | Source: Referenced in Aberdeen archive context; current status not publicly verifiable


## Top observations

- Robert A. Siegel later architected the Wang VS operating system after leaving PHI. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- An applications programmer manages physical machine resources: disk spin, core memory cycle, card reader click. Code is choreography of hardware. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- IBM instruction to set binary flag in register directly without touching memory; replaced 3 memory references with 1 instruction—transformative at scale. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Siegel confirmed the One-Instruction Switch optimization was achievable in COBOL, not just assembly. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Brilliant, abrasive mentor. Did not teach syntax; taught physics of the machine—physical resources of disk, memory, card reader. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Efficiency culture at PHI was direct product of $360/hour economics: when machine time is scarce, programmer's job is to minimize consumption of it. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
