## Quote

> Users will have one box for all their server needs one box to buy and one box to manage,

## Rationale

By 1999, Windows NT had indeed gained share and many organizations standardized more of their infrastructure on NT-based servers, reducing some NetWare and Unix diversity. However, medium and large enterprises continued to deploy multiple specialized servers for file/print, email (e.g., Exchange), databases (e.g., SQL Server, Oracle), and web hosting, and even many small businesses ran more than one server as needs grew. The longer-term trend also moved toward more, not fewer, logical server instances via web farms, clustering, and later virtualization and cloud, so the notion of a single box handling all server needs did not hold up beyond a few very small environments.
