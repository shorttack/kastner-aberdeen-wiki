## Rationale

System 10 was widely regarded as problematic, with serious performance and reliability issues that hurt Sybase’s reputation, so characterizing System 11 as a clear improvement in performance and quality relative to System 10 is directionally accurate. System 11 (SQL Server 11.0/11.5, soon rebranded as Adaptive Server Enterprise) delivered better performance and stability and remained a technically solid OLTP engine in production use, particularly in financial services, through the late 1990s and beyond. However, these technical gains did not translate into a market rebound against Oracle, Microsoft SQL Server, and IBM DB2, so the product’s solidity was real but not as transformative for Sybase’s overall position as the optimistic tone might imply.
