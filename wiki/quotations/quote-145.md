# Computerworld — 1993-11-29

**Headline**: TECHNOLOGY ON TRIAL

**Verdict**: HIGH prescience — score=5, confidence=3, horizon=SH-5y, pipeline=P2

## Quote

> “With products like Microsoft Access, we're seeing PC databases move forward toward enterprise connectivity,'' says Peter Kastner, vice president of corporate computing at Aberdeen Group in Boston.

## Rationale

By the late 1990s, Microsoft Access had evolved from a standalone desktop database into a common front end that could link tables via ODBC to server databases such as SQL Server and Oracle, giving PC databases direct access to enterprise data.[3] This period also saw widespread adoption of client/server architectures and ODBC-based connectivity across Windows desktop tools, so departmental Access applications frequently sat atop corporate relational databases rather than isolated .mdb files, matching Kastner's description of PC databases moving toward enterprise connectivity.[3]
