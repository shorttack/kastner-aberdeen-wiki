## Quote

> Microsoft [now] has the design responsibility for Java on Microsoft operating systems. And Microsoft can use features of Win95 and NT that would be very difficult for other operating systems to support.

## Rationale

Within a few years Microsoft did assume effective design control over its own Java implementation on Windows, shipping the Microsoft JVM, J++, and Windows Foundation Classes that were tightly bound to Win32, COM, and other Windows-specific features. This use of Win95/NT capabilities made Microsoft-centric Java code difficult to port and was central to Sun’s 1997 lawsuit accusing Microsoft of fragmenting Java’s cross-platform promise, confirming the analyst’s concern that Microsoft could steer Java in a Windows-specific direction.
