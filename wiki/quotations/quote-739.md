## Rationale

Within the 2–3 year horizon, Microsoft shipped Chicago as Windows 95 in August 1995, integrating MS-DOS and Windows into a single product with a new 32-bit architecture and GUI, significantly reducing the visible boundary between DOS and Windows for end users.[2][8][9] Windows 95 preserved strong backward compatibility so that most DOS applications could run in windowed or full-screen DOS sessions without special third-party bridging tools, making the DOS-to-Windows transition far more transparent than under Windows 3.x, even though some edge cases and hardware-intensive DOS software still required workarounds.[2][8]
