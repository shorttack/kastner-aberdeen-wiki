# Computerworld — 1994-10-31

**Headline**: AT&T GIS dives into vertical markets

**Verdict**: HIGH prescience — score=4, confidence=2, horizon=SH-5y, pipeline=P2

## Quote

> But until AT&T's announcement ... customers had to select and buy multiple technologies and then build the applications, which are not trivial.

## Rationale

In the mid-1990s, building enterprise data warehouses typically required assembling separate database, ETL, storage, and BI/reporting components from multiple vendors, plus substantial custom application development, as described by Bill Inmon’s Corporate Information Factory and early Kimball-style projects. Through the late 1990s, even as integrated offerings from IBM, Oracle, Teradata, and later SAP BW appeared, most large organizations still faced complex, multi-technology integration and non‑trivial application work to realize data warehouse value. The statement slightly overimplies that AT&T was uniquely changing this, but its core point about the need to select multiple technologies and build significant applications remained accurate over the following five years.
