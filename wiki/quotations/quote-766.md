# Computerworld — 1995-12-11

**Headline**: DBMS tool meets demand

**Verdict**: MEDIUM prescience — score=2, confidence=3, horizon=SH-3y, pipeline=P1_tiebreak

## Quote

> No other vendor has anything close to this.

## Rationale

By the late 1990s, Oracle Enterprise Manager had indeed become an important and long-lived DBA console, but it was not uniquely advanced for long, nor was it unmatched across vendors. Microsoft SQL Server Enterprise Manager (bundled with SQL Server 6.0/6.5 and then 7.0), IBM’s DB2 Control Center, and Sybase’s SQL Central/Adaptive Server administration tools all provided centralized, GUI-based management and automation that were clearly “close to” Oracle’s offering within the 3‑year window. Over the longer term, every major relational platform shipped robust integrated administration suites and third‑party tools like BMC Patrol and CA Unicenter also competed strongly, so the claim of having no comparable rivals does not hold up historically.
