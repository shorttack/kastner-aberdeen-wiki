## Quote

> And some of these high-end tools may automatically generate Java code, which would enable users to develop Java applications from the same models used to generate their client/server software, says Peter Kastner, an analyst at Aberdeen Group Inc., in Boston.

## Rationale

Within a few years of Java’s mid‑1990s emergence, many high‑end client/server modeling and CASE tools added Java as a code‑generation target, so the same analysis and design models could emit Java classes alongside C++ or 4GL code (e.g., Rational Rose with Java round‑trip engineering, Oracle Designer/Developer, and similar UML/MDD tools). This matched the analyst’s directionally correct view that existing model-based client/server tools would evolve to generate Java applications from the same models. However, automatic Java code generation remained a niche or partial practice, with most enterprise Java development still done by hand, so the prediction was more directionally right than transformative in impact.
