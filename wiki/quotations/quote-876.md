## Rationale

From 1989 to roughly 1992, building graphical applications for environments like OS/2 Presentation Manager, Microsoft Windows (2.x/3.0), and X11/Motif on Unix remained complex, requiring low-level C programming, manual event-loop handling, and careful memory management. GUI development was still specialized and time-consuming compared with character-based or batch applications, which validated concerns that developers had to be cautious about committing scarce resources to specific GUI platforms. Although early RAD tools such as Visual Basic appeared by 1991 and started to lower the barrier, they did not yet make enterprise-grade cross-platform GUI work simple within the three-year horizon.
