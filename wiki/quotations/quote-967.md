# Computerworld — 1993-11-01

**Headline**: Start-ups bring heavyweight tools

**Verdict**: HIGH prescience — score=4, confidence=3, horizon=SH-3y, pipeline=P2

## Quote

> These new tools use object technology without the complexity of object-oriented programming languages to let developers create graphical clients with multiple back ends,

## Rationale

Between 1993 and 1996, client/server RAD tools such as PowerBuilder, Gupta SQLWindows, Forte, Delphi, and Visual Basic did in fact let developers build graphical front ends against multiple database and middleware back ends while exposing only simplified, object-like components rather than full-blown OO languages. These tools became mainstream in enterprise IT for line-of-business applications, validating the idea that “object technology” could be packaged into higher-level visual environments to reduce OO complexity, even though longer-term architectural shifts to web and Java-based systems later changed the dominant model after the forecast horizon.
