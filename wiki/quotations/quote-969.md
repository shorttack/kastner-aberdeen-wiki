# Computerworld — 1993-11-29

**Headline**: Software vendors converge on database market

**Verdict**: HIGH prescience — score=4, confidence=3, horizon=SH-3y, pipeline=P2

## Quote

> As a result, IS is starting to put more controls on in order to limit the number of products they have to support,

## Rationale

From 1993 to roughly 1996, many enterprise IT organizations did move to standardize and limit the number of supported products, especially around databases and end‑user tools, in order to control support and integration costs. Large firms increasingly designated a small set of “strategic” database platforms (e.g., Oracle, DB2, Sybase, later SQL Server) and a narrow set of query/reporting tools, while rolling out managed Windows desktops and formal approved‑software lists. Tool proliferation continued at the departmental level and was never entirely eliminated, so the consolidation pressure Kastner described was directionally accurate but not fully determinative, which is why this rates as largely rather than perfectly prescient.
