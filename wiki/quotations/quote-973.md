## Quote

> With products like Microsoft Access, we're seeing PC databases move forward toward enterprise connectivity,

## Rationale

Microsoft Access 1.0 (1992) and subsequent mid-1990s releases quickly added and popularized built‑in data access drivers and ODBC connectivity, letting desktop Access front ends link tables to enterprise relational databases such as SQL Server and Oracle.[2] By roughly 1994–1996, PC databases (Access, Borland Paradox, etc.) were widely used as client tools in client/server deployments, with IS managing back-end SQL servers while end users built departmental applications against corporate data, matching the forecast that PC databases would move "toward enterprise connectivity" within that timeframe.[2]
