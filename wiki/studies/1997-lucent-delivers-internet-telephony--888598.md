# Lucent Delivers Internet Telephony and Carrier-Grade Scale with Internet Telephony Server SP

> Aberdeen evaluates Lucent's Internet Telephony Server SP as first scalable carrier-grade turnkey VoIP gateway platform. Study covers elemedia voice compression POTS-to-POTS capability service provider market opportunity and Lucent's advantage in large-scale implementation over competitors.

## Key observations (top 25)

- **1997** — Internet Telephony Server SP positioning: Lucent developed first scaleable carrier-grade turnkey gateway platform for internet telephony
- **1997** — Internet telephony market barrier: PC-based client requirement has alienated internet telephony from mass markets; incomplete solutions from gateway vendors
- **1997** — Internet telephony cost advantage: Internet telephony promises significantly lower costs for long distance and international voice and fax traffic
- **2004** — Internet telephony cost advantage: Skype (2003) and Vonage (2004) demonstrated massive cost reductions for long distance; international VoIP calls fell to near-zero by mid-2000s; Aberdeen's prediction was fully validated
- **1997** — Internet Telephony Server SP scale: Scaleable from 24 ports upward with real-time alternate routing and flexible call routing
- **1997** — Internet Telephony Server SP reliability: System falls back to another data network or PSTN when data network goes down; near toll-grade sound quality
- **1997** — Lucent VoIP market leadership: Lucent is first supplier capable of wide-scale implementation required for internet telephony and fax to reach mass-markets
- **2006** — Lucent VoIP market leadership: Lucent merged with Alcatel in 2006 before achieving predicted VoIP dominance; Cisco VOIP infrastructure and Sonus softswitch became more influential in carrier VoIP buildout; Lucent's specific product line was superseded
- **1997** — elemedia voice compression: elemedia SX7300P codec delivers near toll-grade sound quality through extensive call processing experience
- **2000** — elemedia voice compression: elemedia codec was superseded by open standards (G.729 G.711 and later Opus); elemedia absorbed into Lucent; Netscape Media Server died with Netscape; Opus open-source codec now dominates
- **1997** — Service provider VoIP opportunity: ISPs cable TV MSOs utilities RBOCs CAPs CLECs and IXCs all cited as potential internet telephony service providers
- **2010** — Service provider VoIP adoption: All major service providers (AT&T Verizon BT Deutsche Telekom) eventually deployed IP-based voice switching; circuit-switched PSTN being phased out globally; Aberdeen's service provider VoIP prediction fully validated
- **1997** — POTS-to-POTS capability value: End-users retain phones and fax machines with no behavior change; Lucent handles IP routing transparently
- **2003** — VoIP signaling standard: SIP (Session Initiation Protocol RFC 2543 1999) became dominant VoIP signaling standard; H.323 declined; proprietary gateway approaches like Lucent's initial implementation were superseded
- **1997** — Lucent service provider strategy: Lucent targets all service provider types (ISPs cable TV MSOs utilities RBOCs CAPs CLECs IXCs) with turnkey internet telephony backed by 24x7 international support
- **2016** — Lucent corporate outcome: Lucent merged with Alcatel in 2006 (Alcatel-Lucent); Nokia acquired Alcatel-Lucent in 2016 for approximately $16.6B; Lucent brand retired
- **1997** — elemedia codec adoption: Netscape Media Server adopted elemedia codec and echo cancellation technologies
- **1997** — Internet telephony quality challenge: Many internet telephony technologies give poor quality of service and spotty reliability; Lucent solution delivers near toll-grade sound quality
