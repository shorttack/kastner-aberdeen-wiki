# Oracle Designer/2000

> This 1997 Aberdeen Group profile evaluates Oracle Designer/2000, Oracle's flagship CASE and application modeling tool. Aberdeen finds that the market has shifted from upper-CASE methodology tools toward second-generation Client-server Application Development Environments (CADEs), and positions Designer/2000 as the leading data-focused design toolset due to its deep integration with Developer/2000, support for Internet application generation, and code generation capabilities for multiple target environments. Aberdeen recommends IS organizations place Designer/2000 on their shortlists for both traditional CASE and emerging Internet development.

**Author:** Aberdeen Group · **Date:** 1997-06-04 · **Type:** market-study
**Importance:** high — *Aberdeen's assessment of the CASE-to-CADE transition was a pivotal market signal in 1997; this study defined the evaluation framework that IS shops used to select design toolsets during the client-server and early web era.*
**Prescience:** medium — *Aberdeen predicted Designer/2000 would help Oracle dominate Internet development tooling—this proved incorrect as Java/J2EE, open source frameworks, and later web frameworks displaced Oracle's proprietary toolchain by the mid-2000s.*

## Key observations (top 25)

- **1997** — designer2000-developer2000-bundle-rate: Designer/2000 bundled with 60% of Oracle Developer/2000 sales
- **1997** — cade-vs-case-transition: Market shifted from upper-CASE methodology tools to second-generation CADEs over prior 2 years
- **1997** — product-strategy: Positioned as Oracle's key product for design and modeling of complex enterprise-scale distributed production systems
- **1997** — nca-architecture: Oracle Network Computing Architecture uses cartridges for client/app server/database tiers to enable Internet deployment
- **1997** — internet-support: Designer/2000 includes WebServer generator for rapid deployment of transactional Internet/Intranet applications without rewriting code
- **1997** — five-components: Designer/2000 comprises: Process Modeller, Systems Modeller, Systems Designer, Systems Generators, Model Management
- **1997** — evaluation-criteria-1-design-functionality: Design-tool scalability, flexibility, methodology support, data/code/GUI-driven design

- **1997** — evaluation-criteria-3-cade-rdbms-integration: Integration with data dictionaries, forward generation, reverse engineering, application-management information flow
- **1997** — visual-basic-limitation: Visual Basic lacks team-development, high-level design, and application-modeling features that Designer/2000 provides
- **1997** — competitor-no-design-tool: Informix and Sybase offer no integrated design tool—Oracle differentiates via Designer/2000 + Developer/2000 integration
