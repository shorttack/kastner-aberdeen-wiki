# PeopleSoft Works The Internet: Information Access By Anybody, Anytime, Any Place

> This 1997 Aberdeen Group strategy profile evaluates PeopleSoft's Internet strategy, branded as 'Interprise' (Internet+Enterprise). Aberdeen finds PeopleSoft differentiated by a people-centric, roles-based approach to Internet enablement focused on bringing occasional users—employees, suppliers, customers—into enterprise applications via simple Java-based Universal Applications and an Application Navigator framework. The study covers 15 pilot self-service modules, Supply Chain Collaborator, and partnerships with Internet-enabling technology vendors, predicting PeopleSoft will become a leading EBA vendor for Internet-enabled enterprise.

**Author:** Aberdeen Group · **Date:** 1997-06-04 · **Type:** market-study
**Importance:** high — *In 1997 PeopleSoft was the leading independent HR/ERP vendor and this strategy assessment defined the roles-based, people-centric model for enterprise Internet applications that became the dominant UX paradigm for HR self-service systems over the next decade.*
**Prescience:** high — *Aberdeen predicted PeopleSoft would succeed in making enterprise applications accessible to occasional users via Web browser and Java; this proved correct—PeopleSoft employee self-service became widely adopted before Oracle acquired the company for $10.3B in 2005.*

## Key observations (top 25)

- **1997** — internet-strategy-type: People-centric, roles-based Internet enablement — contrasted with technology-driven network-centric approaches of competitors
- **1997** — universal-applications-scope: 15 employee and business-partner self-service pilot modules released with PeopleSoft 7
- **1997** — application-navigator-function: Internet browser-based navigational framework requiring no training; workflow integration; exception-to-action progression
- **1997** — supply-chain-collaborator-model: Internet EDI complement for ad hoc supply chain planning; bi-directional buyer-supplier data exchange; available as freeware
- **1997** — interprise-layer-1-people: People layer — honing in on how people use Internet and Web technologies to access information more effectively
- **1997** — interprise-layer-2-internet-desktop: Internet Desktop Layer — starts as browser; evolves to sophisticated UI delivering broad applications and information
- **1997** — interprise-layer-3-connectivity: Connectivity Layer — user-transparent access to Intranets, Extranets, and Internet
- **1997** — interprise-layer-4-internet-utilities: Internet Utilities Layer — Application Navigator, integrated Email, Groupware, security, and directory services
- **1997** — interprise-layer-5-universal-apps: Universal Applications Layer — functional Java-based applications from PeopleSoft and third parties
- **1997** — single-source-business-logic: PeopleTools enhanced to allow single source application logic deployable in either C++ Windows client or Java Internet browser
- **1997** — java-client-requirements: Java Client must be: extremely intuitive; deployable on multiple platforms via web browser; connectable via Intranet/Extranet/Internet; targeted functionality for occasional user; usable by employees/customers/suppliers/partners
- **1997** — edify-partnership: Edify provides telephony front end allowing PeopleSoft access via phone, fax, and computer
- **1997** — netdynamics-partnership: NetDynamics WebExtend creates server-side Java code for Web applications
- **1997** — talx-partnership: TALX provides dynamic HR content with IVR, fax, and email features
- **1997** — peoplesoft-internet-market-leadership: PeopleSoft will become leading EBA supplier for Internet-enabled enterprise through its people-centric approach and Universal Applications
- **2005** — peoplesoft-internet-market-leadership: PeopleSoft's Internet strategy succeeded commercially—employee self-service became widely adopted; PeopleSoft grew significantly before being acquired by Oracle for $10.3B in 2005 after hostile takeover; Oracle continues to sell PeopleSoft HCM
- **1997** — occasional-user-self-service-adoption: Web-based self-service for occasional users (HR, benefits, expense reporting) will dramatically reduce enterprise overhead
- **2010** — occasional-user-self-service-adoption: Employee self-service for HR functions became standard enterprise practice by 2005-2010; HR portals reduced HR department headcount per employee by 15-30% at many enterprises; all major HCM vendors (Workday, SAP, Oracle) followed this model
- **1997** — internet-budget-adoption: Two years ago only visionary few IS budgets allocated funding for Internet; today any IS organization without such a budget line item is behind the times
- **1997** — aberdeen-overall-assessment: Aberdeen applauds PeopleSoft's ease-of-use, people-centric approach; advocates enterprises look into PeopleSoft Internet initiatives
