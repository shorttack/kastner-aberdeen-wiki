# Microsoft NT/Windows 2000 Multi-User Computing

> Aberdeen Group's 1998/1999 report examines the emerging market for thin-client/server-centric multi-user architectures built on Microsoft NT and Windows 2000. The report argues that technological improvements in late 1997 and 1998 have made multi-user architectures viable competitive weapons for enterprise IS managers. It surveys IS managers already evaluating NT multi-user computing and profiles vendors supplying components for Windows 2000-based multi-user environments.

**Author:** Aberdeen Group · **Date:** 1998-04-01 · **Type:** market-study
**Importance:** medium — *Aberdeen was an early authoritative voice on thin-client computing at a pivotal moment; this report helped IS decision-makers evaluate a nascent but strategically important architecture before Windows 2000 shipped.*
**Prescience:** high — *Aberdeen's prediction that multi-user Windows NT architectures would become 'business-altering competitive weapons' proved broadly correct — terminal services and Citrix MetaFrame became mainstream enterprise technologies by 2000-2002.*
