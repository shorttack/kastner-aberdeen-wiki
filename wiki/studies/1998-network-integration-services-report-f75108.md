# Transitions in Network Integration Services

> Aberdeen Group analyst Amy Sachrison's report examines the evolving market for Network Integration Services as enterprises transition from private leased-line networks to public packet services (X.25, Frame Relay, ATM) and face growing complexity in LAN-WAN integration, private IP networks, and TCP/IP-SNA integration. The report provides a framework for understanding the network integration industry, defines service categories (PDIM, network transformation, connectivity and transport, applications, training), presents four end-user case studies, and profiles 21 network integrator vendors.

**Author:** Amy Sachrison, Aberdeen Group · **Date:** 1998-01-01 · **Type:** market-study
**Importance:** medium — *This report captured a pivotal industry transition moment — from private TDM networks to shared public packet services — and provided IS decision-makers with the first comprehensive framework for evaluating network integration service providers in the mid-1990s public network era.*
**Prescience:** medium — *Aberdeen correctly identified network outsourcing and integration services as growth markets; however, most profiled vendors underwent rapid consolidation (MCI Systemhouse→EDS 1999; Vanstar→Inacom 1998; Wang→Getronics 1999; Sprint Paranet grew under Sprint before WorldCom merger attempt 1999).*
