# AberdeenGroup Newsletter Volume 1 Number 2 — April 1999

> The April 1999 Aberdeen Group newsletter (Volume 1, Number 2) surveys the firm's research agenda across six network-technology practice areas: Network Operating Systems, Linux enterprise adoption, Middleware and Messaging, Enterprise Management, Directory Services, and Internet Infrastructure. The issue also introduces Aberdeen's Rapid Accurate Market Positioning (RAMP) methodology for uncovering implicit buyer requirements, announces the opening of the firm's West Coast office in Palo Alto, and previews two forthcoming research reports on Windows NT multi-user computing and network convergence.

**Author:** Aberdeen Group · **Date:** 1999-04-01 · **Type:** newsletter
**Importance:** medium — *Captures Aberdeen Group's research posture at a pivotal moment — April 1999 — when enterprises were beginning to shift from Y2K remediation toward Internet infrastructure investment; represents a primary-source snapshot of six technology practice areas simultaneously.*
**Prescience:** high — *Aberdeen's core theses proved strikingly accurate: Linux achieved major enterprise adoption; network convergence (voice/data/video) became standard; Internet-as-backbone prediction materialized fully; Directory Services and LDAP became foundational enterprise infrastructure.*

## Key observations (top 25)

- **1999** — Internet's role in enterprise networks: Supplementing LANs/WANs as the backbone of enterprise networks
- **1999** — Linux enterprise viability: Emerging low-cost OS alternative to Windows NT and Unix with high reliability and scalability
- **1999** — Linux enterprise adoption trajectory: Linux may be about to extend its reach within the enterprise
- **2005** — Linux enterprise adoption — actual outcome: Linux became dominant in server/cloud infrastructure; Red Hat acquired by IBM for $34B in 2019
- **1999** — Java developers worldwide: Over 500000 developers worldwide
- **1999** — Java-based solutions count: Over 2000 solutions developed
- **1999** — Java as enterprise platform: Java delivering enterprise integration and performance enhancements; platform for robust scalable mission-critical web solutions
- **2010** — Java enterprise adoption — actual outcome: Java became dominant enterprise backend language; Spring framework surpassed EJB; Java still top-3 language globally
- **1999** — LDAP and meta-directory adequacy: LDAP and meta-directory fall far short of what is needed
- **1999** — Directory Services strategic role: Directory will become repository for desktop/system configs and instrumental in delivering QoS
- **2010** — Directory Services — actual outcome: Active Directory (Microsoft) and OpenLDAP became foundational enterprise infrastructure; directory-guided IT materialized
- **1999** — Middleware strategic importance: Vital to supporting today's myriad applications and key to scaling enterprise networks
- **1999** — CORBA vs DCOM standards war outcome: Crucial to ISV strategies; outcome undetermined in 1999
- **2003** — CORBA vs DCOM standards war — actual outcome: Both largely superseded by web services (SOAP/REST) and later microservices; neither CORBA nor DCOM won
- **1999** — Corporate data in legacy host-based systems: Seventy percent of corporate data still resides in legacy host-based systems
- **1999** — Internet-to-legacy integration strategic advantage: Companies integrating legacy systems with Internet gain significant time-to-market tactical advantage
- **2005** — Internet-legacy integration — actual outcome: Web-to-host and legacy integration became critical IT discipline; middleware and ESB markets emerged
- **1999** — Novell NetWare enterprise position: One of dominant NOSs that enterprises must integrate with Internet
- **2011** — Novell fate — actual outcome: Novell acquired by Attachmate in 2011 for $2.2B; NetWare product discontinued
- **1999** — Banyan VINES enterprise status: Legacy NOS still in use at Fortune 1000 organizations
- **2004** — Banyan Systems fate: Dissolved in 2004; VINES NOS discontinued
- **1999** — Aberdeen RAMP methodology value: Interview-based tool for gauging market demand and implicit buyer requirements; 60-day turnaround with 30-day flash report
- **1999** — Aberdeen industry experience: Over a decade of experience analyzing business impact of network technology
- **1999** — Aberdeen West Coast expansion: New office opened at 514 High Street Palo Alto CA
- **1999** — WINE project status: Project underway to allow Linux to run Windows applications
