# Linux Is on the Move - Up!

> This Aberdeen InSight argues that Linux development is moving faster than any other commercial operating system and will leapfrog Windows to replace Unix on the high end within seven to eight years. With major contributors including Compaq, HP, IBM, and numerous smaller companies, Aberdeen predicts Linux will join IBM z/OS and Microsoft Windows as a primary server OS before the end of the decade. The study positions Linux as the third pillar of enterprise server computing.

**Author:** Bill Claybrook · **Date:** 2001-07-01 · **Type:** market-study
**Importance:** medium — *Published in July 2001 before Linux's enterprise breakthrough was fully established, this study served as an early mainstream analyst endorsement of Linux as an enterprise server OS contender, lending Aberdeen's credibility to the Linux adoption narrative.*
**Prescience:** high — *The core prediction — Linux joining z/OS and Windows as a primary server OS before decade's end — proved accurate. Linux achieved 28.3% server market share by 2004 and became the dominant server platform by the early 2010s. The seven-to-eight year Unix leapfrog prediction was broadly correct.*

## Key observations (top 25)

- **2001** — Linux development speed vs. commercial OS: Linux developing faster than any other commercial OS to date
- **2001** — Linux high-end Unix displacement timeline: Linux will leapfrog Windows to replace Unix on the high end within 7-8 years (by 2008-2009)
- **2008** — Linux Unix displacement - actual outcome: IDC 2004 predicted Windows would overtake Unix by 2008; Linux grew from 8.4% to 14.9% server share by 2008; Unix declined from 39.6% to 31.9%
- **2001** — Linux as primary server OS by decade end: Linux will join IBM z/OS and Microsoft Windows as the primary server OSes before end of decade (by 2010)
- **2010** — Linux primary server OS status - actual outcome: Linux server revenue reached $1.6B quarterly by 2005 with 14th consecutive quarter of double-digit growth; Linux became dominant public cloud OS by 2010
- **2001** — Major Linux development contributors: Compaq, HP, IBM and many smaller companies contributing to Linux development efforts
- **2001** — IBM dual-OS strategy: IBM positioned both z/OS (mainframe) and Linux as strategic platforms — Linux for distributed; z/OS for mainframe
- **2001** — Unix high-end market position at study time: Unix occupying high-end server market that Linux is predicted to displace
- **2004** — Linux server market share 2004: Linux server market share reached 28.3% of server sales by 2004 per IDC (combined Unix+Linux 1.48M units)
- **2003** — Linux server revenue Q4 2003: Linux server revenue grew 63% to $960 million in Q4 2003 (IDC)
