# Living with Windows XP Media Player and Wireless Support

> This Aberdeen InSight by Peter S. Kastner provides a hands-on evaluation of Microsoft's Windows XP operating system, focusing on its digital media capabilities (audio, video, moviemaking, photography) and wireless LAN support. Kastner concludes that 'Microsoft delivers' on its launch marketing promises, specifically for media handling and wireless networking, and predicts that almost all previous Windows users will enjoy living with Windows XP. The study includes a practical note about WEP password hex conversion.

## Key observations (top 25)

- **2001** — Windows XP overall assessment: Microsoft delivers on its launch marketing promises for Windows XP
- **2001** — XP digital media support level: New high level of support for digital audio, digital video playing, digital moviemaking, and digital photography
- **2001** — XP wireless LAN support: XP makes connecting to wireless LANs 'a snap' — zero-configuration wireless
- **2001** — WEP password configuration requirement: WEP passwords must be converted into hexadecimal — practical user friction point noted
- **2003** — WEP security outcome: WEP proven cryptographically broken; replaced by WPA (Wi-Fi Protected Access) standard in 2003
- **2001** — Windows XP user adoption prediction: Almost all previous Windows users are going to enjoy living with Windows XP
- **2003** — Windows XP adoption rate - actual: XP achieved 12-14% adoption in first year; less than 10% of Microsoft's installed base upgraded by end of 2002 per Gartner
- **2010** — Windows XP long-term adoption - actual: XP became most-used Windows version; maintained 35%+ share a decade after launch; still 1.44%+ of devices in 2022
- **2001** — Microsoft digital content strategy with XP: Microsoft positioned XP as Personal Information Technology and digital home networking platform
- **2002** — Corporate XP adoption by end of 2002: 75% of corporate PCs still running Windows 95, 98, or NT Workstation by end of 2002 (Gartner)
- **2001** — Launch marketing credibility: For all of the launch marketing hype, this time Microsoft delivers
