# Upgrading to Windows XP: A Long and Winding Road

> Published at the launch of Windows XP in November 2001, this Aberdeen InSight documents Peter Kastner's firsthand experience upgrading PCs to Windows XP. The study concludes that upgrading existing machines is advisable only for skilled technicians, and recommends that most consumers and small businesses obtain Windows XP pre-installed on a new PC at approximately $1,000. The study is notable for evaluating XP's wireless networking support (Agere/ORiNOCO), media capabilities, and SOHO applicability.

- **2001** — Windows XP upgrade complexity: Upgrade advisable only if performed by a good technician
- **2001** — Windows XP stability inheritance: Users get enterprise stability and speed of Windows 2000

- **2001** — Wireless LAN support in XP upgrade: WEP wireless LAN (Agere/ORiNOCO) tested during upgrade — driver/compatibility challenges noted
- **2001** — Recommended upgrade path for consumers and SOHO: Factory-installed XP on new PC is the right choice for most consumers and small businesses
- **2001** — Recommended new PC price point: New XP PC costing around $1000 should be a bargain
- **2001** — Microsoft Windows XP target market: Targets both SOHO users seeking consumer media features and enterprise seeking W2K stability
- **2001** — WEP wireless security: WEP used as wireless security standard in tested SOHO network configuration
- **2001** — New PC as primary XP delivery vehicle: Factory-installed XP on new hardware will be the dominant adoption path for most users
- **2014** — Windows XP end of life: Windows XP reached end of extended support April 8 2014; ran for 13 years — substantially on new hardware as predicted
- **2004** — WEP security outcome: WEP officially deprecated by IEEE 802.11i in 2004; replaced by WPA and WPA2 due to fundamental cryptographic weaknesses
