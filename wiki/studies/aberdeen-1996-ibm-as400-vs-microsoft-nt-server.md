# IBM's AS/400 Versus Microsoft's NT Server: The Challenge That Is Not

> Aberdeen Group analyzes Microsoft's challenge to IBM's AS/400 installed base, arguing that the AS/400 with over 350,000 installations will retain its dominance in midrange commercial computing against Microsoft's NT Server (BackOffice). Aberdeen presents four economic and technical reasons why the challenge will fail: higher total cost for NT due to fat-client PCs, lack of match with AS/400 customer culture, absence of proven migration economics, and AS/400 Advanced Series' superior 64-bit RISC capabilities — predicting the debate will be viewed as 'the challenge that was not' by 1997.

**Author:** Aberdeen Group · **Date:** 1996-01-15 · **Type:** product-viewpoint
**Importance:** high — *This study addressed the defining platform battle of mid-1990s commercial computing; Aberdeen's cost/performance analysis using TPC-C benchmarks and TCO models provided influential quantitative grounding at a moment when many IS executives were actively evaluating the switch.*
**Prescience:** high — *Aberdeen's core prediction proved accurate: virtually no AS/400 customers migrated to NT Server, Microsoft's AS/400 attack program was relegated to the back-burner by 1997, and the AS/400 platform evolved into IBM i and remained active 30 years later.*

## Key observations (top 25)

- **1996** — AS/400 installed base: 350,000+ installations; leading midrange commercial computing choice worldwide
- **1996** — AS/400 design philosophy: Integrated operating environment: easy-to-acquire, -operate, and -maintain; minimal dedicated technical staff needed
- **1996** — Microsoft BackOffice challenge basis: Three-fold: 1) lower cost hardware/software platform, 2) more open, 3) direct path to client-server with PC interface
- **1996** — Fat-client PC cost vs 5250 terminal: NT Workstation Pentium 133 MHz 24MB: $4,900 (with maintenance) vs IBM 5250 dual-session terminal: $1,940
- **1996** — Total hardware cost per user NT vs AS/400: NT Server-based OLTP infrastructure costs $1,700-$2,700 more per deployed end-user device in hardware alone
- **1996** — Additional staffing cost for NT vs AS/400: If BackOffice requires 2 more full-time IS staff than comparable AS/400 system, hundreds of thousands in additional cost over 5-year lifecycle
- **1996** — TPC-C V3 benchmark Compaq ProLiant 4500: Compaq ProLiant 4500 NT Server TPC-C showed good midrange OLTP performance but TPC-C V3 excluded end-user device costs
- **1996** — TPC-C V3 NT Server AlphaServer benchmarks: Two DEC AlphaServer NT Server TPC-C tests showed excellent price/performance vs Unix; but required Unix front-end processors to multiplex data entry
- **1996** — BackOffice OLTP production installations: Fewer than 10,000 BackOffice installations running business-critical OLTP applications
- **1996** — AS/400 Advanced Series performance improvement: 64-bit RISC transition from 48-bit CISC yields 50+% performance improvement; DB2/400 upgraded for distributed OLTP
- **1996** — AS/400 client-server benchmark performance: AS/400 showed excellent client-server performance and price/performance vs Unix/RISC and NT/Intel under Client/Server Labs tests
- **1996** — AS/400 migration path to client-server: Integrated client-server solution via AS/400 Advanced Servers + FSIOP + CA/400 + ODBC; evolutionary not revolutionary
- **1996** — NT Server OLTP suitability assessment: Best suited for enterprises with strong Unix/client-server expert IS organizations; not for AS/400-dedicated organizations
- **1996** — Cairo migration path risk: Migration from NT Server to Cairo will not be transparent upgrade; will require new hardware and applications
- **1996** — AS/400 customer retention against NT: Almost all (95%+) AS/400 customers will opt for evolution to AS/400 Advanced Series rather than migrate to NT Server
- **2000** — AS/400 customer retention against NT: AS/400 installed base remained loyal; platform survived and evolved into iSeries (2000), System i (2006), IBM i (2008); still active in 2026
- **1996** — Microsoft AS/400 attack program prognosis: Microsoft's AS/400 attack program will be relegated to back-burner by 1997; viewed as the 1995 challenge that was not
- **1997** — Microsoft AS/400 attack program outcome: Microsoft shifted focus to Internet strategy (consistent with Gates' 'Road Ahead' and .NET pivot); BackOffice as AS/400 replacement faded from priority by 1997-1998
- **1996** — NT Server support on AS/400 FSIOP: Aberdeen anticipates NT Server will be supported on AS/400 FSIOP in the future
- **2000** — NT Server support on AS/400 FSIOP: IBM did add NT Server support options for AS/400 users; but AS/400 users used NT as complementary not replacement; FSIOP line eventually discontinued
- **1996** — SQL Server maturity: Production version of SQL Server released June 1995; not yet mature enough for IS executives to stake their job on its robustness
- **1996** — AS/400 revenue from installed base: Over 90% of IBM's SME-derived AS/400 revenues come from installed base; IS decision makers do not seriously consider another supplier
- **1996** — Microsoft SME market strategy rationale: Microsoft must gain SME loyalty as stepping stone to enterprise data center penetration with NT Server
- **1995** — NT Server BackOffice revenue estimate: BackOffice product deliverables estimated to account for approximately $500 million of Microsoft's 1995 revenues
- **1996** — TCO factor 1: Hardware acquisition cost: NT Workstation fat-client PC ($4,900) vs 5250 terminal ($1,940) creates $2,960 per-seat hardware premium for NT
