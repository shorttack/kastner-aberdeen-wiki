# Windows NT Server 4.0 — A Giant Step Forward

> Aberdeen Group evaluates Microsoft Windows NT Server 4.0, concluding that it is 'a giant step forward' for the network operating system market. The study analyzes NT 4.0's improvements in convenience, Internet/intranet integration, network connectivity, and performance, positioning it as the dominant application server for workgroups and departments while predicting it will displace Novell NetWare and other competitors to become the dominant NOS platform.

## Key observations (top 25)

- **1992** — NT Server ISV launch event attendance: More than 5,000 ISVs attended Microsoft's initial NT Server software developers' conference in 1992; ~60,000 developer toolkits shipped by end of 1992
- **1996** — NT Server 4.0 domain scale: Up to 40,000 users in a single domain; up to 500 trusted domains depending on server configuration
- **1996** — IIS 2.0 performance vs. IIS 1.0: Microsoft claims IIS 2.0 is 40% faster than version 1.0; bundled with NT Server NOS installation
- **1996** — NT Server 4.0 hardware architecture support: Versions for Intel, MIPS, Digital Alpha, PowerPC (IBM, Motorola, Groupe Bull); SMP support up to 32 processors
- **1996** — LDAP adoption status in 1996: Developed at University of Michigan as X.500 directory client; adopted as standard by major networking vendors in 1996; slated as core NT Server 5.0 directory technology
- **1996** — NT Server 4.0 vs. 3.51 file/printer sharing performance on 100MB network: NT 4.0 vs. 3.51: network frames -32%, bytes written to disk -27%, interrupts -50%, server code path -33%, improved cache flushing
- **1996** — NT 4.0 application server performance improvements: ~30% reduction in resource contention; 35% fewer resource allocations; new Pentium/PentiumPro optimizations; new MP communication protocol
- **1996** — Microsoft NT Server four key themes: 1) Convenience and compatibility, 2) Integrated Internet/intranet capabilities, 3) Network integration, 4) Performance enhancements
- **1996** — Novell NetWare competitive position vs. NT Server: Main competitor; NT Server now provides NTDS that manages NetWare 2.x and 3.x servers (not 4.x); NT encroaching on NetWare territory via wizard tools and departmental deployment model
- **1996** — Aberdeen NT Server market assessment: Aberdeen has not yet found a company or agency not in some stage of implementing NT Server; all interviews over past year indicate major increase in installations in 1997
- **1996** — Aberdeen 'IBM of the 1990s' characterization: Microsoft has become the IBM of the 1990s — a 'safe' bet because of marketing clout, ability to attract key ISVs, and persistence in improving core products
- **1996** — Prediction: NT 4.0 heavy workhorse for database/application servers: Within a year of its introduction, Aberdeen expects NT 4.0 to be seen as a heavy workhorse as a database and application server at the workgroup and departmental level
- **1996** — Prediction: NT will displace NetWare in enterprise deployments: Most new NT Server sales will be into new environments or at expense of OS/2, NetWare, and SCO competitors; NT staying in the race for long-haul keeping pressure on all competitors
- **1996** — Prediction: NT 5.0 LDAP will solve enterprise directory gap: Until NT Server 5.0 with LDAP and Exchange integration ships, NT missing essential interoperability; then single directory will overcome biggest obstacle to enterprise-wide deployment
- **2003** — Outcome: NT Server line dominance as predicted: Windows NT 4.0 succeeded by Windows 2000 Server (Feb 2000) and Windows Server 2003; dominated enterprise server market throughout late 1990s and 2000s; still active as Windows Server 2025 as of 2026
- **2011** — Outcome: Novell NetWare decline and acquisition: NetWare lost dominant NOS position to Windows NT by 1999; Novell acquired by Attachmate 2011 for $2.2B; NetWare effectively obsolete; Novell technologies eventually absorbed into OpenText (2023)
- **2000** — Outcome: Windows 2000 Active Directory with LDAP: Windows 2000 Server (released February 2000) shipped with Active Directory using LDAP as core directory technology as Aberdeen predicted
- **1996** — NT 4.0 reason for customer choice: Ease of deployment: Ease of set-up, deployment, management, and use — identified by Microsoft focus groups as top customer reason for choosing NT
- **1996** — NT 4.0 reason for customer choice: Compatibility: Compatibility with existing systems — identified by Microsoft focus groups as customer reason for choosing NT
- **1996** — NT 4.0 reason for customer choice: Single OS for multiple roles: Ability to use same OS for application servers, file servers, and communication servers
- **1996** — NT 4.0 reason for customer choice: Built-in web server: Suitability as Internet platform because of built-in Web server (IIS)
