# Object-Oriented Three-Tier-Plus Computing: Client-Server for Adults

> Aberdeen Group's whitepaper examines the maturation of three-tier client-server computing in 1996, presenting the 'Three-Tier Plus' model that adds MPP/clustered SMP as a fourth tier for data warehousing. The study synthesizes field research from Aberdeen consulting assignments showing that organizations implementing 3-Tier architectures achieve four key business outcomes: improved enterprise efficiency, multi-source information access, scalability for emerging technologies, and superior ROI. Aberdeen argues object-oriented programming is critical for partitioning applications across tiers and predicts NT Server will close the gap with Unix on mid-tier within 24 months.

## Key observations (top 25)

- **1996** — 3-Tier computing strategic rationale: Senior management consensus: productivity, customer satisfaction, revenue enhancement from effective IS strategy; 3-Tier architecture enables this
- **1996** — 3-Tier business requirement 1: Enterprise efficiency: Automate business information flows, improve productivity, add revenue opportunities, cut costs; replace batch mainframe with real-time processes
- **1996** — 3-Tier business requirement 2: Multi-source information access: Flexible data access from multiple databases; data warehousing; real-time information access across enterprise
- **1996** — 3-Tier business requirement 3: Scalability for emerging technologies: Graceful evolution to new technologies; investment protection; SMP clustering and board-level upgrades increasingly popular
- **1996** — 3-Tier business requirement 4: Superior ROI: Lower cost hardware (PC/LAN/mid-tier); reuse of existing mainframe applications; API bridges to legacy data; rapid application prototyping
- **1996** — Three-Tier Plus model definition: Traditional 3-Tier + MPP/clustered SMP as fourth-tier for data warehousing and complex query; the 'Plus' in Three-Tier-Plus
- **1996** — NT Server mid-tier competitiveness timeline: NT-based systems will begin to close sales gap vs Unix for mid-tier application servers within 24 months; will at least equal unit sales in workgroup
- **1998** — NT Server mid-tier competitiveness actual outcome: Windows NT Server 4.0 (1996) and NT Server 4.0 EE (1997) closed gap with Unix; NT became dominant mid-tier OS for enterprise application servers by 1998-2000
- **1996** — NT Server LAN market position: NT Server beginning to dominate new LAN server shipments over Novell NetWare
- **1996** — MPP broader market acceptance prediction: As Oracle/Informix port to MPP and prices decline, MPP machines will achieve broader market acceptance as enterprise-class servers
- **2003** — MPP broader market acceptance actual: MPP data warehouse systems (Teradata, Netezza, later Amazon Redshift) became mainstream for enterprise analytics by 2000-2005
- **1996** — OOP criticality for 3-Tier: Object-oriented programming techniques are critical to 3-Tier: enable application partitioning and deployment across tiers
- **1995** — PC/workstation client shipments 1995: Approximately 25 million business client workstations shipped worldwide in 1995
- **1996** — Mainframe residual value decline prediction: Residual value of mainframe software portfolio will continue to decline during second half of 1990s as PCs handle more processing
- **2005** — Mainframe residual value decline actual: Mainframe installed base shrank but did not disappear; IBM z-series still significant for banking/insurance; client-server/3-tier replaced most new development
- **1996** — 3-Tier base platform maturity: Hardware, RDBMS platforms now stable, reliable, well-understood; missing pieces from 1992 (OOP tools, TP performance, data replication, network management) now in production
- **1996** — Application partitioning via OOP: OOP enables modular application development; partitioned components can be maintained/modified with fewest staff resources and shortest time
- **1996** — Data warehousing as Internet third-tier enhancer: Internet browsers will explode 3-Tier information access with additional functionality, ease of use, and network throughput
- **1996** — Unix vs NT SMP performance comparison: Unix 4-to-8-way SMP configurations superior to NT Server for higher-volume transaction processing; NT closing gap
- **1996** — NT vs Novell LAN market prediction: NT Server with NetWare interconnect services beginning to dominate new LAN server shipments over Novell NetWare
- **2000** — NT vs Novell LAN market actual outcome: Microsoft Windows 2000 Server completely displaced Novell NetWare as dominant LAN OS by 2000; Novell market share collapsed from >70% to <10%
- **1996** — Aberdeen verdict: sufficient evidence to proceed with 3-Tier: We have sufficient evidence for IS executives to proceed with confidence. Technology direction is clearer now. Products are more powerful and less expensive than ever.
- **1996** — OOP dominance in enterprise development: Object technology and application partitioning will be the method for maintaining/modifying modular development environments with fewest resources
- **2000** — OOP dominance actual outcome: OOP became dominant paradigm for enterprise application development by 2000; Java/.NET/C++ standard; prediction fully confirmed
