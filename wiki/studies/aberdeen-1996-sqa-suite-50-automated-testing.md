# SQA Suite 5.0: Innovative, Integrated, Automated Testing Tools

> Aberdeen Group evaluates SQA Suite 5.0, a four-product integrated automated testing toolset for Windows client-server applications developed by SQA, Inc. The study assesses SQA's market position, product capabilities including OLE/OCX/ActiveX testing, load/stress testing, and repository-based integration, and recommends IS managers seriously evaluate automated testing tools within two years. Aberdeen predicts SQA's integrated approach and Windows-focused strategy position it as a serious contender in the testing tools arena.

**Author:** Aberdeen Group · **Date:** 1996-01-01 · **Type:** market-study
**Importance:** medium — *Published at the critical moment when Windows client-server testing was becoming essential; provided IS managers early guidance on a nascent market. Aberdeen's recommendation to evaluate automated testing tools was influential in accelerating adoption of formal QA practices.*
**Prescience:** high — *Aberdeen's prediction that automated testing tools would become mandatory proved correct. SQA was acquired by Rational Software in 1997 for $300M, validating its viability. The broader prediction about automated testing becoming ubiquitous has proven highly accurate with modern CI/CD pipelines.*

## Key observations (top 25)

- **1996** — Market Focus Strategy: Windows-only automated testing; differentiated from cross-platform competitors
- **1996** — Product Integration Architecture: Server-based repository integrates all 4 testing tools; enables shared scripts and historical analysis
- **1996** — OLE/OCX/ActiveX Test Capability: SQA Suite uniquely able to test OLE-enabled components and ActiveX objects in Windows environment
- **1996** — Application Development Cycle Duration: Shortened from 2-3 years to less than 1 year due to 4GL tools
- **1996** — Automated Testing Tool Adoption: Aberdeen predicts every technology buyer will consider automated testing tools within two years
- **2000** — Automated Testing Tool Adoption - Outcome: Automated testing tools became standard by 1998-2000; entire category grew substantially; CI/CD practices embedded by 2005
- **1996** — SQA Inc. Competitive Viability: Positioned as serious contender in testing arena; aggressive product enhancement schedule
- **1997** — SQA Inc. Competitive Viability - Outcome: Acquired by Rational Software in late 1996/early 1997 for ~$300M; viability confirmed by premium acquisition
- **1996** — Aberdeen Testing Criteria: Robustness: Tool must withstand rigorous trials with immature code to gather maximum information during development
- **1996** — Aberdeen Testing Criteria: Scalability: Support for testing very large applications and load testing capacity
- **1996** — Aberdeen Testing Criteria: Flexibility: Ability to handle changes in test scripts during execution and leverage existing scripts
- **1996** — Aberdeen Testing Criteria: Open Architecture: Ability to integrate with third-party tools and adapt to multiple development environments
- **1996** — Aberdeen Testing Criteria: Defect Tracking: Integrated defect management with priority assignment and resolution tracking
- **1996** — Aberdeen Testing Criteria: Reporting: Comprehensive test data reporting with historical analysis capability
- **1996** — Windows NT Platform Adoption for Development: Enterprise IS migrating development to Windows NT; 32-bit testing becoming mandatory
- **1996** — SQA Suite vs Competitors: 16/32-bit Script Reuse: SQA uniquely leverages test scripts across both 16-bit and 32-bit without modification
- **1996** — Mercury Interactive Market Strategy: Cross-platform testing strategy with Unix and Windows support; WinRunner product
- **1996** — Aberdeen Recommendation: IS Manager Action: Aberdeen strongly suggests IS managers serious about delivering robust client-server applications evaluate SQA Suite
- **1996** — Testing as Integral Development Component: Testing must be integral part of development cycle; without continuous testing apps will be more costly, delayed, buggier
- **1996** — SQA Suite Pricing Model: Repository-based suite pricing; individual product or full suite purchase options
