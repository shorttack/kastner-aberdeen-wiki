# Internet Infrastructures: 1998 Practice Summary

> Aberdeen Group's 1998 analysis of the Internet Infrastructure market, defining the four-component architecture (Application Development Environment, Application Runtime Environment, Service Middleware, and ISP Services) and introducing the 'Internet Object Computing' (IOC) framework. The report assesses the Java vs. Microsoft COM+/DNA battle, the role of CORBA and LDAP, the maturity of EJB and distributed computing standards, and provides competitive profiles of eight major vendors: Borland/Inprise, HP, IBM, Microsoft, Netscape, Novell, Oracle, and Sybase.

**Author:** Aberdeen Group · **Date:** 1998-05-01 · **Type:** other-research

## Key observations (top 25)

- **1998** — IOC framework definition: Internet Object Computing: Java + CORBA + ISP services enabling distributed enterprise computing across corporate boundaries
- **1998** — Java market size outlook: Overall Java market will be significant; market share cannot yet be predicted due to bifurcation caused by Microsoft's alternative approach
- **1998** — LDAP as dominant directory standard: Most if not all proprietary directories headed for extinction as LDAP becomes entrenched; even LDAP-capable proprietary directories will need to become fully interchangeable
- **1998** — Actual LDAP outcome: Deferred verification of LDAP dominance prediction.
- **1998** — EJB vs COM+ competitive dynamics: EJB extremely immature but rare supplier alliance forming; Microsoft has large installed base of COM-based apps; developer community clearly favors Microsoft in 1998
- **1998** — Microsoft DNA architecture assessment: Windows DNA not made for inter-enterprise computing; NT-tied; lacks scalability and platform independence; Microsoft-only strategy risks missing IBM/Netscape/Sun/Oracle benefits
- **1998** — COM+ on non-Microsoft Unix platforms: Key watch area: Microsoft delivery of production-quality COM+ on Unix platforms will greatly extend interoperability story
- **1998** — Actual COM+ cross-platform outcome: Deferred verification.
- **1998** — Consumer rejection of push/publish-subscribe: Consumers driving market rejection of push and publish/subscribe; e-mail underestimated and outperforms complex messaging alternatives
- **1998** — Internet outsourcer role growth: Role of Internet outsourcers will increase substantially over next 5 years; migration from proprietary systems; software/hardware costs insignificant vs. expert labor
- **1998** — Actual Internet outsourcing growth outcome: Deferred verification.
- **1998** — Java application porting assessment: Porting current applications to Java rarely satisfactory; Java is a communications environment not just a language; applications must be rewritten
- **1998** — Internet Infrastructure adoption barriers: Three barriers to enterprise-class Internet deployment: Security, Trust, and Reliability; trust requires directory-based security certificates and PKI
- **1998** — EJB vs COM+ runtime battle outcome prediction: Java alliance expects EJB runtime on multiple platforms; Microsoft expects NT+COM+ on multiple hardware; battle will fragment market over next 1-2 years
- **1998** — Actual EJB/COM+ market fragmentation outcome: Deferred verification.
- **1998** — Borland/Inprise market position: Excellent technology; struggles with consistent message and marketing strategy; many strategic relationships via Visigenic; unable to leverage into lasting market position
- **1998** — HP Internet Infrastructure assessment: Domain FoundationTools and FoundationWare appeal to large-enterprise; 'honest broker'; LDAP engine from Netscape as differentiator; never first to market; challenge: gain mindshare from IBM
- **1998** — IBM Internet Infrastructure assessment: Exceptionally attractive solution; popular offerings across all IOC components; clear vision; mindshare in e-commerce; challenges: integrate disparate offerings and demonstrate enterprise-scale deployment
- **1998** — Netscape market position assessment: Led on open standards; SuiteSpot initially defined Internet computing; too slow on server-side Java; lost momentum to Microsoft and IBM; new NetCenter + IOC Business Services strategy announced
- **1998** — Novell market position assessment: IntranetWare maintaining NOS dominance; EJB as infrastructure strategy; must prevent NT 5.0 erosion; Eric Schmidt-led Java/Internet plan; execution remains to be seen
- **1998** — Oracle Internet Infrastructure assessment: NCA strategy: Oracle8 + Java + Designer/2000 + Developer/2000; e-commerce providers report Oracle's products too proprietary and less useful than Microsoft's in Internet implementations
- **1998** — Sun Internet Infrastructure assessment: Substantial Java mindshare; Certificate, Mail and Directory Servers offered as components not integrated; need to integrate development tools/middleware/Java into scaleable offering
- **1998** — Sybase Internet Infrastructure assessment: Adaptive Server + Jaguar CTS + PowerDynamo + Enterprise CONNECT + Powersoft = integrated platform; challenge: Powersoft perceived as proprietary; market unaware of Sybase middleware
- **1998** — CORBA role in Java interoperability: CORBA extends Java capabilities to legacy and disparate platforms; Aberdeen predicts CORBA will become lingua franca between different Java environments
- **1998** — Internet Infrastructure vendor selection criteria: Look for: in-depth knowledge of installed environment + proof of interoperability; AND credibility in supporting all relevant Internet Infrastructure services + consulting best-practices expertise
