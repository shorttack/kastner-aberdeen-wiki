# Linuxcare, Inc. -- Enterprise Service and Support for All Things Linux

> An Aberdeen Group company profile of Linuxcare, Inc. published in November 1999, assessing the startup's viability as the first enterprise Linux services and support company. The paper evaluates Linuxcare's four service pillars (24x7 support training porting and certification), its key OEM contracts with Dell IBM and Sun, and its Kleiner Perkins Caulfield and Byers backing. Aberdeen concludes that a credible enterprise Linux services market exists and recommends Linuxcare be considered by IT executives seeking Linux as an alternative enterprise OS.

## Key observations (top 25)

- **1999** — Linuxcare founding and model: Founded 1998 as Linux consulting company; OEMs sought expertise; expanded to training and support
- **1999** — Kleiner Perkins first Linux investment: Kleiner Perkins Caulfield and Byers chose Linuxcare as its first Linux-related investment
- **2019** — Kleiner Perkins Linux bet validation — actual outcome: Linux became dominant enterprise server OS; IBM acquired Red Hat for $34B in 2019; KPCB's early Linux thesis proved visionary
- **1999** — Linux enterprise application coverage prediction: Within the next year IT managers will have a Linux-based alternative in every major application area
- **2005** — Linux enterprise application coverage — actual outcome: Oracle SAP IBM middleware all ported to Linux by 2003-2005; enterprise Linux became the dominant server platform; prediction proved accurate within 3-4 years not just 1
- **1999** — Linux current enterprise use cases: IT departments using Linux for email file/print Web servers; increasingly for decision support caching storage DNS Web commerce
- **2015** — Linux server OS market share — actual outcome: Linux grew from ~25% enterprise server OS in 2003 to >70% by 2015; became THE dominant server OS
- **1999** — Linuxcare service model — four centers of excellence: 24x7 support + training (Linuxcare University) + porting/migration (Linuxcare Labs) + benchmarking/certification
- **2019** — Enterprise Linux services model validation — actual outcome: Red Hat built $3.4B annual revenue on exactly this model before IBM acquisition; SUSE and Canonical followed same playbook; market thesis proved correct
- **1999** — Linuxcare OEM contracts: Dell (back-end support for OptiPlex Dimension Precision workstations and PowerEdge Servers) + IBM (RS/6000) + Sun (Star Office) + TurboLinux (North American customers)
- **1999** — Dell Linux support contract with Linuxcare: Dell contracted Linuxcare for back-end Linux support on OptiPlex Dimension Precision workstations and PowerEdge Servers
- **1999** — IBM Linux support contract with Linuxcare: IBM contracted Linuxcare for Linux support on RS/6000 line
- **1999** — Sun Linux support contract with Linuxcare: Sun contracted Linuxcare for support of Star Office suite (acquired from Star Division)
- **1999** — Linuxcare platform support: Alpha + Intel + MIPS + PowerPC + SPARC + StrongARM
- **1999** — Linuxcare support tiers: Bronze / Silver / Gold / Platinum
- **1999** — Linuxcare University course catalog: Linux System Administration + Network Administration + Security + Linux Overview for NT Professionals + Extreme Samba + Linux for Executives
- **1999** — Linuxcare private-branding model: All services can be private-branded (e.g. www.dell.linuxcare.com)
- **1999** — Aberdeen viability assessment of Linuxcare: Aberdeen convinced by extensive market research that credible enterprise Linux services market exists; Linuxcare proven viable source of Linux expertise
- **2004** — Linuxcare fate — actual outcome: Linuxcare pivoted to focus on network management (Definiti brand) then acquired by Levanta in 2004; faded as independent company but market thesis proved correct
- **1999** — Linux enterprise IT support gap: IT management has contracts for Unix and Windows NT support; same 24x7 global support question must be answered for Linux
- **1999** — Linuxcare challenges identified by Aberdeen: Growing headcount and placing QA metrics in place (scaling challenges)
- **1999** — Samba author employed as key Linux guru: Andrew Tridgell (original Samba author) employed as Linux guru at Linuxcare
- **1999** — ISV enterprise Linux porting prediction: ISVs have announced ports of major enterprise applications to Linux
- **2019** — Red Hat as long-term market leader — actual outcome: Red Hat built the dominant enterprise Linux business on Linuxcare's model; acquired by IBM for $34B in 2019
- **1999** — Linuxcare Labs: distribution-neutral porting: Porting and migration assistance via Linuxcare Labs — distribution-neutral approach
