# Network Operating Systems: 1998 Practice Summary

> Aberdeen Group's 1998 practice summary on Network Operating Systems (NOS) covering Microsoft Windows NT Server, Novell NetWare/IntranetWare, and IBM OS/2 Warp Server. The report addresses key strategic questions about NOS viability in an Internet era and assesses the competitive landscape among the three major NOS vendors. Aberdeen finds that NOSs remain essential even as Internet infrastructure grows and that Novell's market leadership will be tested by the NetWare 5 launch.

## Key observations (top 25)

- **1998** — NT Server enterprise suitability: NT Server 4.0 being overused for enterprise-scale implementations it cannot support; NOS use mostly workgroup
- **1998** — NT Server 5.0 release timeline: NT 5.0 is a 1999 production issue — no relief coming in 1998; buyers must sort out 1998 on their own
- **1999** — NT Server 5.0 release timing: Windows 2000 shipped February 2000 — verify actual date.
- **1998** — Novell viability assessment: Novell is still technology and market-share NOS leader; not a dead company; NetWare 5 expected summer 1998
- **1998** — NetWare 5 launch success: NetWare 5 launch on track; beta testing on schedule; customer feedback favorable; good chance to recapture mindshare
- **1998** — NetWare 5 launch success: Verify NetWare 5 reception and market impact.
- **1998** — IBM OS/2 Warp Server market position: IBM not anticipating significant market share gains; maintaining installed base; $30B IBM revenue relies on OS/2
- **1998** — OS/2 Warp Server product quality: OS/2 Warp Server excellent for file/print; exceeds NT Server functionality even with NT extra-cost utilities
- **1998** — NT Server security weakness: NT Server has almost non-existent security at Windows desktop level vs. very adequate Unix and IBM/Novell NOS
- **1998** — Directory services battle framing: Battle between Novell NDS (shipping) and Microsoft Active Directory (upcoming) is truly strategic
- **1998** — Internet impact on NOS viability: Internet INCREASES need for powerful NOSs — directory services
- **1998** — NOS market sales growth: Sales of all three major NOS vendors increased over past two years as market expands and orgs upgrade/consolidate
- **1998** — NT Server NOS market positioning: Vast majority of NT Server NOS sales are in workgroup; few network managers seriously consider it as enterprise NOS
- **1998** — NOS unification drivers: Three forces driving NOS re-examination: 1) LAN linking into WANs; 2) M&A creating multi-NOS environments; 3) concentration in Microsoft/IBM/Novell/Unix
- **1998** — NT Server Y2K status: NT 4.0 compliant with minor issues; requires Service Pack 3 plus Site Server Express 3.0 plus QFE fixes; NT 3.51 must upgrade
- **1998** — NetWare Y2K status: NetWare 4.11a and 3.2 are Y2K ready; older versions need downloadable upgrades from Novell website
- **1998** — Microsoft NOS strategy assessment: Microsoft is mindshare leader; leveraging desktop dominance to push NT Server; massive ISV/channel recruitment
- **1998** — Novell IntranetWare assessment: IntranetWare provides extensive improvements to platform/print/file/application/security; good Internet integration
- **1998** — Professional services demand for NOS: NOS implementations so complex they often require outside assistance; especially true for NT Server enterprise deployments
- **1998** — IS decision quality concern: More IT decisions based on emotional/political reasons rather than careful assessment; risks now capable of destroying companies
