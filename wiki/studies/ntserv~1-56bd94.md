# Windows NT Server: 1998 Practice Summary

> Aberdeen Group's 1998 practice summary on the Windows NT Server market covering Intel-based server hardware and the NT operating environment. The report sizes the NT server hardware market at $6 billion in 1997 and projects 50% annual growth; it also covers SMP architectures, clustering (Microsoft Cluster Server/Wolfpack), systems management deficiencies, and supplier profiles for Intel, Microsoft, Compaq, HP, IBM, Dell, and Digital Equipment. Aberdeen identifies NT's ongoing limitations relative to Unix and frames 1998 as a strategic inflection point for NT enterprise adoption.

**Author:** Aberdeen Group · **Date:** 1998-05-01 · **Type:** other-research

## Key observations (top 25)

- **1997** — NT server hardware market size (1997): ~$6 billion in hardware revenue; NT application revenues ~$2 billion
- **1998** — NT server hardware market growth forecast: 50% annual growth for next 4 years; hardware market to grow to $9 billion by 2000
- **1998** — NT application server revenue forecast (2001): NT application revenues ~$2B in 1997; will grow to ~$13 billion by 2001
- **1998** — Unix application server market comparison: Global Unix application server market $19.6 billion in 1996; projected $40 billion in 2000; 4.5x larger than NT market
- **1998** — NT in IS strategic plans: Windows NT servers part of strategic plans for more than 90% of Fortune 1000 IS executives
- **1998** — NT server deployment complexity: NT deployments increasingly require professional services; IS without staff NT experience common
- **1998** — NT 5.0 release timeline and features: Windows NT 5.0 to be released sometime in 1999; will add Active Directory
- **1999** — NT 5.0 (Windows 2000) release timing: Windows 2000 shipped February 17 2000 — verify and update.
- **1998** — IA-64 (Merced) timeline: Intel IA-64 (Merced) arriving late 1999; IA-32 to IA-64 conversion likely takes 5+ years
- **2001** — IA-64 (Itanium) commercial availability: Itanium shipped June 2001; verify market adoption pace.
- **1998** — Digital Alpha market share and roadmap: Alpha holds ~2% of NT server market; reaching 660 MHz by H2 1998; projected 1 GHz by 2000; strong for transaction workloads
- **1998** — Microsoft Cluster Server limitations: MSCS (Wolfpack) introduced fall 1997; two-node failover only; not full HA; no automatic load balancing
- **1998** — SMP scaling debate: Suppliers divided: proprietary >4-way now vs. waiting for Intel standard 8-way chipset; few NT apps exploit multi-threading
- **1998** — NT operating system shipment growth forecast: NT Server OS shipments to increase 88% in 1998; over 100% in 1999
- **1998** — Compaq NT server market position: Compaq largest NT/Intel server supplier; ProLiant from entry-level to 4-way and 8-way; direct and indirect model transition
- **1998** — Dell NT server trajectory: Dell company to watch in 1998; transitioning from SOHO/SME to enterprise; 8-way rack servers expected by year-end
- **1998** — IBM Netfinity NT market assessment: IBM Netfinity (rebranded PC Server) in downward spiral; early 1998 Intel server revenues declining; technology leadership lacking
- **1998** — HP NT server position: HP NetServer line strong in SMP and systems management; 8-way and 16-way architectures in development; co-developing IA-64 with Intel
- **1998** — Digital Equipment NT server assets: Digital has largest NT installed base of clustered systems; >1600 certified NT professionals; being acquired by Compaq
- **1998** — NT enterprise readiness assessment: NT remains less robust/scalable/enterprise-ready than mature Unix platforms; second choice for larger mission-critical apps
- **1998** — NT single-application limitation: NT essentially supports one application per OS copy; keeps NT servers on periphery of larger database environments
- **1998** — NT Y2K misconception: Misconception that NT/Intel servers are a Y2K safe harbor is false; require software updates at application/OS/hardware levels
- **1998** — Intel server processor market dominance: Intel microprocessors in >95% of NT servers; IA-32 (Pentium II Xeon for >4-way) and IA-64 (late 1999) roadmap
