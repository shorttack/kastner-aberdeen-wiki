# Much In Store Beyond 2004: Microsoft Has Experts Questioning Some Initiatives

> Processor Magazine editorial (2004-03-05) by Warren S. Hersch surveying Microsoft's 2004 product roadmap — Longhorn, Yukon, MOM, Virtual Server, Live Communications Server, Tablet PC — and SMB business-applications strategy. Peter Kastner (chief research officer, Aberdeen Group) argues Microsoft's SMB focus will target high-volume products like QuickBooks competitors rather than SAP/PeopleSoft/Oracle enterprise territory, and that Microsoft rationally will not open-source Windows or port Office to Linux because that would help a competitor OS lacking a proven mass market.

**Author:** Warren S. Hersch (Processor Magazine / Sandhills Publishing) · **Date:** 2004-03-05 · **Type:** news-article
**Importance:** medium — *Captures Kastner's mid-2000s diagnosis of Microsoft's SMB vs. enterprise strategy split at the moment when Microsoft Business Solutions (Great Plains/Navision/Solomon) was consolidating.*
**Prescience:** high — *Kastner was right on both counts: Microsoft stayed with volume SMB tooling (QuickBooks-style, Dynamics Small Business) rather than displacing SAP in large enterprises; and Microsoft never opened Windows source code even as Linux grew. The SMB volume-model bet paid off over 20 years.*

## Key observations (top 25)

- **2004** — Microsoft SMB volume-sales playbook: A product like QuickBooks is more attractive to Microsoft than the spaces that SAP, PeopleSoft, or Oracle compete in because you can sell tens of millions of units around the world. Competing against, say, SAP over a few thousand implementations woul…
- **2004** — Microsoft will not open-source Windows: You'd be asking Microsoft to lose a lot of money in helping a competitor operating system. No sane business person would make this decision. There is no proven mass market for Linux.
- **2004** — Windows SMB desktop share: Windows OSes now reside on more than 90% of SMB desktops.
- **2004** — Longhorn slip to 2006: Longhorn (next desktop OS) is not expected to ship before 2006.
- **2004** — Yukon (SQL Server 2005) planned: Microsoft SQL Server codename Yukon planned with enhanced scalability, manageability, availability, business intelligence, deeper dev-tool integration.
- **2004** — Virtual Server midyear launch: Microsoft plans to launch Virtual Server by midyear 2004 allowing multiple OSes on one server.
- **2004** — Microsoft usability scores: When measured in terms of usability, affordability, and support, Microsoft solutions score lower in surveys than competitive offerings from Intuit and salesforce.com.
- **2004** — Linux desktop threat: A lot of companies are starting to experiment not only with Linux on the server, but also Linux on the desktop. Microsoft's decision is going to hurt them in the eyes of customers.
- **2024** — Windows did not open-source: Microsoft has never open-sourced Windows (though parts like WSL, PowerShell, .NET, VS Code are open source). Kastner prediction validated.
- **2024** — Linux desktop share stays marginal: Linux desktop share has remained below 5% for 20 years; Robinson's threat assessment did not materialize — Kastner's skepticism was correct.
