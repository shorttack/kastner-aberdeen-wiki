# The Strategic R/3 Solution for the Enterprise

> This vendor presentation by Sequent Computer Systems presents the SAP R/3 SD benchmark results achieved on the Sequent Symmetry SE70 SMP server running R/3 version 2.2d on both Windows NT and UNIX. The document positions the Sequent platform favorably versus HP, Sun/Cray, and IBM on user count, independent certification, and RDBMS CPU utilization.

**Author:** Sequent Computer Systems · **Date:** 1996 · **Type:** benchmark
**Importance:** medium — *First independently audited SAP R/3 SD benchmark on a Sequent SMP system running both NT and UNIX; captures a critical moment in mid-1990s enterprise server competition for SAP workloads.*
**Prescience:** medium — *The document implied Sequent's SMP approach on NT would be competitive with UNIX-only rivals; Sequent was later acquired by IBM in 1999, partially validating the platform strategy, though NT enterprise penetration proved slower than hoped., confidentiality: vendor-confidential*
