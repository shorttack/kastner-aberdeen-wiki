# Competitive Advantage Through Prism Metadata Scalability

> Aberdeen Group profile of Prism Solutions Inc. (Sunnyvale CA) evaluating its metadata-driven data warehouse software suite. Prism Scaleable Data Warehousing Solutions packages include the Prism Warehouse Executive (new), Prism Warehouse Directory, Prism Iterations methodology, and Web Access/Personal Mart modules. Aberdeen endorses Prism's metadata-first architecture as key to managing dynamic data warehouse evolution and recommends Prism's approach for enterprises scaling from data marts to enterprise warehouses. Prism was acquired by Ardent Software for $42M in January 1999.


_Published 1997, author **Aberdeen Group**, type **Profile**._


## Top observations

- Leading supplier to forward-thinking data warehouse users
- Scalability requires managing metadata changes not just database size growth
- Business-driven demand: modify business rules alter data sources add technologies
- Data mart proliferation could choke enterprises relying on non-scalable warehousing techniques
- Robust metadata and tool-driven proficiency is the key to managing new architectures
- Common GUI across all Prism applications; integrates design construction maintenance
- Metadata facility for both business and technical users; CDIF exchange with CASE tools
- Java and HTML views of metadata for browser users; $2500 for 5 concurrent seats
- Business users build their own web-based views of desired data independently of IS
- Developers reuse particular mappings tables and user exits within mappings
- 400 customers for data migration technology and consulting services
- 250 data warehouse implementation and consulting engagements inform Iterations methodology
- DB2/MVS, DB2/400, Enscribe, IDMS, IMS, Informix, NonStop SQL, Sybase, Teradata, Oracle (Rdb), Digital RMS, VSAM
- DB2 Parallel Edition, Informix, Microsoft SQL Server, NonStop SQL, Oracle (Rdb), Red Brick Warehouse, Sybase/SQL Server, Teradata
- HP Intelligent Warehouse exchanges metadata with Prism via CDIF standard
- PLATINUM PR/MVS and R&O Rochade repositories exchange metadata via CDIF
- Logic Works ERwin exports metadata to Prism Warehouse Directory
- Prism will integrate with CORBA to distribute and synchronize metadata
- CORBA superseded by web services; Prism absorbed before CORBA integration matured
- Metadata management will become critical infrastructure for all enterprise DW
- Confirmed: data catalogs (Collibra Alation) became multi-billion dollar market; metadata governance foundational
- Prism positioned as competitive advantage toolset with strong customer base
- Prism stock crashed from $35 to $2; acquired by Ardent for $42M (fire sale) in Jan 1999
- More enterprises will demand systematic DW approach as warehouses scale in importance
- Confirmed: DW became universal enterprise infrastructure; cloud DW (Snowflake Redshift BigQuery) emerged 2010s
