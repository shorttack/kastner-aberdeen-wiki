# DynaSoft's BoKS Family: A Pragmatic Choice for Single Sign-On

> Aberdeen Group profile of DynaSoft AB (Stockholm, Sweden) and its BoKS product family, evaluating it as a pragmatic Single Sign-On (SSO) solution for enterprises. The report covers DynaSoft's SSO/SSSO product architecture (BoKS Desktop, BoKS Connect, BoKS Manager, ToolBoKS), its authentication framework using RSA cryptography and X.509 certificates, strategic partnerships with Hewlett-Packard and Sun Microsystems, and user testimonials from major enterprises including BankBoston, BP Oil, Citibank, Chase Manhattan Bank, Merrill Lynch, and Telstra. Aberdeen concludes BoKS delivers reliable, pragmatic SSO that users consistently recommend.


_Published 1997, author **Aberdeen Group**, type **Profile**._


## Top observations

- Delivering SSO since 1984; focus on Unix then client-server then Internet
- Works directly with customers to fold lessons into product
- HP chose BoKS technology for HP Praesidium Single Sign-On
- Sun chose DynaSoft as strategic partner for Sun Security Manager
- IS finding slide-ware instead of demonstrable product and reference accounts
- Non-interoperable user profile databases across unlike platforms
- Common authentication authorization and auditing across multiple technology domains
- Reusable framework for evolving business needs
- No cadre of highly-skilled IS staff required
- Full project deployments from start to finish in less than 60 days
- Moderate-skilled admins managing hundreds to thousands of nodes and tens of thousands of users
- No impact on existing applications and networks
- RSA-based cryptography for in-transit information protection in SSSO
- X.509 certificates supported as credential type in BoKS PSDs
- Entrust Technologies CA services integrate with BoKS for multi-level authorizations
- BankBoston, BP Oil, Citibank, Chase Manhattan, Indian Telecom, Mannesmann Mobilfunk, Merrill Lynch, SmithKline Beecham, Telecom Italia, Telmex, Telstra
- Aberdeen recommends standardizing on DynaSoft and BoKS
- Validated: acquired by Security Dynamics for $115M within months
- SSO will become essential enterprise infrastructure
- Confirmed: SSO is universal enterprise infrastructure
- NT Server version in field test; planned for future release
- Users consistently give DynaSoft high marks for helping deploy projects ahead of schedule
- HP and Sun endorsements consolidate support, widen distribution, add professional services
- Software credential containers independent of specific credential implementations
- Security Dynamics built security portfolio via acquisitions (RSA Data Security 1996 DynaSoft 1997)
