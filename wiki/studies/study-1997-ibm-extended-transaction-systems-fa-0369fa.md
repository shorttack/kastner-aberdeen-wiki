# IBM Extended Transaction Systems Family

> Aberdeen Group evaluates IBM's Extended Transaction Systems (ETS) product family — comprising MQSeries commercial messaging, Lotus Notes groupware, Transaction Server (CICS/Encina), Database Server (DB2), and IMS — assessing their value for mission-critical transaction processing in network-computing and Internet/Intranet architectures. The study recommends ETS as a low-risk migration path for IBM shops transitioning to network computing.


_Published 1997, author **Aberdeen Group**, type **Profile**._


## Top observations

- Most popular TP monitor worldwide
- Unix, OS/2, Windows NT, Digital VAX, MVS/ESA servers; Unix/DOS/OS/2/Win95/NT clients
- Performance approaching RPC
- Most popular LAN groupware product
- Most-used mainframe DBMS
- Very-large-database data-warehousing proven
- Web servers creating scalability bottlenecks
- Migration path for IBM mainframe shops to network computing
- Will add third-party and IBM tools for ORBs and commercial-messaging applications
- Renamed and expanded; ORB integrations added
- Will continue integrating products and development tools with the Internet
- Sold by IBM to HCL for $1.8B; lost collaboration market to Microsoft 365
- Will extend multimedia capabilities for Web-site and Internet needs
- DB2 UDB shipped with extensive multimedia/XML/Extender support
- TP-monitor middleware most critical to Internet architecture scalability
- Java application servers (WebSphere, JBoss, WebLogic) confirmed TP-monitor pattern at Internet scale
- Encina removed from TXSeries V6.1 in 2006
- CICS TS 6.3 released September 2025; actively developed with Jakarta EE 10, Spring Boot 3 support
- Assured once-and-only-once delivery with connection independence
- CICS Gateway for Java; Web and Lotus Notes integration
- Large data types up to 2 GB; Relational Extenders for complex types
- Covers both IBM and non-IBM sites via open middleware interoperability
- IMS accessible via Web browser through Internet Connection Server / MQSeries gateway
- ETS deserves IS buyers' closest attention; highly attractive network-computing family
- Internet/Intranet adding new TP patterns for e-commerce
