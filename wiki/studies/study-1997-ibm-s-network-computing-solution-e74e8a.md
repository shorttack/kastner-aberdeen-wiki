# IBM's Network Computing Solution: Energize Your Enterprise

> Aberdeen Group profiles IBM's comprehensive Network Computing Solution branded 'Energize Your Enterprise', comprising six product families: Personal Communications, Business Intelligence, Information Integration, Application Development, Systems Management, and Extended Transaction Services. The study assesses IBM's approach to helping enterprises migrate from legacy architectures to Intranets, Web-enabled applications, and n-tier client-server. Aberdeen evaluates key technologies including DB2, MQSeries, Tivoli, VisualAge, CICS/Encina, and IBM's AnyNet multiprotocol middleware. The study provides Aberdeen's framework for network computing evaluation and concludes IBM's integrated approach provides a superior migration path versus point-solution competitors.


_Published 1997, author **Aberdeen Group**, type **profile**._


## Top observations

- Personal Comms, Business Intelligence, Information Integration, App Dev, Systems Mgmt, Extended Transaction Services
- Web browsers/servers/applets; TP-monitor scaling; Intranet migration; legacy integration
- IBM comprehensive suite provides superior migration path vs fragmented competitors
- Automated e-commerce and supply-chain integration predicted as major benefit of network computing
- IBM endorsing CORBA + Java Beans for distributed object architecture
- CORBA failed to dominate; displaced by XML Web Services (SOAP), then REST APIs
- E-commerce became multi-trillion dollar global sector; Aberdeen prediction highly accurate
- Most commonly implemented TP environment worldwide (CICS); MQ 20+ industry platforms
- N-tier client-server cited as key new architecture alongside distributed-object and Internet thin-client
- BI identified as core network computing value proposition; data warehousing and analytics
- Legacy data access and integration identified as critical for network computing ROI
- Internet thin-client and web-based architecture became dominant; IBM's prediction accurate
- Oracle acquired Sun Microsystems in 2010 for $7.4B including Java and MySQL
- Manages mixed heterogeneous environments; integrates SMS, NetView, OpenView, NetManager
- Comprehensive integrated suite vs point-solutions; migration path from legacy; service-led
- IBM endorsing Java server-to-client development with VisualAge; opposing ActiveX/Microsoft
- Strategic intelligence, organizational connectivity, global solution delivery, legacy leverage
- MQSeries renamed WebSphere MQ 2002; renamed IBM MQ 2014; active enterprise messaging platform
