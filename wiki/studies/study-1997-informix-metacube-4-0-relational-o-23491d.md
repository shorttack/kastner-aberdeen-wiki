# Informix MetaCube 4.0: Relational OLAP and RDBMS Create an Integrated DSS Environment

> Aberdeen Group examines Informix MetaCube 4.0, a Relational OLAP environment that leverages Informix Dynamic Scalable Architecture (DSA). The profile argues emerging customer-centric applications demand RDBMS-native ROLAP with speed, scalability, and adaptability to changing data models and intranet strategies. MetaCube 4.0 shares critical tasks between RDBMS and OLAP layers for manageability.


_Published 1997, author **Bob Moran / Aberdeen Group**, type **Product Profile**._


## Top observations

- RDBMS-leveraging ROLAP approach will be preferred over standalone MOLAP for large-scale deployments `[ps=5]`
- Emerging customer-centric applications demand more from data warehouses `[ps=4]`
- Decision support requires RDBMS foundation with greater speed and scalability `[ps=4]`
- Intranet adoption increases requirements for adaptive ROLAP tools `[ps=4]`
- ROLAP tools must adapt quickly to user population growth and data volume increases `[ps=4]`
- DSA enables intelligent sharing of resource-intensive tasks between RDBMS and OLAP `[ps=4]`
- MetaCube discontinued after IBM acquired Informix database division for $1B in 2001; IBM focused on DB2+Cognos for BI `[ps=4]`
- Combining DSS with RDBMS administration creates manageability advantage `[ps=4]`
- ROLAP largely won for large-scale enterprise deployments; Microsoft SSAS (MOLAP) won SME; Essbase/Oracle maintained niche `[ps=4]`
- Routine large-scale decision support access requires RDBMS foundation with scalability `[ps=4]`
- Confirmed: web-based BI reporting became dominant delivery mode by 2000-2003; Cognos ReportNet, Business Objects XI all web-native `[ps=4]`
- Confirmed: scalability and automatic metadata management became top BI tool criteria; Tableau/Looker/SSAS validated `[ps=3]`
- Intranet strategies will increasingly drive enterprise ROLAP requirements `[ps=3]`
- MetaCube 4.0 positioned as competitive ROLAP solution for enterprise DSS `[ps=2]`
- Forthcoming release leveraging Informix DSA `[ps=0]`
