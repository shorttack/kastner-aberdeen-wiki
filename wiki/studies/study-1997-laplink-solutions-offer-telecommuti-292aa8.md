# LapLink Solutions Offer Telecommuting Value-Add

> Aberdeen evaluates Traveling Software's LapLink remote control solutions for telecommuting. Study covers remote control vs remote node architecture security features SpeedSync technology and the growing telecommuting market with 9.5M off-site workers in 1997 projected to exceed 15M by 2000.


_Published 1997, author **Virginia Brooks / Aberdeen Group**, type **Impact Brief**._


## Top observations

- Microsoft RDP (Terminal Services) and Citrix MetaFrame became dominant remote access solutions by 2001; LapLink's dial-up remote control approach became niche `[ps=5]`
- Telecommuting increases employee retention and productivity between 10 to 30 percent `[ps=4]`
- Traveling Software renamed LapLink Software ~2004; pivoted from remote control to PC migration (PCmover); remote control market lost to RDP and VPN; company survived through product pivot `[ps=4]`
- IT must enable remote use of bandwidth-hungry applications economically over low-bandwidth dial-in connections while addressing multiple protocols and security `[ps=4]`
- Flexibility flexibility for dependent care alternatives to relocation air quality legislation compliance cited as drivers `[ps=4]`
- Remote node does not permit end-users to remotely operate desktop applications or allow MIS diagnostic control `[ps=3]`
- LapLink provides effective economical remote access addressing major stumbling blocks of remote information access file transfer and synchronization `[ps=3]`
- Traveling Software recognized as well-established market leader in file transfer and remote control functionality `[ps=2]`
- SpeedSync transfers only changed file portions reducing transfer times by as much as 80% `[ps=0]`
- Over 9.5 million employees work off-site in 1997
- Telecommuting projected to exceed 15 million by the year 2000
- Actual telecommuting was approximately 10% of workforce (roughly 13-14M workers) by early 2000s; projection directionally correct though definition-dependent
- Remote control is superior to remote node for large database-oriented applications over low-bandwidth connections
- Separate caller passwords optional password protection three access levels keyboard/mouse disabling screen blanking callback feature and Event Log
- Broadband adoption post-2000 eliminated dial-up constraints; VPN became standard remote access; LapLink's bandwidth optimization features became less compelling as line speeds increased 100x
