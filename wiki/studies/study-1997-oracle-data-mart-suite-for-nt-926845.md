# Oracle Data Mart Suite for NT: Hitting The Mass-Market Sweet Spot

> This 1997 Aberdeen Group profile evaluates Oracle's Data Mart Suite for NT, a pre-packaged data mart solution designed to lower cost and complexity barriers for line-of-business managers. The study argues that Oracle's bundled approach—combining database, ETL, OLAP, query tools, and administration into a single NT-native package—positions it to capture the emerging mass-market for departmental data warehousing. Aberdeen rates the product highly for cost-of-ownership advantages over ad hoc tool-integration approaches.


_Published 1997, author **Aberdeen Group**, type **market-study**._


## Top observations

- Business Objects cited as leading standalone BI competitor `[ps=5]`
- Integrated data warehouse appliances and cloud suites became dominant; Oracle, Microsoft, IBM all pursued bundled approaches; specialized standalone BI vendors (Business Objects, Cognos, Hyperion) were acquired by major platform vendors `[ps=5]`
- 6-12 months implementation typical for custom data mart `[ps=4]`
- Data mart in a box — pre-assembled complete package `[ps=4]`
- Single unified DBA console for entire suite `[ps=4]`
- Cognos Impromptu cited as leading query/reporting competitor `[ps=4]`
- NT chosen as target platform for mass-market appeal and cost-effectiveness vs Unix `[ps=4]`
- Data mart market estimated in hundreds of millions; growing rapidly `[ps=4]`
- MicroStrategy referenced as high-end BI competitor focused on enterprise scale `[ps=4]`
- Red Brick cited as purpose-built data warehouse DB competitor `[ps=3]`
- Aberdeen rates Oracle Data Mart Suite as strong market contender `[ps=3]`
- Oracle's commitment to NT platform will accelerate enterprise NT adoption for data warehousing `[ps=3]`
- Pre-packaged integrated data mart suites will dominate over custom-assembled multi-vendor solutions `[ps=2]`
- Windows NT/2000 did become dominant enterprise data warehouse platform by 2000-2003; Linux later displaced NT/Windows in data center `[ps=2]`
- Oracle8 RDBMS included as core component of DMS `[ps=0]`
- Oracle Express Server included for multidimensional analysis `[ps=0]`
- Oracle Discoverer included for ad-hoc query and reporting `[ps=0]`
- Under $35,000 for 5 named users; scales to $50-80K for 25-50 users `[ps=0]`
- Oracle Data Mart Suite includes ETL/data transformation tools `[ps=0]`
- Departmental/line-of-business managers; 5-100 users; under $100K total cost `[ps=-1]`
