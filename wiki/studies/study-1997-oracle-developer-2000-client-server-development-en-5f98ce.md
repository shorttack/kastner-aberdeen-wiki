# Oracle Developer/2000 Client-Server Development Environment

> This 1997 Aberdeen Group profile evaluates Oracle Developer/2000, Oracle's second-generation Client-server Application Development Environment (CADE). Aberdeen positions Developer/2000 as having the widest range of scalable application development capabilities among CADEs, targeting medium-to-large data-intensive mission-critical client/server applications while also supporting workgroup-level and World Wide Web deployment via Java interfaces. The study details Developer/2000's 4GL toolset including Forms, Reports, and Graphics modules and its strategic role in Oracle's Network Computing Architecture.


_Published 1997, author **Aberdeen Group**, type **market-study**._


## Top observations

- Widest range of scalable application development capabilities among CADEs; targets medium-to-large data-intensive mission-critical client/server
- Developer/2000 enables application deployment with Java interfaces over World Wide Web
- Advanced 4GL including Forms/Graphics/GUIs, Reports, procedure building, connectivity tools, and server-based development tools
- Developer/2000 is the CADE component of Oracle's Network Computing Architecture; uses cartridge approach for Internet deployment
- Developer/2000 encompasses transaction processing, decision support, and multi-platform connectivity
- Oracle Forms provides forms generation with PL/SQL support; runs on Windows, Unix, and Web via Java
- Oracle Reports provides sophisticated report generation from simple tabular to complex cross-tab and matrix formats
- Oracle Graphics provides chart and graph generation tightly integrated with Forms and Reports
- Microsoft Visual Basic cited as low-end CADE competitor; lacks scalability for mission-critical enterprise applications
- PowerBuilder cited as high-end CADE competitor; strong in corporate IS but lacks Oracle's database integration depth
- Informix cited as RDBMS competitor offering application development tools
- Best suited for medium-scale to high-end data-intensive and mission-critical applications; effective down to workgroup level
- Developer/2000 with Web Cartridge and Java interfaces will position Oracle as leading Internet application development platform
- Oracle Developer/2000 (Forms/Reports) maintained large installed base but failed to win new Internet development projects; Java/J2EE, .NET, and PHP dominated web development by 2005; Forms extended support ended 2023
- Developer/2000 supports Java interfaces for web deployment without requiring all developers to learn Java
- Aberdeen recommends Developer/2000 for medium-to-large data-intensive mission-critical applications; notes effective down to workgroup level
- Developer/2000 front-end runs on Windows 95/NT/3.x; server side on Unix and major platforms
- Developer/2000 is a refinement of Oracle's second-generation Cooperative Development Environment (CDE 2)
