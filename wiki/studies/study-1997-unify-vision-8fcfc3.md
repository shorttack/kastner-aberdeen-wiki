# Unify VISION: The Future Of High-End Internet Software Development

> Aberdeen Group's April 1997 Product Viewpoint evaluates Unify VISION as a high-end software development toolset capable of bridging mature client-server functionality with emerging Internet and Java architectures. The report benchmarks VISION against five key criteria — scalability, Java integration, multi-tier architecture support, portability, and rapid application development — and concludes that VISION's planned Java embedding and multi-tier capabilities position it as a credible enterprise platform. Aberdeen predicts that vendors failing to commit to Java will lose enterprise relevance within two to three years.


_Published 1997, author **Aberdeen Group**, type **market-study**._


## Top observations

- High-end 4GL with mature client-server and emerging internet capability
- Critical — toolsets without Java commitment will lose enterprise relevance
- Mature — approaching obsolescence as internet architectures emerge
- Rapidly emerging — vendors must support n-tier for enterprise credibility
- Capable of thousands-of-users deployments; 911 CAD systems cited as example
- Reduced deployment costs vs. traditional methods
- Faster competitive-advantage upgrades than alternatives
- Partial — Java embedding planned but not yet fully implemented at time of study
- Java will become the dominant enterprise application language within 2-3 years
- Java achieved dominant enterprise language status by 2000-2001; J2EE became the standard
- Tools without Java/internet support will become obsolete or lose enterprise relevance
- PowerBuilder (Sybase) and SQLWindows (Gupta) declined sharply post-2000; 4GL tools displaced by J2EE frameworks
- VISION positioned to compete as top-tier enterprise development platform if Java roadmap executed
- Unify failed to achieve enterprise leadership; accounting fraud scandal 2000; CEO convicted 2003; delisted from Nasdaq; pivoted away from VISION
- VISION supports thousands-of-users deployments; mission-critical 911 CAD proven
- Java embedding on product roadmap; not yet fully delivered
- Supports client-server and beginning to support three-tier; internet architecture transitional
- Cross-platform: Windows; Linux; Unix — broad OS coverage
- Mature 4GL RAD capabilities; forms/report generation; workflow; proven in production
- Leading Windows RAD tool; strong but at risk from internet transition
- Niche Windows/Unix RAD tool; declining relative to PowerBuilder
- Described as large-scale and rapidly growing; no specific TAM figure cited
- Enterprises should require Java commitment from toolset vendors before purchasing
- Emerging enterprise middleware; VISION should integrate with CORBA for object distribution
- Microsoft component model cited as important for Windows desktop integration
