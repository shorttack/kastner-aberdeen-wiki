> An internal Aberdeen Group memorandum from analyst Wayne Kernochan to Peter Kastner proposing a revised template for Aberdeen Practice Summary documents. The memo provides a detailed five-chapter master outline with worked examples drawn from NOS (Network Operating System) and NT/Intel server practice areas, and argues for recasting Practice Summaries as sales-oriented hot-topics vehicles. Two template versions are offered: a lightly revised version with prior-year examples and a more substantial revision emphasizing hot topics for 1999.


_Published 1999, author **Wayne Kernochan**, type **other-research**._


## Top observations

- NT Server's growing role in enterprise and relative decline of other NOS suppliers making IS decisions urgent and strategic `[ps=5]`
- Component development/assembly and Internet application deployment are two thorniest IT issues over next five years; will drive fully distributed multi-tiered environment `[ps=5]`
- Cost-effective NT/Intel servers will continue to plummet in price per transaction to less than $15 `[ps=5]`
- Implementation and maintenance of NOSes has gotten so complex it often requires outside assistance; especially true for NT Server as enterprise NOS `[ps=5]`
- Kernochan argues for recasting Practice Summaries as hot-topics sales vehicles rather than primarily analyst training documents `[ps=4]`
- Most mid/large organizations have multi-tier hardware/software with multiple NOSes; key IS question is interoperability strategy not NOS selection `[ps=4]`
- Recent enterprise adoption of Java development toolsets for e-commerce and distributed application deployment drives AD market `[ps=4]`
- Four major trends: Internet/intranet/extranet development; component production/assembly; distributed-app deployment; modeling/repositories `[ps=4]`
- NT/Intel server market at inflection point with new Intel hardware and Windows NT 5.0 enhancements upcoming `[ps=4]`
- Active Directory and advanced >2-server clustering expected to arrive in NT products before year 2000 `[ps=4]`
- NT Server has significant issues to address vs Unix: interoperability; scalability; user counts; stability; storage management; security `[ps=4]`
- Microsoft mastered ISV recruitment and channel partner alignment; non-IS executive confusion of OS vs NOS helps NT Server adoption `[ps=4]`
- Four trends in 1998: boosting IA server capabilities; server consolidation; improving NT reliability/performance; clustering (work-in-progress) `[ps=4]`
- Under Eric Schmidt leadership Novell plans products/services leveraging Java and Internet Infrastructure for installed base; must execute `[ps=4]`
- NOSes proving more effective than ever as internet arrives; Internet requires directory/admin/security services that NOS is best positioned to provide `[ps=3]`
- Microsoft NT Server 4.0 is being overused at customer sites for enterprise-scale implementations it cannot support `[ps=3]`
- Questions about which features will be included in NT 5.0 make it imperative for IS to scrutinize present implementations `[ps=3]`
- NOS suppliers answering user server-consolidation goals by delivering broader directory services and cross-platform administrative solutions `[ps=3]`
- All three major NOS vendors (Microsoft/Novell/IBM) showed sales increases over past two years despite NT Server dominance; market expanding overall `[ps=3]`
- Novell is not a dead company; NetWare and IBM OS/2 Warp Server can play key roles in Internet Infrastructure via directory services and intranet workgroup support `[ps=2]`
- NT 5.0 is the critical path product for Novell's installed base; Novell's task is to reassure customers NT 5.0 and its Internet Infrastructure will meet needs `[ps=2]`
- Aberdeen expects conversion to IA-64 will take up to five years or more; allows greater NT/Intel server market segmentation between enterprise and cost-effective tiers `[ps=1]`
- Majority of NT Server NOS sales are in the workgroup segment rather than enterprise `[ps=0]`
- Five-chapter master outline: Executive Summary / Summary of Findings / Practice Area Defined / Issues and Challenges / Supplier Abstracts `[ps=0]`
- Aberdeen covers five Group Areas: Platforms / Services / Enterprise Business Applications / Network Services / Telecommunications and Networking `[ps=0]`
