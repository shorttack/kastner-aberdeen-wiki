# Linux Is on the Move - Up!

> This Aberdeen InSight argues that Linux development is moving faster than any other commercial operating system and will leapfrog Windows to replace Unix on the high end within seven to eight years. With major contributors including Compaq, HP, IBM, and numerous smaller companies, Aberdeen predicts Linux will join IBM z/OS and Microsoft Windows as a primary server OS before the end of the decade. The study positions Linux as the third pillar of enterprise server computing.


_Published 2001, author **Bill Claybrook**, type **market-study**._


## Top observations

- Linux developing faster than any other commercial OS to date
- Linux will leapfrog Windows to replace Unix on the high end within 7-8 years (by 2008-2009)
- IDC 2004 predicted Windows would overtake Unix by 2008; Linux grew from 8.4% to 14.9% server share by 2008; Unix declined from 39.6% to 31.9%
- Linux will join IBM z/OS and Microsoft Windows as the primary server OSes before end of decade (by 2010)
- Linux server revenue reached $1.6B quarterly by 2005 with 14th consecutive quarter of double-digit growth; Linux became dominant public cloud OS by 2010
- Compaq, HP, IBM and many smaller companies contributing to Linux development efforts
- IBM positioned both z/OS (mainframe) and Linux as strategic platforms — Linux for distributed; z/OS for mainframe
- Unix occupying high-end server market that Linux is predicted to displace
- Linux server market share reached 28.3% of server sales by 2004 per IDC (combined Unix+Linux 1.48M units)
- Linux server revenue grew 63% to $960 million in Q4 2003 (IDC)
