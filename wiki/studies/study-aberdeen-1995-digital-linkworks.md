# Digital LinkWorks: Delivering Solutions to MIS and End-Users

> Aberdeen Group profile evaluating Digital Equipment Corporation's LinkWorks, a document management and workflow platform for enterprise groupware. Introduces the concept of 'Enterprise Groupware' built on distributed object technology and contrasts it with first-generation products such as Lotus Notes and Microsoft Exchange. Argues that LinkWorks uniquely satisfies both MIS and end-user requirements through open databases, OLE integration, and a component-based development model.


_Published 1995, author **Aberdeen Group**, type **product-profile**._


## Top observations

- Aberdeen research found that groupware products do not usually satisfy all stakeholders simultaneously: department-acquired solutions rarely meet MIS rigor; MIS-acquired solutions rarely meet end-user ease-of-use expectations. `[ps=5]`
- MIS requires standardized rapid development, multi-vendor business process automation, controlled data access, and use of existing infrastructure; end-users require ease of use, searchable common repository, familiar desktop tools, and flexible collaboration — these goals are frequently in conflict. `[ps=5]`
- Failed: Digital LinkWorks was discontinued after Compaq acquired DEC in 1998 for $9.6B; Lotus Notes and Microsoft Exchange/Outlook dominated enterprise groupware `[ps=5]`
- Partially confirmed: OLE/COM became dominant Windows integration layer; CORBA faded. But collaborative tools (SharePoint, Exchange) were mail-centric not object-centric. Web/HTTP displaced CORBA/OLE. `[ps=5]`
- Aberdeen states that applying the Enterprise Groupware litmus test to Lotus Notes makes clear it is a first-generation product — more like a standard development environment supporting multiple tools, not an object-oriented enterprise groupware system. `[ps=4]`
- End-users can specify document routing via a graphical interface: drag-and-drop recipients from an org chart, assign conditional branches, and automate notification when objects are modified. `[ps=4]`
- LinkWorks persists user desktop state server-side: when a user logs in from any machine or OS, the environment is reconstructed exactly as left, with all objects and files accessible. `[ps=4]`
- The LinkWorks Application Plus Objects (APO) interface allows legacy applications and data to be encapsulated as first-class objects; requires a developer fluent in both objects and the legacy system. `[ps=4]`
- Aberdeen identifies cross-organizational support as a critical success factor for enterprise groupware adoption, and positions it as a key market differentiator. `[ps=4]`
- LinkWorks enforces security at the object level, providing controlled access even for applications that are not 'security aware'; all data access is governed by user logon and centrally maintained object permissions. `[ps=4]`
- LinkWorks integrates with Windows via OLE Automation, allowing Windows OLE-capable applications to become objects in the LinkWorks repository. Digital and Microsoft collaborated on porting NT to Alpha and integrating OLE with Digital's object broker. `[ps=3]`
- Aberdeen recommends corporations take 'a long hard look at LinkWorks' for competitive advantage and cost savings through object technology; also recommends confronting legacy integration challenges because the ROI of integration is substantial. `[ps=3]`
- Applications and templates can be packaged into software components and installed or deinstalled across any number of LinkWorks servers via disk, tape, CD-ROM, or the corporate messaging infrastructure. `[ps=3]`
- LinkWorks supports scripts that can be recorded or executed on any desktop or server, and can be encapsulated and used as objects within solutions. `[ps=3]`
- Aberdeen recommends companies confront legacy integration difficulties: once integrated, legacy applications gain full leverage in LinkWorks solutions; legacy programmers gain valuable OO skills enabling them to tackle mission-critical reengineering. `[ps=3]`
- The LinkWorks server maintains a complete record of every object regardless of which server it resides on, enabling enterprise-wide search across the entire LinkWorks environment. `[ps=3]`
- LinkWorks provides a central Administration Manager to control the entire environment; the Cell cluster architecture is event-based and allows centralized management of performance characteristics. `[ps=3]`
- Aberdeen predicts Lotus Notes, classified as first-generation groupware, will be displaced by Enterprise Groupware built on object technology `[ps=3]`
- Prediction wrong: IBM acquired Lotus for $3.5B in 1995; Notes/Domino remained enterprise standard through 2010s; HCL Technologies acquired Notes/Domino 2019; still active in 2026 `[ps=3]`
- Aberdeen notes that Microsoft Exchange, like Lotus Notes, fails the Enterprise Groupware litmus test because it lacks object-oriented architecture and component-based composition. `[ps=1]`
- Digital Equipment Corporation introduced LinkWorks in 1994 and had just announced version 3 at the time of the study (July 1995), described as 'years ahead of more traditional groupware providers.' `[ps=1]`
- Aberdeen states that Digital 'has established a solid lead in bringing Enterprise Groupware to market,' positioning LinkWorks as the first Enterprise Groupware product and DEC as years ahead of traditional groupware providers as of mid-1995. `[ps=1]`
- Aberdeen predicts Digital LinkWorks will become the standard for Enterprise Groupware, displacing first-gen Notes/Exchange in large organizations `[ps=1]`
- LinkWorks desktop clients supported: Windows 3.1, Windows for Workgroups, Motif (Digital/HP/IBM), OS/2 Presentation Manager, and Macintosh OS. `[ps=0]`
- LinkWorks supports Oracle, CA Ingres, Microsoft SQL Server, and Informix as repository databases; Sybase support was planned. `[ps=0]`
