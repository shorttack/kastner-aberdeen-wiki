# Digital's ObjectBroker -- Advanced Integration of Distributed Resources

> Profile evaluating Digital Equipment Corporation's ObjectBroker, a CORBA-compliant object request broker for integrating distributed heterogeneous resources. Examines ORB technology, legacy system encapsulation, OLE-COM integration, and 19-platform support.


_Published 1995, author **Aberdeen Group**, type **product-profile**._

- $149

- 19 platform combinations
- CORBA 1.2
- Planned for ObjectBroker 2.6
- C binding, Visual Basic DLL binding
- Planned for ObjectBroker 2.6
- 1991
- >50% of Digital installed base

- IDL, IML, MML Repositories
- Configuration Registries
- Context Objects
- Systems Administrator, Network Tester, Context Object Editor, Repository Manager, Implementation Viewer, OLE Network Portal, DDE Listener

- Wraps command line interfaces
- OLE 2.0 interface to ObjectBroker registry
- Legacy DDE message bridge
- CORBA wrapper for legacy/procedural code
- IML: describe object implementations; MML: select among implementations
- Dual-standard bridging architecture
- GA expected early 1996
