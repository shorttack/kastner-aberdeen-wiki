# Hewlett-Packard's C++ SoftBench 5.0 -- A Powerful Platform for Professional Developers

> Aberdeen Group executive white paper evaluating HP's C++ SoftBench 5.0 IDE for object-oriented software development. Examines OO development advantages, SoftBench features including CodeAdvisor and graphical class editor, and HP's consulting services.


_Published 1995, author **Aberdeen Group**, type **white-paper**._


## Top observations

- Object-oriented applications can integrate existing software by building an interface wrapper around legacy systems, preserving previous software investments `[ps=5]`
- An industry transition to distributed computing is underway driven by geographically distributed business units and the need to share core databases `[ps=5]`
- Aberdeen firmly believes distributed computing will become increasingly critical to daily business operations and user organizations should evaluate a supplier's distributed computing strategy even with no immediate plans `[ps=5]`
- Aberdeen firmly believed distributed computing would become increasingly critical to daily business operations `[ps=5]`
- Aberdeen predicted that with right tools, training, expertise, and vendor support, OO development would deliver real long-term benefits; time to implement is now `[ps=5]`
- Aberdeen believes the time to implement object technology is now, when combined with appropriate levels of training and support `[ps=4]`
- Aberdeen's field research consistently shows OO development delivers real long-term benefits but only with the right mix of advanced tools and training `[ps=4]`
- When a business rule changes enterprise-wide it will become cost-prohibitive to have programming staff hand-code all occurrences without integrated distributed software methods `[ps=4]`
- Aberdeen field research consistently shows that when any one of four critical factors is missing (robust tools / training / implementation expertise / leadership vendor) there is a much higher chance of delays, cost overruns, and user dissatisfaction `[ps=4]`
- Using the Encapsulator, SoftBench embeds third-party tools so they share the same user interface and seamlessly communicate with each other enabling best-of-breed tool selection `[ps=4]`
- CodeAdvisor automatically enforces C++ coding rules by using the static analysis database to discover common coding errors such as improper object copying with dynamically allocated memory `[ps=4]`
- HP's experience shows customers first inventory existing applications to determine what should be encapsulated and linked to new OO applications using C++ SoftBench and UIM/X `[ps=4]`
- Companies moving to object technology face two major challenges: development staff retraining and migrating the code base `[ps=4]`
- The heavy use of objects by independent software vendors for developing products is accelerating the adoption of OO technology `[ps=4]`
- Distributed computing became foundational: client-server, web services, SOA, cloud computing all represent successive waves validating this prediction. Ubiquitous by 2000. `[ps=4]`
- OO development became mainstream through late 1990s via Java (1995), C++ wide adoption, Python. However the specific C++/HP-UX SoftBench path was displaced by Java, Eclipse, and open source IDEs by 2000. `[ps=4]`
- SoftBench graphically depicts application structure and object inheritance, shortening the time needed for new developers to learn object technology `[ps=3]`
- New SoftBench 5.0 Graphical Class Editor allows developers to visually edit objects with changes automatically reflected in underlying C++ code by making static analysis database read-write `[ps=3]`
- For systems mixing C++, C and COBOL, HP offers COBOL SoftBench and COBOL/C++ SoftBench enabling incremental migration from procedural to OO programming `[ps=3]`
- Aberdeen believes SoftBench's team development features and ability to encapsulate third-party tools result in an excellent environment for professional developers building mission-critical applications `[ps=3]`
- HP's vision is applications assembled from pre-built components from internal development, third parties, or legacy systems; SoftBench will gain enhanced graphical programming and code maintenance capabilities `[ps=3]`
- HP is viewed as a trusted supplier with $25 billion in revenues having the resources to take on the largest and most complex assignments `[ps=3]`
- A new development environment must include robust browsers, editors, compilers, support team development, and cover the full software lifecycle from analysis and design to testing `[ps=3]`
- In Aberdeen's opinion, Hewlett-Packard has the right combination of products, services and partnerships needed in today's market `[ps=2]`
- Aberdeen believes CodeAdvisor represents an elegant way to teach new C++ developers the subtleties of OO programming and will significantly accelerate object adoption timetables `[ps=2]`
