# New LIMD Technology: Speed Plus Real-World Experience

> Technology Viewpoint analyzing Large-Scale In-Memory Database (LIMD) technology, examining how 64-bit architectures and large main memories deliver 10-100x performance improvements for data warehousing, OLTP, and decision support.


_Published 1995, author **Aberdeen Group**, type **market-study**._


## Top observations

- Study implied that as 64-bit platforms became available, LIMD would transition from specialty to mainstream for database workloads exceeding 32-bit memory ceiling `[ps=4]`
- 64-bit Unix (DEC Alpha, IBM AIX, HP-UX) became standard for enterprise RDBMS by 1998-2000. Windows 64-bit server followed later. By 2000, multi-GB main memory databases were standard for OLTP and data warehousing. SAP HANA (2011) is ultimate realization of LIMD concept with in-memory RDBMS as primary paradigm. `[ps=3]`
- Aberdeen forecast up to order-of-magnitude performance improvements arriving over next 2 years as ISV applications were rewritten for LIMD architectures `[ps=1]`
