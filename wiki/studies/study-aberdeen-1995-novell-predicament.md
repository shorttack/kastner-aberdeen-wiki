# The Novell Predicament

> Aberdeen examines Novell's strategic crisis in August 1995, finding that IT managers are standardizing on Windows NT and that Novell has failed to execute its application server strategy. The report details Novell's three principal failure modes (tactical changes, technical execution failures, ISV attrition) and projects erosion of Novell's enterprise position. Aberdeen advises IT executives to carefully evaluate NetWare for medium and long term use while outlining prescriptions for Novell's survival.


_Published 1995, author **Aberdeen Group**, type **market-viewpoint**._


## Top observations

- IT managers standardizing on Windows NT Workstation as desktop; expect NT Server to replace NetWare file/print
- 3 principal failures: annual tactic changes, technical execution failures, ISV attrition
- excellent cross-platform interoperability for Novell+NT+Unix; hierarchical management view
- NT Server unit sales ramping; PC server suppliers reporting NetWare sales decline vs NT growth
- further erosion of Novell enterprise position projected
- Microsoft OLE Directory Services will succeed because OLE-enabled applications drag it into enterprise
- LDAP will become de-facto directory services standard for Internet
- little evidence NDS will achieve widespread acceptance outside Novell installed base
- acquired by Attachmate Group for $2.2B in April 2011; 882 patents sold to Microsoft consortium for $450M
- Windows NT and successors (2000/2003) became dominant enterprise network OS; NetWare marginalized
- LDAP became universal directory protocol; embedded in Active Directory, OpenLDAP, all major systems
- GroupWise lost groupware war to Exchange/Notes; retained only legacy Novell-loyal customers
- SMP, distributed print, systems management, improved IP support
- Must make NDS best on NT bar none; open new markets to dominate; embrace NT not fight it
- Portable NetWare, AppWare, Tuxedo acquisition, UnixWare, WordPerfect—all failed
- Volume 9/Number 14, August 9, 1995
- few ISVs actively porting applications to NetWare; ISVs look elsewhere
- Novell GroupWise vs IBM Notes vs HP OpenMail vs Microsoft Exchange vs Netscape CollabraShare
- NDS infrastructure services marketed to AT&T, Deutsche Telekom, NTT, Telstra, Unisource
- ManageWise vs CA Unicenter vs HP OpenView as competing network management frameworks
- revenue declines confirmed; Aberdeen analysis confirms declining trend
- Either Novell fully integrates NDS with NT or Microsoft delivers OLE Directory interoperating with NDS
- Active Directory shipped in Windows 2000; became dominant enterprise directory service
- IBM acquired Lotus Development Corporation for $3.5B in 1995
- IT executives advised to carefully evaluate NetWare use for medium and long term
