# Progress Version 8.0 Development Environment: The Importance Of Experience-Driven Scalability and Flexibility

> Aberdeen evaluates Progress Software's Version 8.0 client-server application development environment (CADE), finding it a scalable, flexible, database-independent toolset. The study examines Progress's SMARTOBJECT components, VPE tools, 4GL language, DataServer architecture, and object-oriented capabilities, concluding Progress 8.0 addresses key IS requirements for complex data-intensive applications through experience-driven engineering.


_Published 1995, author **Aberdeen Group**, type **product-profile**._


## Top observations

- first-generation limitations becoming visible
- multiple RDBMS via DataServer native drivers
- object classes, encapsulation, inheritance via SMARTOBJECT
- OLE2, VBX, Browser, Combo-box, Print dialog, 3-D support
- experience-driven engineering driving scalability and flexibility
- database-independent, multi-platform CADE targeting complex applications
- scalable toolsets will displace first-generation CADEs
- component-based development will improve productivity for complex applications
- full software lifecycle support is required for long-term CADE viability
- survived as OpenEdge; pivoted to infrastructure software

- Progress 8.0 edge for complex client-server via DataServer performance
- foreign-language translation support as competitive differentiator
- scalability, database-independence, lifecycle support, legacy migration

- team-programming features added in v8.0
