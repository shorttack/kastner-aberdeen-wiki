# Blyth's REN Architecture: A Prescription for IT Success

> Aberdeen Group evaluates Blyth Software's REN architecture (Real solutions, Endless possibilities, No boundaries), a dual-track application development framework targeting both traditional client-server and emerging Internet/Intranet commerce applications. The study argues that Blyth's OMNIS-based toolset, extended with five Net-enabled products (Web Enabler, OMNIS Data Server, Web Vault, Web Manager, Weblets), gives the company at least a 12-month competitive lead in mission-critical web development infrastructure. Aberdeen predicts that successful REN execution could elevate Blyth from a niche vendor to an IT household name.


_Published 1996, author **Aberdeen Group**, type **market-study**._


## Top observations

- More comprehensive Net development vision than competition: dual-track traditional + Net client-server
- Development tools (traditional + Net)
- Database tools (traditional + Net)
- Repository-based application life-cycle management tools
- Reusable software components (Weblets)
- Industrial-strength, complex business applications; cross-platform Windows/OS2/Mac; binary compatible
- TCP sockets, FTP, SMTP/POP3/MIME email, HTTP client/server, HTML generation, Java code generation
- Web Enabler demonstrated accessing FedEx parcel-tracking website and updating internal database automatically
- Vista-based user/group privilege system controlling table and column-level access for web database queries
- Manages HTML, graphics, CGI scripts, Java applets in single version-controlled site; time-sensitive content publishing
- Successful REN execution could propel Blyth from respected-but-small vendor to IT household name
- Never became IT household name; renamed Omnis Technology (1997), Raining Data (2000), TigerLogic (2008); sold to Cliftech Solutions in 2017
- Aberdeen believes Blyth has a twelve month or more advantage over most competitors on Web Enabler-style functionality
- Web development middleware market commoditized by 2000; ASP.NET, PHP, Java EE dominated; Blyth's products could not scale to mainstream adoption
- Word-of-mouth growth + VAR channel + early 'Net market entry; avoid HTML server and page-generation commodity; focus on mission-critical Net middleware
- Named customers include Barclays Bank, Federal Express, Harvard University, Lockheed Martin, Northern Telecom
- IS professionals will soon be 'up to their necks in a swamp of immature Net development products'; will favor high-end tools
- Component marketplace: Blyth + customers + third parties submit components for negotiated payments — buy vs. make decision
- Net application development requires same rigor and tool classes as client-server; most developers not yet aware of this
- Mission-critical Net applications should grow dramatically in 1997 and beyond as Net-enabled electronic commerce takes off
- Second-generation CADE with application logic partitioning, deeper OO, templates/wizards, SQL-aware objects
- Past success inhibited by less-than-stellar distribution and marketing; must ensure Net developers discover the company
