# Data General's Cybershield: Security Solutions for Advancing Business on the Net

> Aberdeen Group profiles Data General's Cybershield security platform, an integrated suite built on the B2-level secure DG/UX operating system (B2SO), designed to protect enterprise Intranets and electronic commerce applications. The study documents IS executives' concerns about network security and the inadequacy of standalone firewalls, then validates Cybershield's ability to segregate users, applications, and data with minimal performance impact. Aberdeen recommends Cybershield as a superior alternative to component-based point solutions for IS executives deploying Internet-facing business applications.


_Published 1996, author **Aberdeen Group**, type **market-study**._


## Top observations

- OS-level and role-based security became industry standard; RBAC, OAuth2/OIDC, and zero-trust all validate 1996 thesis `[ps=5]`
- More worried than ever about lack of control over networked information assets `[ps=4]`
- Three-region compartmentalization: network, admin, application/data; mandatory access controls; role-based access `[ps=4]`
- Integrated platform strategy: one-stop-shopping for intranet/e-commerce security vs. component assembly `[ps=4]`
- Encryption and strong authentication in-plan for all new net-based projects `[ps=4]`
- Firewalls not designed for: complex web-enabled apps, limiting intranet access, segregating parties, or blocking admin access `[ps=3]`
- Single platform consolidating: app-level firewall, auth server, anti-virus, encryption, web server, mail, news `[ps=3]`
- Negligible performance degradation reported by IS managers; users unaware security controls operating `[ps=3]`
- Isolates network traffic; prevents unauthorized access from external networks `[ps=3]`
- Industry validated: unified security platforms (Checkpoint, Cisco PIX, Palo Alto NGFW) dominated; point-solution assembly declined `[ps=3]`
- IS managers cannot cost-effectively improve security of Wintel clients; focusing on auth alternatives `[ps=2]`
- IS executives would be well-served to evaluate DG Cybershield for protecting enterprise Intranets `[ps=2]`
- E-commerce will require OS-level security controls and role-based compartmentalization to be viable `[ps=2]`
- Existing applications can be reused on Cybershield without modification; ISV libraries identical to standard Unix `[ps=0]`
- Integrated off-the-shelf security solutions are nowhere to be found
- IS executives deploying Intranet and electronic commerce applications requiring OS-level security
- Prevents administrators from acquiring access to production applications and data
- Protects applications and data; isolates viruses from production systems
- Integrated platforms will outperform component point-solutions for enterprise internet security
- Discontinued after EMC acquisition of DG in Oct 1999; DG/UX and Cybershield not carried forward
- IS managers confirm consolidated firewall and secure application servers with WAN connections onto single Cybershield
- ISV libraries identical on B2SO and standard Unix; no application changes required
