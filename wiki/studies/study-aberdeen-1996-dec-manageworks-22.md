# ManageWORKS 2.2 Market Profile

> This Aberdeen Group product profile evaluates Digital Equipment Corporation's ManageWORKS 2.2, a multi-NOS LAN management platform designed for site and workgroup environments of 10 to 800 nodes. The study assesses ManageWORKS' architecture, partner ecosystem, and competitive positioning against McAfee and Symantec's Norton Administrator for Networks, concluding that its open, partner-extensible approach is unique in the market. Aberdeen highlights the product's advantage in enabling best-of-breed integrations across disparate network operating systems.


_Published 1996, author **Aberdeen Group**, type **market-study**._


## Top observations

- 10 to 800 managed nodes (site and workgroup level)
- Open partner platform: DEC provides base functionality; partners provide domain-specific applications
- NetWare 3.x/4.x, LAN Manager 2.x, LAN Server, PATHWORKS, partial Windows NT
- Windows 3.1, Windows for Workgroups, Windows 95, Windows NT on Intel and Alpha
- ManageWORKS forwards SNMP traps to POLYCENTER, NetView for AIX, HP OpenView, or any SNMP-capable enterprise manager
- Event Manager acts as processor/repository; pollers distribute across network; console provides UI
- Allows plugging any DOS/Windows application into ManageWORKS without writing code
- OEM licensing allows PC server and comms device vendors to use ManageWORKS as vendor-specific management base
- Configuration management, hardware/software inventory, software distribution, metering, remote control, virus protection
- Tightly integrated proprietary product suite; not designed for third-party integration
- ManageWORKS open integration approach is unique in the LAN management market; appeals to best-of-breed builders
- Open platform strategy positions ManageWORKS to maintain competitive edge in LAN management market
- Digital Equipment Corporation acquired by Compaq in June 1998; ManageWORKS product line discontinued
- POLYCENTER Manager on NetView positioned as higher-end SNMP platform for large installations beyond ManageWORKS scope
- Performance, accounting, software asset/configuration, network, security, storage, problem, automation management (via partners)
- User interface for event/network status viewing and monitoring parameter configuration
- Central processor and repository; logs all alerts; forwards SNMP traps to enterprise managers
- Distributed SNMP pollers tasked with collecting status from specified nodes/subnetworks; communicate with Event Manager via TCP/IP socket
- ManageWORKS gives users a consistent view of disparate networks; no other product offers this
- Multiple consoles can access same Event Manager data simultaneously (read-only); single console can update; data stored on separate file server
