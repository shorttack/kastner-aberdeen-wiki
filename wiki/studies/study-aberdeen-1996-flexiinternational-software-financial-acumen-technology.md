> This Aberdeen Group profile evaluates FlexiInternational Software (Flexi), a 1991-founded provider of object-oriented financial client-server solutions (CSS) competing in the enterprise financial systems market. Aberdeen assesses Flexi's technology architecture, IBM integration strategy, Web-enablement roadmap, and market positioning against major ERP competitors including Dun & Bradstreet, PeopleSoft, Oracle, and SAP. The study concludes that FlexiInternational is well positioned technologically and through business alliances to challenge for CSS market leadership.


_Published 1996, author **Aberdeen Group**, type **market-study**._


## Top observations

- Survived as profitable niche insurance/financial-sector accounting vendor; not a broad CSS market leader. Still active in 2025 as Flexi Software after strategic investment from Quality Standard. `[ps=5]`
- Company went public (OTC) and focused on insurance/financial vertical; alternate channel strategy remained limited in scope relative to main competitors `[ps=4]`
- Windows NT was succeeded by Windows 2000 in 2000; BackOffice suite was retired by 2001. Flexi adapted to Windows 2000/XP server environments successfully. `[ps=4]`
- High-end: D&B Software, PeopleSoft, Oracle, SAP AG; mid-market: Coda, SQL Financials, J.D. Edwards, Lawson, SSA `[ps=4]`
- Screen field add/move/delete, cursor navigation mapping, image inclusion, process flow modification `[ps=4]`
- Database Definition Repository: table/column/datatype definitions, column-level security, audit trail control `[ps=4]`
- Proactive on-site baseline installation for comparative/diagnostic support; dial-in remote access; Aberdeen calls it a support precedent competitors must follow `[ps=4]`
- Enterprises with complex accounting or advanced tech requirements migrating from proprietary to open client-server environments; financial services and banking sector growth `[ps=4]`
- Best-of-breed object-oriented financial CSS targeting complex accounting environments and open-systems migrations `[ps=3]`
- OO Foundation Class Toolkit: CASE-driven design, FlexiFinancials class libraries, source-level mods, new application development `[ps=3]`
- Phase I: HTML/ISAPI query; Phase II (planned): ActiveX/DCOM distributed component apps `[ps=2]`
- Unique deep IBM integration via DRDA, CAE, DDCS, DARIs; optimized DB2 access on all hardware platforms `[ps=2]`
- Aberdeen believes Flexi's success in Windows NT market will continue as Microsoft moves Internet-enabling technologies into Windows NT Server mainstream `[ps=2]`
- OOT-based CSS suppliers best positioned for Internet/Intranet distributed component deployment; Flexi among best-prepared for web commerce transition `[ps=2]`
- Aberdeen predicts FlexiInternational will become one of the Financial CSS market leaders in the Enterprise and across the Internet `[ps=1]`
- Direct sales through 8 US offices plus 1 UK office; ~30% of personnel in sales/marketing; pursuing international distributors `[ps=0]`
- ~100% year-over-year in 1995; projected to continue at 100% through FY 1996 `[ps=0]`
- 50% MS SQL Server, 30% Sybase, 10% IBM DB2, 5% Oracle (+ 5% other) `[ps=0]`
- 300%-500% performance advantage over ODBC-based implementations `[ps=0]`
- Fully object-oriented; 50+ FlexiObjects accessible via API; target of 300+ objects in Release 4 (mid-1997) `[ps=0]`
- Flexi designated as reference client-server financial product for Windows NT BackOffice; one of 150 Worldwide Development Partners out of 25,000 `[ps=0]`
- 3 initial Flexi Industry Partners: Enterprise Systems (hospital materials mgmt), Innovative Computing Corp (transportation/warehousing), Quantra (real estate) `[ps=0]`
- Aberdeen expects FIP program and international distributors to positively impact bottom-line as measurable percentage of revenues in H2 1996 `[ps=0]`
- Windows desktop look-and-feel controls available at base level `[ps=0]`
