# IBM's AS/400 Versus Microsoft's NT Server: The Challenge That Is Not

> Aberdeen Group analyzes Microsoft's challenge to IBM's AS/400 installed base, arguing that the AS/400 with over 350,000 installations will retain its dominance in midrange commercial computing against Microsoft's NT Server (BackOffice). Aberdeen presents four economic and technical reasons why the challenge will fail: higher total cost for NT due to fat-client PCs, lack of match with AS/400 customer culture, absence of proven migration economics, and AS/400 Advanced Series' superior 64-bit RISC capabilities — predicting the debate will be viewed as 'the challenge that was not' by 1997.


_Published 1996, author **Aberdeen Group**, type **product-viewpoint**._


## Top observations

- IBM did add NT Server support options for AS/400 users; but AS/400 users used NT as complementary not replacement; FSIOP line eventually discontinued `[ps=5]`
- Integrated operating environment: easy-to-acquire, -operate, and -maintain; minimal dedicated technical staff needed `[ps=4]`
- Three-fold: 1) lower cost hardware/software platform, 2) more open, 3) direct path to client-server with PC interface `[ps=4]`
- Fewer than 10,000 BackOffice installations running business-critical OLTP applications `[ps=4]`
- 64-bit RISC transition from 48-bit CISC yields 50+% performance improvement; DB2/400 upgraded for distributed OLTP `[ps=4]`
- Aberdeen anticipates NT Server will be supported on AS/400 FSIOP in the future `[ps=4]`
- Production version of SQL Server released June 1995; not yet mature enough for IS executives to stake their job on its robustness `[ps=4]`
- Microsoft must gain SME loyalty as stepping stone to enterprise data center penetration with NT Server `[ps=4]`
- AS/400 base prefers supplier-integrated value; BackOffice requires component assembly — fundamental culture mismatch `[ps=4]`
- Microsoft itself uses AS/400 to run its own business operations; its migration to SAP R/3 on BackOffice will be closely watched `[ps=4]`
- By 1997-1998, Microsoft's focus shifted to Internet/Exchange; direct AS/400 attack program did wind down as Aberdeen predicted `[ps=4]`
- Over 90% of IBM's SME-derived AS/400 revenues come from installed base; IS decision makers do not seriously consider another supplier `[ps=3]`
- Microsoft has not shown AS/400 users economic advantage for 18-24 month multi-million dollar migration to NT `[ps=3]`
- NT Workstation Pentium 133 MHz 24MB: $4,900 (with maintenance) vs IBM 5250 dual-session terminal: $1,940 `[ps=2]`
- Best suited for enterprises with strong Unix/client-server expert IS organizations; not for AS/400-dedicated organizations `[ps=2]`
- Migration from NT Server to Cairo will not be transparent upgrade; will require new hardware and applications `[ps=2]`
- Microsoft shifted focus to Internet strategy (consistent with Gates' 'Road Ahead' and .NET pivot); BackOffice as AS/400 replacement faded from priority by 1997-1998 `[ps=2]`
- NT Workstation fat-client PC ($4,900) vs 5250 terminal ($1,940) creates $2,960 per-seat hardware premium for NT `[ps=2]`
- In 1997 the industry will view the great AS/400-NT Server debate as the challenge-that-was-not `[ps=1]`
- Compaq ProLiant 4500 NT Server TPC-C showed good midrange OLTP performance but TPC-C V3 excluded end-user device costs `[ps=0]`
- Two DEC AlphaServer NT Server TPC-C tests showed excellent price/performance vs Unix; but required Unix front-end processors to multiplex data entry `[ps=0]`
- BackOffice product deliverables estimated to account for approximately $500 million of Microsoft's 1995 revenues `[ps=0]`
- 350,000+ installations; leading midrange commercial computing choice worldwide
- NT Server-based OLTP infrastructure costs $1,700-$2,700 more per deployed end-user device in hardware alone
- If BackOffice requires 2 more full-time IS staff than comparable AS/400 system, hundreds of thousands in additional cost over 5-year lifecycle
