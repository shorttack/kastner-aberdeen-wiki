# IBM's OS/2 Warp Server: The Whole is Greater Than the Sum of the Parts

> Aberdeen Group evaluates IBM's newly released OS/2 Warp Server, arguing it combines the networking strengths of Novell NetWare with the application strengths of Microsoft NT Server plus integrated directory and security services via a DCE-based Directory and Security Server (DSS) add-on. The study contends that OS/2 Warp Server is at least a year ahead of competitors in delivering an integrated, enterprise-wide NOS with objects, distributed directory services, and network security.


_Published 1996, author **Aberdeen Group**, type **product-viewpoint**._


## Top observations

- OS/2 Warp Server integrates file/print/database/application server capabilities in single package; at least 1 year ahead of NetWare 4.x and NT Server 3.5x
- Market share leader for file/print services; lacks stability for integrated database/application server role
- Gaining popularity for database/application servers but lacks stability for full IS department needs
- Lacking SMP at launch; free SMP upgrade entering beta; will allow adding CPUs instead of servers
- DSS with DCE provides first integrated enterprise-wide NOS connecting all platforms; NetWare NDS only brings NetWare servers
- Fast losing market acceptance; lost competitive edge over past year
- NetWare-centric: NDS only connects NetWare 4.x servers; proprietary rather than open
- Beta users pleased with basic product; very enthusiastic about included utilities
- Cairo (successor OS) migration will not be transparent upgrade; will require new hardware and applications like Windows 3.1 to Windows 95 experience
- IBM's plans for OS/2 Warp Server will be successful in 1996; market position will improve
- IBM discontinued OS/2 support December 31, 2006; never achieved mainstream enterprise NOS adoption; lost to Windows NT
- DSS may turn OS/2 Warp Server into industry's first true enterprise-wide NOS connecting all platforms
- Active Directory (Microsoft) dominated enterprise directory market; DSS/DCE never achieved predicted enterprise-wide NOS role
- Oracle7 porting to OS/2 Warp Server for early 1996 shipment; strengthens application availability
- Sybase has ported SQL Server to OS/2 Warp Server platform
- Novell NetWare still market share leader; NT Server gaining in database/application server market; OS/2 Warp positioned as third choice
- Preemptive multitasking allows priority management and eliminates three-finger salute reboot; multithreading provides no-cost performance boost
- Integrated SystemView for OS/2 and NetFinity management; includes software inventory, asset management, performance monitoring, software distribution, and systems alert
- Over past year Aberdeen interviewed scores of LAN managers; management tools topped desired feature list; OS/2 Warp Server management maps well against administrator needs
- Includes TCP/IP, SLIP, PPP and remote LAN access for Internet server platform capability
- IBM will put considerable marketing muscle behind OS/2 Warp Server products
- IBM investment in OS/2 marketing was inadequate; internal IBM sabotage and budget cuts decimated OS/2 marketing; product withdrawn from mass market by 2001
- Unlike proprietary NDS and StreetTalk, DCE enables cross-platform interoperability including IBM mainframes, AS/400, HP, DEC, Sun
- Executives in non-IBM shops looking for NOS for workgroups/departments well advised to include OS/2 Warp Server on short list for 1996
- Btrieve Technologies agreed to make hundreds of applications available on OS/2 Warp Server by mid-1996
