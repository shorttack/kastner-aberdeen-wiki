# IQ Software: Applying the WWW To Reporting Problems


## Short-horizon prescience (3-year / 5-year)

> Aberdeen Group profiles IQ Software Corporation's IQ/LiveWeb product, which applies World Wide Web technologies to enterprise reporting and decision support. The study argues that IQ/LiveWeb's three-tier architecture, object-oriented query capabilities, and Internet/Intranet publishing engine positions IQ Software ahead of competitors in WWW-enabled business intelligence, predicting the product will maintain a leadership position if IQ Software sustains its innovation pace.


_Published 1996, author **Aberdeen Group**, type **product-profile**._


## Top observations

- Three-tier architecture became the standard for web-based enterprise applications and BI tools by 2000-2005; prediction proved accurate `[ps=5]`
- IQ Software acquired by Information Advantage for $65 million in September 1998; did not maintain independent leadership `[ps=5]`
- Users must be able to navigate across heterogeneous databases and share results; links must remain active when documents distributed `[ps=5]`
- WWW-enabled information-driven computing represents the natural evolution toward dynamic enterprise-class on-demand information access `[ps=5]`
- Web-based BI became the dominant delivery model by 2000-2005; all major BI vendors (Cognos, Business Objects, MicroStrategy) shifted to browser-based delivery `[ps=5]`
- Top-notch frame-based reporter; can give multiple views of a query within single report but lacks three-tier architecture `[ps=4]`
- Decision-support implementations grow 3-5x every 18 months; three-tier architecture required to avoid scalability/performance problems `[ps=4]`
- WWW-enabled applications will require sophisticated three-tier architectures; will create a flurry of announcements among suppliers `[ps=4]`
- Two publishing modes: scheduled reporting for production/repetitive users; on-demand printing for time-sensitive non-standard information `[ps=4]`
- System must automatically import metadata, re-import if database schema changes, transform tables/columns into business terms `[ps=4]`
- Successful decision-support implementations grow 3-5x every 18 months; architecture must handle this growth `[ps=4]`
- Successfully competing with frame-based Impromptu and Powerplay against IQ Software; has not yet delivered three-tier WWW architecture `[ps=4]`
- IQ/Vision uses open architecture for OLAP; IQ Software plans to use it as springboard for integrating OLAP and query/reporting tools `[ps=4]`
- IQ Software must maintain current pace of innovation to maintain leadership position in WWW-enabled enterprise reporting `[ps=3]`
- HTML interface works poorly with Microsoft OLE; relatively primitive application development; Phase II IQ/LiveWeb will bypass HTML via browser plug-in `[ps=3]`
- Only solution shipping for both on-demand and scheduled access to corporate data over the Internet as of 1996 `[ps=2]`
- IQ has had a Unix and NT three-tier architecture since 1995; one year of refinement gives it advantage over would-be competitors `[ps=2]`
- CGI is standard mechanism for web servers to communicate with applications; used for on-the-fly HTML translation and report presentation `[ps=2]`
- Phase II slated Q3 1996: IQ/Objects as browser plug-in to bypass HTML limitations and utilize full IQ/Objects on the Web `[ps=2]`
- Unlike Cognos Impromptu objects, IQ/Objects can communicate between objects and pass attributes; delivers multiple views of multiple queries `[ps=1]`
- $21.8 million in calendar 1995; publicly traded company `[ps=0]`
- Approximately 1.5 million users worldwide `[ps=0]`
- $3,995 on Microsoft Windows NT and low-end Unix platforms; $19,995 for high-end Unix servers (HP/UX, Sun Solaris, IBM AIX) `[ps=0]`
- Competitor in frame-based reporting; has not yet delivered three-tier architecture as of 1996 `[ps=0]`
- IQ/LiveWeb supports ODBC access to all major RDBMSs including Oracle, Sybase, Informix, DB2 family, Red Brick, Progress `[ps=0]`
