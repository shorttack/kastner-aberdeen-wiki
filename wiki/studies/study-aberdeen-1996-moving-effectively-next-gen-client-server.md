# Moving Effectively To Next-Generation Client-Server Development


## Short-horizon prescience (3-year / 5-year)

- **3-year verdict:** high — 3y Rule A: mean=3.67 over 30 usable obs (0 prefiltered, 0 pending) -> high [high>=3.5, medium>=2.0].
- **5-year verdict:** medium — 5y Rule A: mean=3.40 over 30 usable obs (0 prefiltered, 0 pending) -> medium [high>=3.5, medium>=2.0].

> Aberdeen Group white paper, sponsored by Gupta Technologies, argues that first-generation client-server application development environments (CADEs) such as Visual Basic and PowerBuilder are 'topping out' and recommends immediate adoption of next-generation CADEs. The study provides an evaluation framework for next-generation CADE selection and positions Gupta's Centura product as the leading choice for organizations migrating from first-generation toolsets.


_Published 1996, author **Aberdeen Group**, type **white-paper**._


## Top observations

- Visual Basic, PowerBuilder, Delphi, SQLWindows; best for departmental/simple/client-centric apps not needing scale `[ps=5]`
- PowerBuilder adopted by Sybase but never achieved full-featured repository; Visual Basic evolved to VB.NET (2002) with significant breaking changes; both tools lost significant market share to Java and C# as Aberdeen predicted `[ps=5]`
- 3-tier architecture became the standard enterprise application pattern throughout the late 1990s and 2000s, exactly as Aberdeen predicted; web tier, application server, database tier became ubiquitous `[ps=5]`
- Most popular first-gen CADEs are Microsoft Visual Basic and Sybase/Powersoft PowerBuilder; major users in many cases contemplating new toolsets `[ps=4]`
- Sybase/Powersoft committed to using repository from recently acquired company; delivery date not yet clear; use for next-gen technology even further off `[ps=4]`
- First-gen CADEs provide little application partitioning, query optimization, or load balancing; applications slow drastically as users/database size increase `[ps=4]`
- In short to medium term, users may have serious concerns about VB/PowerBuilder shops' ability to solve first-gen problems without bringing in new toolset `[ps=4]`
- Gupta renamed to Centura Software (1995); passed through investors (Warp Technology Holdings 2005, Unify Corporation 2006, renamed back to Gupta Technologies 2012); acquired by OpenText 2015; Centura did not become dominant next-gen CADE `[ps=4]`
- Java EE (1999) and Microsoft .NET (2002) provided enterprise-scale application development frameworks that made the CADE category largely obsolete; Aberdeen's CADE evaluation framework was correct but the winner was not Centura `[ps=4]`
- 6-7 times growth in database size over 18 months in many data warehouse cases; requires next-gen CADE scalability `[ps=3]`
- TI-Microsoft initiative shows no signs of finishing; only fruit is TI's administrator-intensive departmental Arranger; Microsoft shows no intention of targeting fully-featured high-end development `[ps=3]`
- Internet QuickObjects for Web-enabled SQL data access; Centura Web Data Server replicates data from multiple databases with firewall security; Java compilation planned for subsequent release `[ps=3]`
- First-gen CADEs provide little software for scaling development process or automating unfamiliar tasks for training; communication problems increase as square of programmer count `[ps=3]`
- Absence of automated deployment/maintenance software requires physical installation at each site, local admin burden, repeated redeployment on upgrades `[ps=3]`
- First-gen CADEs lack repositories and application-repartitioning GUIs for adapting to 3-tier and Intranet architectures `[ps=3]`
- Complex/data-intensive applications require reversion to 4GL or 3GL scripting; most productivity gains lost for large applications `[ps=3]`
- Version control, project management, regression testing; Centura: Team Object Manager + Team Object Repository + integrated PVCS version control `[ps=3]`
- Client-server partition via drag-and-drop VPE; Centura Application Server targeted at 2-tier and 3-tier partitioning `[ps=3]`
- Design (Rational Rose/LogicWorks ERWin links), programming/testing (debugger, incremental compiler), deployment (repository-based), maintenance (SQLConsole integration) `[ps=3]`
- Centura Data Model Viewer for business modeling; reverse engineering of schemas from modeler, CASE tools, or RDBMS metadata `[ps=3]`
- Average start-to-ship development speed improvement ~35% after 1+ year learning curve, per fragmentary studies cited by Aberdeen `[ps=3]`
- Gupta Centura, Symantec, Unify, Compuware Uniface; appropriate for scaling up existing first-gen applications and new moderate-scale development `[ps=3]`
- Oracle, Sybase, Informix, CA-Ingres, Progress CADEs; useful for installed RDBMS base for upgrading from 4GL and data-intensive applications `[ps=3]`
- Beta testing in 2Q96; provides drag-and-drop application partitioning across 2-tier and 3-tier architectures; supports DCE, TCP/IP, Network OLE communications `[ps=2]`
- Full-featured object-oriented repository; Team Object Repository on standard RDBMSs; open to Oracle and Sybase metadata; key differentiator vs. Visual Basic and PowerBuilder `[ps=2]`
