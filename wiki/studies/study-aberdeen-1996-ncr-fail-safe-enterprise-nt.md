# NCR: Finally a Fail-Safe Choice For Enterprise NT


## Short-horizon prescience (3-year / 5-year)

- **3-year verdict:** medium — 3y Rule A: mean=3.35 over 20 usable obs (0 prefiltered, 0 pending) -> medium [high>=3.5, medium>=2.0].
- **5-year verdict:** medium — 5y Rule A: mean=3.20 over 20 usable obs (0 prefiltered, 0 pending) -> medium [high>=3.5, medium>=2.0].

> Aberdeen Group evaluates NCR's Windows NT Server products for mission-critical OLTP applications based on user interviews with early adopters. The study finds that NCR's LifeKeeper, TOP END, and WorldMark servers address NT's enterprise weaknesses in reliability, scalability, and manageability. Aberdeen concludes that NCR has delivered on its 1994 promise and is a 'fail-safe choice' for NT-based OLTP deployment in retail, finance, telecom, and transportation industries.


_Published 1996, author **Aberdeen Group**, type **market-study**._


## Top observations

- RAS-augmentation: add enterprise-grade HA/clustering/TP-monitor on top of NT `[ps=4]`
- Redirects client transactions around failed servers, apps, or network nodes `[ps=4]`
- Microsoft SQL Server 6.5 on NT up to 90% less costly than Unix/OpenVMS/MVS RDBMS alternatives `[ps=4]`
- NCR/Teradata became leading enterprise data warehouse platform in late 1990s; NT-based data marts proliferated broadly as predicted `[ps=4]`
- IT decision makers primary motivation: NT enables faster competitive response than legacy mainframe `[ps=4]`
- IS decision makers sought single standard OS platform across hardware; reduced management complexity `[ps=4]`
- Windows NT Server 4.0 Enterprise Edition (Sept 1997) supported 8-way SMP clustering; SQL Server 7.0 (1998) supported 8+ CPUs `[ps=3]`
- Business-line managers wanted OLTP on NT to align with desktop Windows; reduced training, OLE object reuse `[ps=3]`
- NCR became major Microsoft partner for enterprise solutions; Teradata/NT integration was commercially successful through late 1990s `[ps=3]`
- NT/SQL Server to scale to 8 CPUs with NT Server 4.0 (fall 1996); 12-16 CPUs by mid-1997 `[ps=2]`
- NCR to provide NT-based data mart solutions starting with NT Server 4.0; data-mart-up/down routing to Teradata `[ps=2]`
- NCR is an 'experienced, fail-safe choice for NT-based OLTP application deployments' `[ps=2]`
- NCR LifeKeeper/TOP END enabled IS to commit to enterprise-grade SLAs, including external customer-facing guarantees `[ps=2]`
- Automatic failover in 2 seconds to 5 minutes; up to 3-node NT cluster `[ps=0]`
- 20-25% reduction in OLTP application deployment time; some sites reported 50% `[ps=0]`
- NCR to introduce SMP Utilization Manager for NT in 1996 for 16-way WorldMark systems `[ps=0]`
- NCR delivered SMP management tools; absorbed into later Teradata and NT product lines; specific 'Utilization Manager' branding not widely documented post-1997 `[ps=0]`
- August 1994: AT&T GIS announced plan to bring NT into enterprise with scalability, manageability, reliability, serviceability features `[ps=0]`
- Aberdeen predicts NCR will become one of select Microsoft Authorized Consulting Partners for NT `[ps=0]`
- Primary: retail, finance, telecommunications, transportation `[ps=0]`
