# Object-Oriented Three-Tier-Plus Computing: Client-Server for Adults

> Aberdeen Group's whitepaper examines the maturation of three-tier client-server computing in 1996, presenting the 'Three-Tier Plus' model that adds MPP/clustered SMP as a fourth tier for data warehousing. The study synthesizes field research from Aberdeen consulting assignments showing that organizations implementing 3-Tier architectures achieve four key business outcomes: improved enterprise efficiency, multi-source information access, scalability for emerging technologies, and superior ROI. Aberdeen argues object-oriented programming is critical for partitioning applications across tiers and predicts NT Server will close the gap with Unix on mid-tier within 24 months.


_Published 1996, author **Aberdeen Group**, type **white-paper**._


## Top observations

- Flexible data access from multiple databases; data warehousing; real-time information access across enterprise `[ps=5]`
- NT Server beginning to dominate new LAN server shipments over Novell NetWare `[ps=5]`
- NT Server with NetWare interconnect services beginning to dominate new LAN server shipments over Novell NetWare `[ps=5]`
- OOP became dominant paradigm for enterprise application development by 2000; Java/.NET/C++ standard; prediction fully confirmed `[ps=5]`
- Automate business information flows, improve productivity, add revenue opportunities, cut costs; replace batch mainframe with real-time processes `[ps=4]`
- Graceful evolution to new technologies; investment protection; SMP clustering and board-level upgrades increasingly popular `[ps=4]`
- Traditional 3-Tier + MPP/clustered SMP as fourth-tier for data warehousing and complex query; the 'Plus' in Three-Tier-Plus `[ps=4]`
- Windows NT Server 4.0 (1996) and NT Server 4.0 EE (1997) closed gap with Unix; NT became dominant mid-tier OS for enterprise application servers by 1998-2000 `[ps=4]`
- Hardware, RDBMS platforms now stable, reliable, well-understood; missing pieces from 1992 (OOP tools, TP performance, data replication, network management) now in production `[ps=4]`
- Object technology and application partitioning will be the method for maintaining/modifying modular development environments with fewest resources `[ps=4]`
- As Oracle/Informix port to MPP and prices decline, MPP machines will achieve broader market acceptance as enterprise-class servers `[ps=3]`
- MPP data warehouse systems (Teradata, Netezza, later Amazon Redshift) became mainstream for enterprise analytics by 2000-2005 `[ps=3]`
- Object-oriented programming techniques are critical to 3-Tier: enable application partitioning and deployment across tiers `[ps=3]`
- Microsoft Windows 2000 Server completely displaced Novell NetWare as dominant LAN OS by 2000; Novell market share collapsed from >70% to <10% `[ps=3]`
- We have sufficient evidence for IS executives to proceed with confidence. Technology direction is clearer now. Products are more powerful and less expensive than ever. `[ps=3]`
- Residual value of mainframe software portfolio will continue to decline during second half of 1990s as PCs handle more processing `[ps=2]`
- Approximately 25 million business client workstations shipped worldwide in 1995 `[ps=0]`
- Senior management consensus: productivity, customer satisfaction, revenue enhancement from effective IS strategy; 3-Tier architecture enables this
- Lower cost hardware (PC/LAN/mid-tier); reuse of existing mainframe applications; API bridges to legacy data; rapid application prototyping
- NT-based systems will begin to close sales gap vs Unix for mid-tier application servers within 24 months; will at least equal unit sales in workgroup
- Mainframe installed base shrank but did not disappear; IBM z-series still significant for banking/insurance; client-server/3-tier replaced most new development
- OOP enables modular application development; partitioned components can be maintained/modified with fewest staff resources and shortest time
- Internet browsers will explode 3-Tier information access with additional functionality, ease of use, and network throughput
- Unix 4-to-8-way SMP configurations superior to NT Server for higher-volume transaction processing; NT closing gap
