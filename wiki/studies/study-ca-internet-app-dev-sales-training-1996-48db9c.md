# An Overview of Internet Application Development (CA Sales Training June 1996)

> 'An Overview of Internet Application Development' — Peter S. Kastner presentation to Computer Associates Sales Training, June 1996. Introduces the Internet/intranet stack (thin-client browser, TCP/IP, HTTP, CGI, firewall, RDBMS) and contrasts Internet applications with traditional client-server. Early canonical analyst framing of the Web as an application-delivery platform delivered to a CA sales audience in the Netscape-dominant pre-IE3 era.


_Published 1996, author **Peter S. Kastner**, type **employer-record**._


## Top observations

- CGI was displaced by application servers (Java EE, PHP, Rails, Node, etc.) within a decade; Kastner's implicit pointer to limitations of raw CGI was correct. `[ps=5]`
- Thin-client Web browser (e.g., Netscape); WAN/LAN using TCP/IP; HTTP server; CGI scripts; firewall for enterprise-network privacy; application RDBMS. `[ps=4]`
- CGI positioned as current server-side scripting standard; implicitly foreshadows need for richer application servers. `[ps=4]`
- Web application architecture (server-side app + browser presentation) became the dominant enterprise-app architecture by ~2001 and remains so. Kastner prediction verified. `[ps=4]`
- Client-server: app runs on desktop; data brought from server to desktop; session-oriented (OLTP). Internet: app runs on server(s); presentation by client browser; no concept of a session. `[ps=2]`
- Netscape referenced as the default example browser in a June-1996 CA sales deck — accurate market position at time of writing. `[ps=0]`
- Signed as 'Vice President', Aberdeen Group. `[ps=0]`
- June 1996 Internet app-dev training for CA sales — concrete evidence of the sales-force-education service line named in the 1999 retainer proposal. `[ps=0]`
- Thin-client Web browser as presentation layer enables application architecture that runs on servers and presents via browser — foundational framing for the next decade of enterprise apps.
- Client-server architecture was largely displaced by Web/web-services architecture across enterprise app development by 2005. Kastner's 1996 contrast framing was prescient.
