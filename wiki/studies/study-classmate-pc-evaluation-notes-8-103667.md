> Kastner's detailed hands-on evaluation notes for the Intel Classmate PC (CMPC) — an ultra-mobile education PC — tested both in the United States and at a teacher's college in Jacmel, Haiti where teachers and K-12 students handled the device. Covers install quirks (50Hz/220v international power cable, WLAN activation gating), tutorial guide errata, operational issues (keyboard defaults, 7-inch screen real estate, standby battery), and extensive buggy behavior in the Mythware e-Learning Class v6.0 software. Concludes the hardware is a 'fine, workable device' for small hands, but Windows XP 'in silicon' carries high IT maintenance cost and the software is buggy but promising.


_Published 2008, author **Peter S. Kastner**, type **memoir**._


## Top observations

- The netbook/UMPC market boomed 2007-2011 with Intel Classmate PC, OLPC XO, ASUS Eee PC, and numerous netbooks. By 2012-2013 the market declined as tablets (iPad) and Chromebooks displaced netbooks. Chromebooks achieved dominance in K-12 education by mid-2010s as predicted. `[ps=5]`
- Windows users, especially teachers, find the 'XP Pro in silicon' very familiar; no needed features missing. However, Windows comes with a significant learning curve and high IT maintenance costs. `[ps=4]`
- 'It's not hard to connect the next-generation hardware dots to see a large (and potentially vast) market for this class of mobile Internet devices.' Price per unit will be key to developing-nation success. `[ps=4]`
- Hardware worked as expected but e-Learning Class v6.0 software is buggy, though shows great promise. Functionally v6.0 enables teacher sharing/collaboration in direct, blackboard, and multimedia ways with individuals and classes. `[ps=2]`
- Tested in U.S. and at a teacher's college in Jacmel, Haiti, where teachers and K-12 students handled the CMPC and 'gave it high marks.' `[ps=0]`
- CMPC's small 7-inch screen sometimes hides portions of Windows admin screens (e.g., wireless network setup) — increases administration difficulty. `[ps=0]`
- Install Bug #1: product box shipped with international 50Hz/220V electrical cable only — PC will not charge in the U.S. without user purchasing a 3-plug adapter. `[ps=0]`
- Install Bug #2: CMPC initial boot encountered Microsoft activation; impossible to set up WLAN without first activating Windows from a wired Ethernet connection. `[ps=0]`
- Install Bug #3: speaker volume initial setting is maximum loud — a distraction. `[ps=0]`
- Install Bug #4: Internet Explorer default web site is microsoft.com — 'there ought to be a better landing place.' `[ps=0]`
- Tutorial Guide error 1.1 (page 5): item 5 incorrect — CMPC in wireless mode works fine with wired-Ethernet teacher PC on the same network. `[ps=0]`
- Tutorial Guide error 2.1.2 (page 7): initial login instructions incorrect — typing name+password fails; removing password allows login but creates unprotected user. `[ps=0]`
- Operation Bug #3: Windows default 5-minute standby without warning — CMPC often turns off just before use. Suggest a beep N seconds before standby. `[ps=0]`
- Operation Note #4: NoteTaker hardware and software are slick but rudimentary — a good 'v1.0' starting point. `[ps=0]`
- Operation Bug #5: Power-off battery life only a couple of days even after full charge. 'Too much power leakage during power-off standby?' Doubts student can carry home for weekend and still have standby power Monday. `[ps=0]`
- Operation Issue #6: biggest hurdle is screen real estate — some Windows command screens do not fit into the visible portion; getting to Enter/Next prompt is a hassle. Admin of Classmate is 'problematic.' `[ps=0]`
- e-Learning Class v6.0 Bug #1: Waiting Connection List — each student must be individually accepted; at class start this is a 'big pain' for teacher. Suggest 'Accept All' option. `[ps=0]`
- Class v6.0 Bug #3: Screen Broadcast results in CMPC lockup that Ctrl-Alt-Delete will not remedy. Twice — second time on all-wired LAN. `[ps=0]`
- Class v6.0 Bug #4: could not get Net Movie function to work on any .avi at any bandwidth, including Class v6.0 demo files. Error 'not enough bandwidth' even on wired LAN. Needs a setup wizard. `[ps=0]`
- Class v6.0 Bug #5: clicking anywhere in upper left corner (and sometimes top bar) sent user to Chinese-language Mythware site. Happened often while trying to click top student in list. `[ps=0]`
- Class v6.0 Bug #6: software install problematic — some teacher-oversight features do not work or work inconsistently; tried wireless and wired LANs with different student/teacher PC combinations. `[ps=0]`
- Overall: CMPC is a fine, workable device, especially in small hands of young people. Size, packaging attractive. A complete laptop in a small package — an ultra-mobile PC.
- Install Bug #5: CMPC initial network settings do not find the Internet even when router provides an IP address. Requires running Microsoft's network setup wizard — would add more than an hour per classroom install.
- Operation Bug #1: during login, hitting Enter instead of clicking Accept defaults to 'close'; Class v6.0 runs invisibly; restart fails with 'program already running.' Suggest default = 'connect' not 'close.'
- Operation Bug #2 (2.3.4 Virtual Classroom, page 9): icon color change from black to blue is hard to identify on a 7-inch screen — suggest contrasting colors.
