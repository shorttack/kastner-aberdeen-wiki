# PC Replacements: Lawyers, Auditors, and Common Sense Rules

> Aberdeen InSight arguing that the roughly 50 million Windows 98 / NT 4 corporate PCs still in service by mid-2003 should be accelerated off the desktop. Windows NT 4.x end-of-support (June 30, 2003) and Windows 98/SE (January 16, 2004) expose enterprises to unpatched security risk, auditor scrutiny, and potential negligence claims. Mid-2003 is framed as an auspicious PC replacement window anchored by Windows XP Pro SP1, Server 2003, Office 2003, Intel Springdale, Pentium 4 Hyper-Threading, and Centrino notebooks.


_Published 2003, author **Peter S. Kastner**, type **dct**._


## Top observations

- 50,000,000+ Windows 98 / NT 4 PCs worldwide
- June 30, 2003
- January 16, 2004
- Five-year support window after OS introduction
- W95.Tenrobot — memory-resident file appender on Win 95/98/Me
- Win 98/NT lack facilities to indicate machine has been hacked
- Unpatched corporate desktops = unacceptable IT practice
- Negligence claim risk; reputational risk of 'laughing stock' outcomes
- Windows XP Pro SP1 out and working well — no stability problems
- Server 2003 + Exchange 2003 + SQL Server more efficient users of resources
- Out in a few months; worth evaluating
- Springdale inaugurates 18-month platform/image stability period
- P4 HT now mainstream — better multi-tasking and thread-aware apps
- ~1/3 corporate PC purchases in 2003 will be notebooks; Centrino = long battery life + wireless productivity
- $1,250-$1,400 including Windows XP Pro and Office XP Pro
- ~$2/day over 3-4 years
- Aberdeen itself upgraded its aging PC ecosystem the prior year
- SMBs lacking 24x7 IT should crank up planning for the recession-disrupted PC replacement cycle
- Centrino achieved rapid mainstream adoption: launched March 12 2003; by end of 2003 Centrino-branded notebooks dominated business + premium consumer notebook segments; Intel reported Centrino as core of mobile PC growth through 2005 when Core Duo replaced Pentium M.
- Windows XP became the corporate mainstream desktop OS by mid-2004; Microsoft extended XP support multiple times due to Vista's slow corporate uptake (2007-2009); XP remained dominant enterprise desktop until Windows 7 displacement 2010-2013. Corporate mainstreaming timeline accurately anticipated.
- Ford guarantees parts 5 years; Microsoft supports OS 5 years
