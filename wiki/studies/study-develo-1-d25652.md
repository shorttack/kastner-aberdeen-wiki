> Aberdeen Group's 1998 practice summary covering the application development tools market, assessing IDEs, 4GLs, RAD tools, Java tools, component-based development frameworks, and Internet deployment environments. The report surveys 16 named vendors including Borland/Inprise, IBM, Microsoft, Oracle, Rational, Sybase/Powersoft, and Symantec, evaluating their competitive position and strategic outlook. Four primary market drivers are identified: Internet/Intranet/Extranet development, component production and assembly, distributed-application deployment, and application development modeling and repositories.


_Published 1998, author **Aberdeen Group**, type **other-research**._


## Top observations

- Java being adopted for e-commerce applications distributed application deployment and component development `[ps=5]`
- Java will not replace C++ as primary language within next 2-3 years; will be used for new-application development especially server-side `[ps=5]`
- Dot-com bust 2000-2001 confirmed rapid consolidation; many pure-play Internet tool vendors disappeared or were acquired `[ps=5]`
- Y2K remediation is cutting back time and resources available for new development initiatives `[ps=5]`
- UML is becoming language of choice for OO modeling; most development tool suppliers now supporting and implementing specification `[ps=5]`
- Microsoft has largest number of programmers using its tools and largest third-party ISV ecosystem; will remain key contender `[ps=5]`
- Up to 50% per year for suppliers keeping pace with multi-tier and Internet demands `[ps=4]`
- Up to 10 suppliers can flourish at medium size ($40-300M revenues) in hot toolset markets `[ps=4]`
- Java did gain server dominance but C++ remained primary for performance-critical applications `[ps=4]`
- Microsoft succeeded on client but .NET replaced COM/DCOM; CORBA declined on both tiers `[ps=4]`
- Heavy consolidation expected in Internet development/deployment tool market within next 3 years; startups will be acquired by database/heavy hitters or disappear due to lack of differentiation `[ps=4]`
- Components take twice as long as expected, cost three times more, 3 years for ROI, deliver less than expected when done `[ps=4]`
- Automated testing can reduce application testing cycle and cost by 50-75% compared to manual processes `[ps=4]`
- Delivers excellent technology but struggles with enterprise credibility; JBuilder licensed by Oracle; renaming to Inprise June 1998; will never again compete with Microsoft head-to-head `[ps=4]`
- One of largest and most successful testing solution suppliers; LoadRunner for web/client-server load testing; needs better cross-product integration and common repository `[ps=4]`
- Java Workshop and Java language ownership gives immense market credibility; needs Windows marketplace partnerships; database vendors announcing Java VM inclusion signals Java's growing enterprise importance `[ps=4]`
- Component-based development will be a critical programming technique for next 5-10 years; Java and legacy code expected to provide the largest number of components `[ps=4]`
- IS buyers increasingly looking to development toolsets to implement Intranets and E-commerce; E-commerce is fastest-growing segment of the development-tool market `[ps=4]`
- Frameworks show great potential for development cost savings but presently slow to sell; users view initial solutions as complex and proprietary `[ps=4]`
- Windows NT is the de facto development environment displacing Unix and C regardless of deployment target `[ps=3]`
- Market-leading modeling tool (Rose); SQA and Pure/Atria acquisitions give testing and SCM portfolio; Microsoft relationship gives strategic credibility; needs coherent integration strategy `[ps=3]`
- Financial difficulties obscure broad product suite with loyal customers; PowerBuilder being revamped for component support; must reassure customers of long-term viability `[ps=3]`
- PVCS is undisputed market leader in version control; Intersolv diversifying into Y2K services and data connectivity to reduce PVCS revenue dependence `[ps=3]`
- Indirect channels continue as primary sales source for ADE suppliers; SIs and application providers buy tools for implementation and integration work `[ps=3]`
- Microsoft DCOM will by default become primary means of communications between objects; CORBA will bridge to DCOM on client-side `[ps=2]`
