# Development Tools: 1998 Practice Summary

> Aberdeen Group's 1998 practice summary covering the application development tools market, assessing IDEs, 4GLs, RAD tools, Java tools, component-based development frameworks, and Internet deployment environments. The report surveys 16 named vendors including Borland/Inprise, IBM, Microsoft, Oracle, Rational, Sybase/Powersoft, and Symantec, evaluating their competitive position and strategic outlook. Four primary market drivers are identified: Internet/Intranet/Extranet development, component production and assembly, distributed-application deployment, and application development modeling and repositories.


_Published 1998, author **Aberdeen Group**, type **other-research**._


## Top observations

- $2-3 billion (conservative estimate, includes international sales)
- Up to 50% per year for suppliers keeping pace with multi-tier and Internet demands
- Low: $400-$1000/unit; Mid: $1000-$3000; High: $3000-$30000
- Up to 10 suppliers can flourish at medium size ($40-300M revenues) in hot toolset markets
- Java being adopted for e-commerce applications distributed application deployment and component development
- Java will not replace C++ as primary language within next 2-3 years; will be used for new-application development especially server-side
- Java did gain server dominance but C++ remained primary for performance-critical applications
- Windows NT is the de facto development environment displacing Unix and C regardless of deployment target
- Microsoft DCOM will by default become primary means of communications between objects; CORBA will bridge to DCOM on client-side
- Microsoft succeeded on client but .NET replaced COM/DCOM; CORBA declined on both tiers
- Heavy consolidation expected in Internet development/deployment tool market within next 3 years; startups will be acquired by database/heavy hitters or disappear due to lack of differentiation
- Dot-com bust 2000-2001 confirmed rapid consolidation; many pure-play Internet tool vendors disappeared or were acquired
- Y2K remediation is cutting back time and resources available for new development initiatives
- Components take twice as long as expected, cost three times more, 3 years for ROI, deliver less than expected when done
- Automated testing can reduce application testing cycle and cost by 50-75% compared to manual processes
- UML is becoming language of choice for OO modeling; most development tool suppliers now supporting and implementing specification
- Delivers excellent technology but struggles with enterprise credibility; JBuilder licensed by Oracle; renaming to Inprise June 1998; will never again compete with Microsoft head-to-head
- Microsoft has largest number of programmers using its tools and largest third-party ISV ecosystem; will remain key contender
- Developer/2000 has widest range of scalable application development capabilities available; largest installed base; larger sales force than competitors
- Market-leading modeling tool (Rose); SQA and Pure/Atria acquisitions give testing and SCM portfolio; Microsoft relationship gives strategic credibility; needs coherent integration strategy
- Financial difficulties obscure broad product suite with loyal customers; PowerBuilder being revamped for component support; must reassure customers of long-term viability
- Harmony unification strategy (OO repository + multimedia GUI) to unite disparate products; delivery planned 1999; Jasmine OO database and Opal legacy tool as key development plays
- PVCS is undisputed market leader in version control; Intersolv diversifying into Y2K services and data connectivity to reduce PVCS revenue dependence
- One of largest and most successful testing solution suppliers; LoadRunner for web/client-server load testing; needs better cross-product integration and common repository
- Java Workshop and Java language ownership gives immense market credibility; needs Windows marketplace partnerships; database vendors announcing Java VM inclusion signals Java's growing enterprise importance
