> Verbatim transcript of Informix's Universal Server launch event (Dec 1996, New York). Phil White (CEO) and Mike Stonebraker (CTO, ex-Ingres/Illustra founder) introduce the first commercial object-relational DBMS, integrating DataBlade extensions for text, 2D-spatial, image, video, time-series, and Java types. Stonebraker predicts ORDBMS will replace relational as the mainstream database within a few years. Ed Zander (Sun president) keynotes on the network-computer thesis. Panels of DataBlade partners (FAME, Open Market, MapInfo, Kodak, Excalibur, NEC) and beta customers (GE Information Services, GDE Systems, CS First Boston, CitySearch, Creative Artists Agency) anchor the launch. $8-10B database market, growing 30-50%; 1500+ apps already in production; 29 DataBlades available, 51 more announced; stock up from $17 to $27.50 in two weeks.

## Top observations

- Phil White (CEO): 'Informix redefines database performance, extending it into new dimensions'
- Phil White: 1994 DSA shared-nothing/shared-everything parallelism -> 1996 Universal Server with typed extensions
- Shipped to 20-30 customers Sept 30 1996; general availability today (Dec 1996); 'twelve to eighteen months ahead of anybody in the industry'
- Phil White: $8-10B relational database market; only 15-20% of organizational data is numbers/characters; 70-80% is text/video/spatial/time-series; market growing 30-50%
- Stonebraker: 'object-relational... will replace relational databases as the mainstream database technology over the next few years'
- Object-relational DBMS replaces pure relational as mainstream within 'the next few years' (Stonebraker, 1996)
- [DEFERRED]
- Stonebraker: pure relational works for numbers/character strings but 'laid an egg' for geographic info, mechanical CAD, document imaging, medical imaging
- Stonebraker authored 'Object Relational Databases, The Next Great Wave' ($29.95) summarizing the thesis
- Stonebraker / Mike Saranga began integration work May 1995; Illustra-Informix merger announced Dec 1995
- Phil White: stock $17 two weeks ago -> $27.50 in first 40 min of launch event; ~3M shares traded -- 'Thanks to Michelle from First Boston'
- Database Programming and Design: Illustra Most Influential DB 1995, Informix Most Influential DB 1996 -- 'two consecutive years'
- Zander (Sun president): three industry dislocations -- internet/intranet, bandwidth, Java -- network is the computer
- Sun announced $750 JavaStation thin client ~1 month before Universal Server launch
- Sun and Informix embed JVM in Universal Server for stored procedures and DataBlades
- Sun runs Catalyst ISV program (10,000+ applications) on Universal Server
- Sun and Informix demonstrate Video DataBlade integrated with Sun video servers
- Colton + Simmons: Universal Server completes telecom billing-discount query in 6 sec vs ~60 sec on middleware (~10x faster, 'not even using CORBA')
- Universal Server claimed 10x to 1000x faster than equivalent middleware approaches across workloads
- Colton: middleware approach to ORDBMS is 'like playing chess by US mail' -- multiple round trips between app and DB
- Universal Server in production in 1500+ applications at Dec 1996 launch
- End of December 1996: GA on Sun and SGI; mid-1997: Windows NT and other Unix
- 29 DataBlades available in Dec 1996; 51 additional announced at launch; 30 DataBlade partners demoing at DB Expo; hundreds more in development
- Tandem announced ORDBMS based on DataBlades, shipping 1997
- Bomsie (FAME CTO): TimeIQ DataBlade adds time-series management, stats library, and 4GL on top of Universal Server
