# RDBMS Report Card

> Aberdeen Group evaluates the role of relational database management systems (RDBMS) in enterprise computing, covering their use in OLTP and decision support. The study profiles six leading independent RDBMS vendors—Oracle, Ingres, Sybase, Informix, Software AG, and Progress—against seven functional criteria and produces a best-in-class report card. Aberdeen concludes that RDBMS has become the central application platform for enterprises and that Oracle leads the market while IBM's DB2 trails all competitors.


_Published 1993, author **Peter S. Kastner, John Logan, Thomas Willmott**, type **market-study**._


## Top observations

- Primary software platform for enterprise IS infrastructure; unifies mainframe, midrange, and desktop
- Can support 99.99% of all real-world OLTP applications
- Reduces application development code by up to 35%
- Over $1.2 billion
- Market leader; largest installed base
- First time Oracle demonstrated true technical leadership
- Approximately $250 million
- Aggressive MS-Windows client support; best-in-class client-server dev tools
- $300+ million (public company)
- Challenge Oracle for enterprise-class RDBMS leadership; gateways, replication server, network admin
- Unix RDBMS standard; champion of speed and portability; VAR tool of choice at low end
- 25% of revenues invested in R&D
- $80 million
- Worst-in-class across all platforms (DB2, QS/400, OS/2 Data Manager)
- Oracle best-in-class; none lacking
- Software AG, Informix, Oracle lead; none lacking for 95%+ of applications
- Sybase and Ingres best-in-class; Progress lacking
- Informix and Ingres best; Progress least capable
