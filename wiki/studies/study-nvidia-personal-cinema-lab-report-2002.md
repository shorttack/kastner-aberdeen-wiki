# nVidia Personal Cinema 1.0 — Aberdeen Lab Report

> Aberdeen Group laboratory feedback report to nVidia management on 16 hours of hands-on testing of the Personal Cinema 1.0 kit (Compro GeForce2 MX 400 graphics card with VIVO breakout box) on a Dell 8100 running Windows XP. Evaluates graphics, TV tuner via WinDVR, DVD playback via WinDVD, Ulead Video Wave 4, and Microsoft Movie Maker workflows, and recommends packaging, cabling, and software-install improvements.


_Published 2002, author **Peter S. Kastner**, type **topic-analysis**._


## Top observations

- 16 hours over 3 days in December 2001
- Dell 8100 / P4 1.4 GHz / 384 MB RDRAM / current BIOS / Windows XP
- Easy; did not require metal bar used for ATI Radeon
- Two different connectors poorly labeled; low-contrast tape easily missed
- Use high-contrast or different-color tape; add 90-degree connector at card end
- Required unexpected manual hard reboot before drivers installed correctly
- Comanche 4 and Ghost Recon — default and gamer settings — met ratings
- ~15% of Pentium 4 1.4 GHz
- Excellent analog quality in partial-screen
- Adequate at normal distance; not as satisfying as DVD playback
- Television tab defaults to mono despite repeated stereo selection
- Excellent full-screen video across tested DVDs
- PCfriendly installs software that conflicts with WinDVD; causes dropped frames
- All consumers will click 'yes' on PCfriendly install — high nVidia support-call volume expected
- Documentation and video tours inadequate for new users
- Does not reliably/automatically set up with Personal Cinema; video-configure choices randomly missing
- Ships with every Windows XP PC — nVidia wise to ensure seamless out-of-box Personal Cinema support
- Stereo-receiver configuration was overly ambitious; required hours of debugging and careful volume calibration
- WinDVD install failed because prior ATI WinDVD was not uninstalled first; blank Company field not accepted; '0'/'O' serial-number confusion
- Restart prompt appeared before teletext install completed; 45-minute shutdown hang observed
- No address or phone number for Compro on packaging — all calls presumed to go to nVidia
- High marks for hardware and packaging; software install integration needs improvement
