# Next Steps in SOA: Applications on the Network

> A research preview for a planned 1Q06 Aberdeen benchmark study, the third in an ongoing SOA series, examining application processing on the network as service-oriented architecture blurs the line between network and software infrastructure. Led by analyst Peter S. Kastner, the study will assess which applications suit network processing, benefits for early adopters, the roles of application vs. network architects, and SOA security considerations.
