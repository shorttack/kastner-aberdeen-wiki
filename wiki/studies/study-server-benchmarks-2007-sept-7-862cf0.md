# Intel and AMD Server Benchmarks (September 2007)

> Kastner-authored Excel spreadsheet comparing Intel Xeon 7140M dual-core, Xeon 7350 quad-core, and AMD Opteron 8220se dual-core and Barcelona 8222 across SQL Server database, ERP SAP-SD, Java SPECjbb, Integer SPECint_rate_2006, and SPEC webserver 2005 benchmarks. Includes DP chipset RAS feature comparison for Intel 5000X, 5000P, and 5000V. Primary document of Intel's quad-core lead over AMD's first-generation Barcelona in 2007.


_Published 2007, author **Peter S. Kastner**, type **benchmark**._


## Top observations

- SQL Server database: Intel Xeon 7140M dual = 318,407 (benchmark units).
- SQL Server database: Intel Xeon 7350 quad-core = 407,079 — highest in the comparison.
- SQL Server database: AMD Opteron 8220se dual = 262,989.
- ERP SAP-SD: Intel Xeon 7140M dual = 2,127 SD users.
- ERP SAP-SD: Intel Xeon 7350 quad-core = 3,705 SD users — leads AMD 8220se by 78%.
- ERP SAP-SD: AMD Opteron 8220se dual = 2,078 SD users.
- Java SPECjbb: Intel Xeon 7140M dual = 217,334.
- Java SPECjbb: Intel Xeon 7350 quad-core = 437,412 — ~2x AMD 8220se.
- Java SPECjbb: AMD Opteron 8220se dual = 176,909.
- Integer SPECint_rate_2006: Intel Xeon 7140M dual = 80.6.
- Integer SPECint_rate_2006: Intel Xeon 7350 quad-core = 214 — ~2x AMD 8220se.
- Integer SPECint_rate_2006: AMD Opteron 8220se dual = 108.
- SPEC webserver 2005: Intel Xeon 7140M dual = 18,981.
- SPEC webserver 2005: Intel Xeon 7350 quad-core = 30,261.
- SPEC webserver 2005: AMD Opteron 8220se dual = 22,254.
- Intel 5000X Chipset RAS features: DIMM sparing, Memory RAID, Memory mirroring, x4 SDDC, Memory ECC, HUB interface ECC, DMA.
- Intel 5000P Chipset RAS features: DIMM sparing, Memory RAID, Memory mirroring, x4 SDDC, Memory ECC, HUB interface ECC, DMA (same as 5000X).
- Intel 5000V Chipset RAS features: DIMM sparing, Memory RAID, x4 SDDC, Memory ECC, HUB interface ECC, DMA — no memory mirroring (value-tier).
- Across SQL, SAP-SD, SPECjbb, SPECint_rate_2006, and SPEC webserver 2005, Intel Xeon 7350 quad-core leads AMD Opteron 8220se dual-core on every benchmark — frequently by 1.8x to 2x — signalling Intel's quad-core lead as Barcelona launched.
