# When Does Remote Control Benefit Remote Node Architecture?

> This 1997 Aberdeen Group impact study examines the trade-offs between remote node and remote control architectures for corporate remote access, finding that hybrid deployments combining remote node with remote control software (specifically Traveling Software's LapLink) deliver superior performance. Aberdeen's end-user research identifies five specific deployment conditions where remote control over remote node is advantageous, including mobile user concentrations above 10%, large database access, and frequent software upgrade cycles.


_Published 1997, author **Aberdeen Group (Virginia Brooks)**, type **impact-study**._


## Top observations

- Remote node solutions dominate corporate remote access environments
- Move to remote node sacrifices important benefits provided by remote control
- 28.8 kbps; most remote connections run at this speed
- Large data volumes stream continuously across slow link; clogs remote pipes for bandwidth-intensive apps
- Almost continuous but small traffic flow; only GUIs mouse movements and keystrokes traverse link
- Enables full advantage of corporate desktop horsepower from remote location; computing done at corporate site
- Support personnel can configure fine-tune and update remote devices via remote control; take control to diagnose problems
- Considered secure because users subject to same LAN security; but captured data streams more harmful than screen/mouse captures
- Remote control over remote node provides encryption access control and parameter-setting for heightened security
- 10% or higher concentration of mobile users needing LAN application access when out of office
- Access to large databases and legacy applications from remote locations is required
- Software/systems upgraded every 90-120 days
- IT needs to provide continuous support to remote users
- Data interception by outsiders is a concern
- Traveling Software's LapLink positioned as enabling remote control over remote node hybrid architecture
- Remote control implementation on the rise as business users frustrated with 28.8kbps data streaming
- Remote Desktop Protocol (RDP) and Citrix ICA became dominant enterprise remote access; remote node/dial-up displaced by VPN over broadband by 2003-2005
- LapLink positions as solving core remote access cost/time/experience problems for IT
- Traveling Software renamed Laplink Software circa 2003; active in 2026 as PC migration software vendor; partnerships with Microsoft (2014) and Intel (2022)
- Dial-up remote node (RAS) displaced by IPSec VPN over DSL/cable broadband by 2003; modem-era constraints that justified hybrid approach became irrelevant
