# Eclipsys SunriseXA 3.3 Meets Subsecond Response Time Objective: A Benchmark Audit Report

> An April 2004 Aberdeen Group benchmark audit report on a hospital-workflow simulation benchmark of Eclipsys SunriseXA Release 3.3, conducted March 2–3, 2004, using Mercury LoadRunner to simulate a 6,000-bed peak hospital workload. Aberdeen confirms that nearly all transaction types met subsecond response times, sustained transaction rates exceeded 1,000 per minute, and Eclipsys had successfully resolved response-time issues identified in the prior 2003 release.


_Published 2004, author **Aberdeen Group**, type **benchmark**._
