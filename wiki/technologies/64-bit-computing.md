# 64-bit Computing (general)

> Itanium's biggest selling point and biggest drawback


## Top observations

- Let me make clear that 64-bit computing has been around for quite some time now, and in fact the whole UNIX RISC area already is 64-bit capable. We see it being used particularly for handling large, scalable [data]. — [[study-amd-industry-analyst-visionaries-64bit-2-7a191f]]
- Drivers: declining memory prices, more OS features (security, virtualization), and web-services-driven application growth requiring larger memory footprints — [[study-amd-industry-analyst-visionaries-64bit-2-7a191f]]
- The 64-bit market is dominated by high-end proprietary systems. This will change dramatically over the remainder of the decade. Industry-standard 64-bit architectures will move down to the low-end and up into the mid-range and high-end. — [[study-amd-industry-analyst-visionaries-64bit-2-7a191f]]
- In the next two to three years, one will witness a large set of enterprises going in for 64-bit systems as it offers superior performance in terms of scalability, power and reliability — [[study-amd-industry-analyst-visionaries-64bit-2-7a191f]]
- Transition for pervasive 64-bit computing is going to take some time. The server side is well familiar with this technology; the trick is on a desktop, where this is going to take longer. — [[study-amd-industry-analyst-visionaries-64bit-2-7a191f]]
- I believe that 64-bit technology will bring new and exciting opportunities to the mainstream market. Once you give millions [of users 64-bit, the ecosystem follows]. — [[study-amd-industry-analyst-visionaries-64bit-2-7a191f]]
