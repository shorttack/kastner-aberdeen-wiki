# Apollo Lunar Navigation Software

> Navigation code for the Apollo lunar program; PHI founders Philip Hankins and David Moros had written this code before founding PHI.


## Top observations

- Philip Hankins wrote navigation code for the Apollo lunar program before founding PHI. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- David Moros co-wrote navigation code for Apollo and served as PHI engineering lead; described as dapper, polite, and relentlessly precise. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- PHI's zero-defect culture derived from Apollo: for Apollo programmers, a bug didn't mean a system crash—it meant a spacecraft missing the moon. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
