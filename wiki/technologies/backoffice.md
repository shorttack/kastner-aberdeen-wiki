# Microsoft BackOffice

> BackOffice suite (Exchange, SQL Server, SNA Server, Systems Management Server) central to Microsoft's enterprise pitch. Discontinued as bundle ca. 2002.


## Top observations

- NT and BackOffice require capable partner help for enterprise-class: high transaction rates, high availability, fault tolerance, mainframe connectivity, systems management — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- 'Scant help for executives designing for today's IT projects' — much of Scalability Day demonstrations depended on next year's software — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- Three-fold: 1) lower cost hardware/software platform, 2) more open, 3) direct path to client-server with PC interface — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Fewer than 10,000 BackOffice installations running business-critical OLTP applications — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Microsoft's AS/400 attack program will be relegated to back-burner by 1997; viewed as the 1995 challenge that was not — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Microsoft shifted focus to Internet strategy (consistent with Gates' 'Road Ahead' and .NET pivot); BackOffice as AS/400 replacement faded from priority by 1997-1998 — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- BackOffice product deliverables estimated to account for approximately $500 million of Microsoft's 1995 revenues — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- AS/400 base prefers supplier-integrated value; BackOffice requires component assembly — fundamental culture mismatch — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Microsoft has not shown AS/400 users economic advantage for 18-24 month multi-million dollar migration to NT — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Still needs solving — [[study-aberdeen-1996-risc-unix-market]]
