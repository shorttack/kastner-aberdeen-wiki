# CIS-to-ERP Integration

> Aberdeen identifies CIS-ERP integration as a 'rapidly emerging trend'; proved highly accurate — became a major driver of SAP CRM, Oracle Siebel integration, and eventually the ERP-CRM convergence in cloud suites.


## Top observations

- Rapidly emerging trend; enabling 360-degree customer view by connecting front-office to back-office data — [[study-1997-cis-report-ba825e]]
- CIS-ERP integration became a major enterprise software battleground; SAP mySAP CRM and Oracle's E-Business Suite CRM were built on this premise; integration is now table stakes for all enterprise CRM — [[study-1997-cis-report-ba825e]]
