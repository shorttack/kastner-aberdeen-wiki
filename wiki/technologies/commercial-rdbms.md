# Commercial Relational Database Management Systems

> IBM DB2, Oracle, SQL Server, etc.


## Top observations

- Kastner framing implies that commercial RDBMS market will consolidate to IBM / Oracle / Microsoft dominance over the following 5-10 years. `[ps=5]` — [[study-october-1997-editor-s-buffer-5-771798]]
- By 2010 IBM (DB2), Oracle, and Microsoft SQL Server dominated commercial RDBMS; Sybase acquired by SAP (2010), Informix by IBM (2001), Ingres by CA then independent. Cloud players (AWS RDS, etc.) entered thereafter. `[ps=5]` — [[study-october-1997-editor-s-buffer-5-771798]]
- Tough competition facing database vendors not named IBM, Oracle, or Microsoft. — [[study-october-1997-editor-s-buffer-5-771798]]
