# Core Dump / Hexadecimal Core Dump

> Debugging technique: on catastrophic failure, OS printed entire core memory contents as hex. Could span hundreds of pages. Kastner learned to read these to find program errors.


## Top observations

- Kastner learned to read hexadecimal core dumps to find the 'ghost in the machine'—debugging equivalent of reconstructing a car crash from skid marks. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Catastrophic program failure generated hundreds of pages of raw hexadecimal numbers representing entire core memory contents. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Reading a core dump was like reconstructing a car crash from skid marks—hundreds of pages of raw hex to locate program crash cause and data state. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
