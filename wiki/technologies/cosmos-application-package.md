# Cosmos (Customer Accounting System / CAS)

> Code-generation system at PHI that produced millions of lines of COBOL per specification. Originally called Customer Accounting System (CAS). Named after Creedence Clearwater Revival album 'Cosmos Factory'. Enabled a team of four to build an entire bank checking account system in one year.


## Top observations

- ADL substituted COSMOS-based approach for floundering Chase IT project, conceived by Murray Sherry — [[study-adl-commercial-engagements-kastner-1972-1979-b8b001]]
- Kastner was lead designer and chief programmer of the securities subsystem under TOOS — [[study-adl-commercial-engagements-kastner-1972-1979-b8b001]]
- Mary Ellen 'Mel' Holland — Marine Midland alum and first woman with Columbia MBA — co-developed Chase TOOS customer application — [[study-adl-commercial-engagements-kastner-1972-1979-b8b001]]
- Kastner and Holland produced 25M lines of debugged COBOL ready in under a year using COSMOS — [[study-adl-commercial-engagements-kastner-1972-1979-b8b001]]
- Kastner's COSMOS code at Chase reportedly never caused an application rerun once in production — [[study-adl-commercial-engagements-kastner-1972-1979-b8b001]]
- PHI brochure describes Kastner as 'Systems Analyst with PSD's Financial Systems Group' working on PHI internal accounting and First Chicago correspondent-bank DDA — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- Kastner programmed correspondent-bank DDA system for First Chicago covering 14 correspondents with custom-tailored apps based on run-time parameters and flexible model software in COSMOS — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]
- Kastner involved in Cosmos/CAS code generator development at PHI, 1969-1973. — [[study-volume-1-appendix-career-timeline]]
- Originally called Customer Accounting System (CAS), renamed Cosmos; Creedence Clearwater Revival 'Cosmos Factory' album cover framed on main room wall. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Cosmos generated millions of lines of architecturally sound COBOL code according to specifications—a generator, not a conventional application. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Team of four built an entire bank checking account system using Cosmos in one year. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Working on Cosmos was 'genuinely exciting—the closest I had come so far to the automation dream'—building a machine that built other machines. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- In 1969, most large apps were built by teams writing COBOL by hand one procedure at a time; Cosmos automated this with perfect architectural consistency. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Cosmos allowed PHI to deploy systems at a scale and speed impossible with conventional programming teams; a force multiplier. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
- Cosmos felt like the closest realization of Kastner's childhood automation dream since working in a restaurant bookkeeping room. — [[study-volume-1-ch02-physics-of-the-machine-1969-1972]]
