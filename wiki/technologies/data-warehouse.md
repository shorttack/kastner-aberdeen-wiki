# Data Warehouse / Business Intelligence

> Largest aggregation of data and metadata in enterprise; limitations: performance at large size; query-only; data fiefdom resistance; daily refresh constraint; all major DB suppliers support

- Most enterprises have one or more inconsistent definitions for basic enterprise expression 'revenue' across systems — [[study-aberdeen-1996-enterprise-data-knowledge-integrated-data-marts]]
- Enterprise must work from high-level model and common business metrics before building individual data marts — [[study-aberdeen-1996-enterprise-data-knowledge-integrated-data-marts]]
