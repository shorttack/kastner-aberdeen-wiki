# DataDirect Explorer

> description=Desktop query, analysis, and reporting tool providing Query Builder, Chart Builder, Report Builder, Form Builder, and Job Scheduler components.; lifecycle_note=Explorer desktop product discontinued following Merant restructuring; capabilities partially absorbed into successor BI tooling.; successor_technology=ODBC-compliant BI tools


## Top observations

- Explorer's Chart Builder dynamically links data to a chart and provides users with wizards to help them build charts from 37 available styles. `[ps=3]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- Explorer's Report Builder is a Microsoft OLE 2.0 container that can embed any OLE object within a report and automatically generates sections, headers, and footers. `[ps=0]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- The Explorer Job Scheduler allows users or administrators to script decision-support chores, run queries on different processors at different times, and print reports automatically. `[ps=0]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- Intelligent snapshot, a feature of Explorer, allows the administrator to take a snapshot of, for example, IBM's DB2 RDBMS and save the results as an Oracle table in any ODBC format. `[ps=0]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- The Explorer Administrator is an optional $199 component that allows IS to augment database security, tune desktops per user skill level, define user classes, and apply query governors. `[ps=0]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- Users give strong praise to the Explorer desktop; its prompts and annotation capacity supplement the tool's ability to allow a user to build a query and drill down for additional information. `[ps=0]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- Explorer's Query Builder generates correct SQL and is a powerful vehicle for both general business users and power users. `[ps=0]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
