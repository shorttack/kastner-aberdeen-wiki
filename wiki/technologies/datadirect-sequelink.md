# DataDirect SequeLink

> description=Server-based database-independent middleware for client-server connectivity, enabling heterogeneous joins, cursor management, and legacy integration without performance-degrading gateways.; lifecycle_note=SequeLink product was eventually discontinued after Intersolv/Merant transitions; server-side connectivity approach supplanted by modern middleware.; successor_technology=JDBC/ODBC middleware; modern data integration platforms


## Top observations

- DataDirect SequeLink is a server-based, performance-enhancing, data-access technology that enables the Virtual Data Warehouse to support large user populations without reducing performance. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- On October 23, 1995, Intersolv announced the acquisition of TechGnosis International, a Brussels, Belgium-based developer of SequeLink, for approximately $80 million. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- SequeLink resides between the database source and the client application, links directly to existing networks rather than relying on performance-degrading gateways, and is both database and network independent. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- SequeLink provides cursor management to minimize network traffic caused by SQL calls and data transfer. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- SequeLink supports legacy integration with numerous database systems including both relational and non-relational databases. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- Administrators say they are encouraged by the acquisition of TechGnosis; Intersolv will now evolve the Virtual Data Warehouse into a more robust server-based solution. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- Intersolv plans to use the TechGnosis engine to provide a layer that will enable administrators to add or remove sources and automatically propagate changes to clients. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- SequeLink API is a set of C programming interfaces for developers, allowing programmatic access to the SequeLink middleware. — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
