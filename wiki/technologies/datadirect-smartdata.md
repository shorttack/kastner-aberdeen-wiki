# DataDirect SmartData

> description=Intelligent metadata layer implemented as an ODBC driver that shields users from SQL complexity and creates virtual databases (SmartSets) over physical data sources.; lifecycle_note=Specific SmartData branding discontinued post-merger; metadata management capabilities absorbed into subsequent DataDirect products.; successor_technology=DataDirect ODBC drivers


## Top observations

- SmartData is implemented as an ODBC driver and uses intelligent metadata to create and serve as a common interface for each data source in the Virtual Data Warehouse. `[ps=3]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- Aberdeen believes enterprises will be able to transform many virtually dormant data sources into vital information-delivery vehicles using SmartData technology. `[ps=3]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
- The SmartData Warehouse Manager is a point-and-click tool that allows IS administrators to build a Virtual Data Warehouse by defining columns, constructs, and SmartSets; it also generates semantically correct SQL. `[ps=0]` — [[study-aberdeen-1995-intersolv-virtual-data-warehouse]]
