# DB2 Common Server

> lifecycle_note=Continues as IBM Db2; current versions available for cloud and on-premises; standard_body=IBM; introduced_approx=1993; role=subject


## Top observations

- HP-UX and Sun Solaris; porting in progress to Siemens Nixdorf, Windows NT, and PowerPC `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- major player and strong competitor in the DORS market, especially in the IBM-workstation-server market `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- databases requiring connectivity to other IBM platforms; middle tier of three-tier solutions; medium-to-large-scale data-warehousing; mission-critical OLTP `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- has added functionality to compete on equal technological basis with, and in some cases surpass, other major DORS suppliers `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- multithreading support for SMP scalability matching other major DORS suppliers `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- query rewrite, more alternatives, better non-uniform data distribution detection, pre-fetching, parallel I/O, asynchronous writes `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- parallel backup/restore on tablespace basis; integration with ADSM for mainframe and AS/400 backup `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- IBM RS/6000 HACMP clustering with failover; backup/recovery field-proven over a decade `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- stored procedures, triggers (before/after insert/delete/update), column/table constraints, user-defined functions and data types `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- mainframe/AS/400 connectivity to open servers; large-scale decision-support/data-mart; OLTP on open systems as application servers `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- DB2 is strong competitor in DORS market with high scalability, distributed-database, data-warehouse, open replication, admin tools; especially attractive on departmental/divisional IBM-hardware systems `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- replication technology for data-warehousing; ability to incorporate mainframe and AS/400 in enterprise-scale RDBMS `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- multithreading for SMP scalability, two-phase commit, large/complex data types (video, audio, text, imaging) `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- IBM planned Relational Database Extenders for text, imaging, audio, video; SQL querying of image content by color/shape/pattern; fingerprint analysis `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- IBM shipped DB2 Extenders (text, image, audio, video, XML) through late 1990s-2000s, evolving into DB2 Content Manager and IBM Information Integrator. The multimedia extension concept validated; specific extender products eventually superseded by broader content management. `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- Aberdeen predicted DB2 v2 had achieved functional parity and IS buyers should look at DB2 for distributed open production systems as serious Oracle/Sybase/Informix alternative `[ps=4]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- client-server version of DB2/MVS RDBMS running on RS/6000 (AIX) and OS/2 Warp/Warp Connect `[ps=3]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- OS/2, AIX, Windows NT servers; beta on HP-UX, Solaris, Sinix; DB2 Web server support upcoming `[ps=3]` — [[study-aberdeen-1995-ibm-db2-common-server]]
- CICS, Transarc Encina, Novell Tuxedo; implements X/Open XA API `[ps=3]` — [[study-aberdeen-1995-ibm-db2-common-server]]
