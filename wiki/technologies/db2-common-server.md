## Top observations

- client-server version of DB2/MVS RDBMS running on RS/6000 (AIX) and OS/2 Warp/Warp Connect — [[study-aberdeen-1995-ibm-db2-common-server]]
- HP-UX and Sun Solaris; porting in progress to Siemens Nixdorf, Windows NT, and PowerPC — [[study-aberdeen-1995-ibm-db2-common-server]]
- major player and strong competitor in the DORS market, especially in the IBM-workstation-server market — [[study-aberdeen-1995-ibm-db2-common-server]]
- core DB2 RDBMS plus DataPropagator, DataRefresher, DataJoiner, DataHub, Visualizer, DB2 Parallel Edition — [[study-aberdeen-1995-ibm-db2-common-server]]
- databases requiring connectivity to other IBM platforms; middle tier of three-tier solutions; medium-to-large-scale data-warehousing; mission-critical OLTP — [[study-aberdeen-1995-ibm-db2-common-server]]
- has added functionality to compete on equal technological basis with, and in some cases surpass, other major DORS suppliers — [[study-aberdeen-1995-ibm-db2-common-server]]
- OS/2, AIX, Windows NT servers; beta on HP-UX, Solaris, Sinix; DB2 Web server support upcoming — [[study-aberdeen-1995-ibm-db2-common-server]]
- TCP/IP, SPX/IPX, NetBIOS, SNA LU6.2 (APPC/APPN); interconnection to MVS, OS/400, VSE, VM via DRDA — [[study-aberdeen-1995-ibm-db2-common-server]]
- 10.0 years — [[study-aberdeen-1995-ibm-db2-common-server]]
- 3119.16 tpmC — [[study-aberdeen-1995-ibm-db2-common-server]]
- 349.0 USD/tpmC — [[study-aberdeen-1995-ibm-db2-common-server]]
- multithreading support for SMP scalability matching other major DORS suppliers — [[study-aberdeen-1995-ibm-db2-common-server]]
- query rewrite, more alternatives, better non-uniform data distribution detection, pre-fetching, parallel I/O, asynchronous writes — [[study-aberdeen-1995-ibm-db2-common-server]]
- parallel backup/restore on tablespace basis; integration with ADSM for mainframe and AS/400 backup — [[study-aberdeen-1995-ibm-db2-common-server]]
- two-phase commit across LAN internetworks and IBM hardware including RS/6000, PCs, AS/400 (OS/400), mainframes (MVS) via CICS, Encina, or Tuxedo TP monitors — [[study-aberdeen-1995-ibm-db2-common-server]]
- 1992 ANSI SQL Entry level, plus some Intermediate/Full functions and proposed SQL3 standard — [[study-aberdeen-1995-ibm-db2-common-server]]

- IBM RS/6000 HACMP clustering with failover; backup/recovery field-proven over a decade — [[study-aberdeen-1995-ibm-db2-common-server]]
- DB2 Performance Monitor, Visual Explain, SNMP subagent; database MIB support — [[study-aberdeen-1995-ibm-db2-common-server]]
