# Digital Alpha XL Personal Workstation

> Alpha XL 266/300/366 MHz; 128-bit data path on 300/366; field-upgradeable via daughter card on 266


## Top observations

- Personal Workstations should halve the cost of current low-end Unix workstations while providing superior price/performance; Unix workstation suppliers must cut costs or increase functionality `[ps=5]` — [[study-aberdeen-1996-digitals-personal-workstation-new-markets-channels]]
- Target low-end and mid-range of Unix workstation market with equivalent/superior performance at half the cost; use NT's growing ISV ecosystem as leverage `[ps=4]` — [[study-aberdeen-1996-digitals-personal-workstation-new-markets-channels]]
- 1) Low-cost Unix workstation alternative; 2) Powerful NT-based commercial desktop; runs both PC apps and formerly Unix-only technical apps `[ps=4]` — [[study-aberdeen-1996-digitals-personal-workstation-new-markets-channels]]
- Markets requiring 64-bit processing (GIS data warehousing, complex 3D EDA) will continue on Unix workstations; NT will not challenge 64-bit architectures for several years `[ps=4]` — [[study-aberdeen-1996-digitals-personal-workstation-new-markets-channels]]
- Digital Content and Creation (DCC): Adobe, Softimage, AutoDesk 3D Studio Max, Saros, Looking Glass — high-end publishing, web creation, animation `[ps=3]` — [[study-aberdeen-1996-digitals-personal-workstation-new-markets-channels]]
- Single base chassis with three microprocessor families (Pentium, Pentium Pro, Alpha); economies of scale in manufacturing; field-upgradeable via daughter card `[ps=2]` — [[study-aberdeen-1996-digitals-personal-workstation-new-markets-channels]]
- Digital's VAR program will succeed as real differentiator: common base platform reduces VAR inventory/training costs; promotional margin programs incent VAR adoption `[ps=2]` — [[study-aberdeen-1996-digitals-personal-workstation-new-markets-channels]]
