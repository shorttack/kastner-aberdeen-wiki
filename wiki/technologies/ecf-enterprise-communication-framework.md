# Enterprise Communication Framework (ECF)

> Adopted by HL7 for V3.0; used in PACS/RIS interoperability; component-based middleware approach


## Top observations

- Encapsulates HL7 standard in Enterprise Communicator software objects; eliminates need for app developers to parse raw HL7 `[ps=4]` — [[study-aberdeen-1997-hp-andover-working-group]]
- Industry support and actual standardization development efforts rarely aligned so succinctly in traditionally fragmented healthcare market `[ps=4]` — [[study-aberdeen-1997-hp-andover-working-group]]
- AWG Enterprise Communicators will bring application interoperability closer to reality than ever before `[ps=3]` — [[study-aberdeen-1997-hp-andover-working-group]]
- ECF adopted by HL7 for Version 3.0 standard; published in IEEE Transactions on IT in Biomedicine (1998); used in PACS/RIS interoperability `[ps=3]` — [[study-aberdeen-1997-hp-andover-working-group]]
- Transcends common interoperability interests; two highly influential groups consolidated vision and technical specs for standardization `[ps=2]` — [[study-aberdeen-1997-hp-andover-working-group]]
- ECF commercially available by end-1997; fully embedded in leading healthcare IS supplier applications by 1998 `[ps=1]` — [[study-aberdeen-1997-hp-andover-working-group]]
- Alpha software distributed to core members August 1996; proof-of-concept demo October 1996 — [[study-aberdeen-1997-hp-andover-working-group]]
- Standardization at implementation level via Enterprise Communicator components, not just specification level — [[study-aberdeen-1997-hp-andover-working-group]]
