# Marathon Endurance 4000

> Hardware-based fault-tolerant NT server; ~$24,995; two lock-stepped Pentium Pro CEs + two IOPs; 99.99% uptime; 1.5km fiber separation. Superseded by software-based everRun in 2004.


## Top observations

- 99.99% application uptime — approximately two orders of magnitude improvement over standard NT server — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- $24,995 — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- 4 servers: 2 lock-stepped Computing Elements (CE) + 2 I/O Processors (IOP); all Pentium Pro class — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- Each half connected by optical fiber up to 1.5 kilometers (1 mile) apart — building/campus-scale disaster recovery — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- NT OS and all shrink-wrapped applications unaware of Endurance 4000; no special application versions required — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- Wolfpack or other cluster software can run on Endurance-hardened servers — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- CEs synchronized by memory copy; IOPs synchronized by automatic disk copy when failed component replaced; true continuous processing — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- If Endurance 4000 passes hardware compatibility tests, it will be 'breakaway leader' in the new 'fault-tolerant NT servers and clusters' category — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- Marathon Technologies succeeded; HP announced reseller agreement for Endurance 6200 (successor) in 2000; First Options of Chicago used Marathon for trading apps; Aberdeen analyst Joe Clabby confirmed '5 nines of availability in NT industry' — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- Compaq, Dell, HP, IBM, Micron — major Pentium Pro server platforms tested — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- Endurance 4000 includes port to alert external alarm system upon failure — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- 'Well-architected, affordable, hardware-based solution' that adds value 'as if by magic' to shrink-wrapped applications on standard Intel hardware — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
