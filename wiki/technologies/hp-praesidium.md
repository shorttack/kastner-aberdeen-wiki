# HP Praesidium Security Framework

> Integrated security framework for Intranet/Internet transactions; VirtualVault + Authorization Server + ICF + ImagineCard


## Top observations

- Role-and-rules authorization separating identity from back-end; access by app/server/location/time/roles; HA replication; transforms mechanical ACLs into flexible business-logic `[ps=5]` — [[study-aberdeen-1996-hp-praesidium-family]]
- Modular yet integrated security framework: VirtualVault (trusted gateway) + Authorization Server (business-logic) + ICF (crypto framework) + ImagineCard (authentication); business-logic-driven vs mechanical ACL approach `[ps=4]` — [[study-aberdeen-1996-hp-praesidium-family]]
- IS executives testing small-scale pilot projects between trading partners; point-solutions found inadequate; internal-commerce-networks physically disconnected from corporate network for security `[ps=4]` — [[study-aberdeen-1996-hp-praesidium-family]]
- Prediction verified: enterprise security market consolidated around integrated frameworks; HP Praesidium products were discontinued but the framework concept prevailed — IAM platforms (RSA, IBM Tivoli, Microsoft IAM) and unified security suites became the industry standard by 2005 `[ps=4]` — [[study-aberdeen-1996-hp-praesidium-family]]
- Praesidium could reduce or eliminate $300,000 up-front cost to establish account with third-party CA; enterprises with large transaction volumes can run own secured back-end operations `[ps=4]` — [[study-aberdeen-1996-hp-praesidium-family]]
- Credentials: passwords, smart cards, X.509 certificates, biometrics; ImagineCard for multi-credential; HP integrating diverse credential types including SET and public-key systems `[ps=4]` — [[study-aberdeen-1996-hp-praesidium-family]]
- B1-class trusted gateway isolating web apps from Intranet; roles-based admin; real-time audit; goes beyond firewall protection; shields against internal threats and external `[ps=4]` — [[study-aberdeen-1996-hp-praesidium-family]]
- Aberdeen concludes point-solutions will not work for production-grade enterprise e-commerce; integrated framework required; Praesidium approach will prevail `[ps=2]` — [[study-aberdeen-1996-hp-praesidium-family]]
- HP Praesidium could do for commercial cyber-transactions what vaults did for banks; provides tools for IS executives to secure Intranet and conduct Internet commerce `[ps=2]` — [[study-aberdeen-1996-hp-praesidium-family]]
- ICF resolves national encryption export control impasse; enables per-country crypto policy; protects credentials and message traffic in transit over wire and wireless networks `[ps=2]` — [[study-aberdeen-1996-hp-praesidium-family]]
