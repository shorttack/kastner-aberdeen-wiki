# IBM System/360 Model 65

> Present at both MIT (dedicated development machine with graphics workstation and trackball) and Cornell (main production mainframe). FORTRAN airflow-analysis code written on this machine was still embedded in climate models as late as the 2020s.


## Top observations

- Chase chose IBM 360/65 mainframe for new trust operations system — [[study-adl-commercial-engagements-kastner-1972-1979-b8b001]]
- Once converted, IBM 360/65 processed 174,000 unique securities held by 25,000+ trust clients with combined value over $10 billion (1975 dollars) — [[study-adl-commercial-engagements-kastner-1972-1979-b8b001]]
- CPU time was $360/CPU-hour at PHI; 20 hours equaled Kastner's annual pay; computer time was precious, programmer time was not — [[study-phi-psd-brochure-and-kastner-engagements-1969-1972-b8d001]]

- Operated Cornell's IBM System 360/65 while continuing undergraduate education — [[study-volume-1-about-the-author]]
