# IBM Transaction Processing Facility (TPF)

> High-performance mainframe OS for airline reservations and other ultra-high-volume transaction workloads


## Top observations

- TPF is adept at handling reservations, but adding new applications is problematic. `[ps=4]` — [[study-sabre-s-challenge-fb76f5]]
- For a long time, we have wanted to migrate out of the TPF environment in order to reduce the time to market and cost of building products. We have not figured out a way to do that yet. `[ps=4]` — [[study-sabre-s-challenge-fb76f5]]
- American Airlines SABRE on IBM TPF cited as the high-end TP ceiling case nobody else can yet match `[ps=3]` — [[study-dec-blue-monday-internal-sales-training-dectp-vs-ibm-0021cc]]
- Sabre continues to run core reservations on TPF (now z/TPF) into the 2020s, surrounded by distributed Java/cloud services — exactly the surround strategy described in 1997. Core TPF never fully retired. `[ps=-1]` — [[study-sabre-s-challenge-fb76f5]]
