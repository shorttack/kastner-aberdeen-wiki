# Intel 915 Express / Grantsdale chipset

> Intel desktop chipset for LGA775 Pentium 4 / Celeron D (Jun 2004); integrated GMA 900 graphics, DDR2, PCI Express, HD Audio, ICH6 I/O; paired with Grantsdale-P (915P) and Alderwood (925X)

- The new 915 G/P and 925 X chipsets represent the biggest change in input-output capability in a decade. All of this adds up to significant changes that will positively benefit consumers and corporate users. `[ps=4]` — [[study-technology-news-hardware-intel-ships-gra-47f656]]
- Gartner's Martin Reynolds: This is a major cycle rather than a minor cycle. This is a big cycle and it provides the platform headroom for new processors.
