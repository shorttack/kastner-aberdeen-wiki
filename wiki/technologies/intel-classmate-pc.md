# Intel Classmate PC (CMPC)

> Ultra-mobile education PC; 7-inch screen, Windows XP.


## Top observations

- The netbook/UMPC market boomed 2007-2011 with Intel Classmate PC, OLPC XO, ASUS Eee PC, and numerous netbooks. By 2012-2013 the market declined as tablets (iPad) and Chromebooks displaced netbooks. Chromebooks achieved dominance in K-12 education by mid-2010s as predicted. `[ps=5]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- 'It's not hard to connect the next-generation hardware dots to see a large (and potentially vast) market for this class of mobile Internet devices.' Price per unit will be key to developing-nation success. `[ps=4]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- Tested in U.S. and at a teacher's college in Jacmel, Haiti, where teachers and K-12 students handled the CMPC and 'gave it high marks.' `[ps=0]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- CMPC's small 7-inch screen sometimes hides portions of Windows admin screens (e.g., wireless network setup) — increases administration difficulty. `[ps=0]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- Install Bug #1: product box shipped with international 50Hz/220V electrical cable only — PC will not charge in the U.S. without user purchasing a 3-plug adapter. `[ps=0]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- Install Bug #3: speaker volume initial setting is maximum loud — a distraction. `[ps=0]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- Install Bug #4: Internet Explorer default web site is microsoft.com — 'there ought to be a better landing place.' `[ps=0]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- Operation Bug #5: Power-off battery life only a couple of days even after full charge. 'Too much power leakage during power-off standby?' Doubts student can carry home for weekend and still have standby power Monday. `[ps=0]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- Operation Issue #6: biggest hurdle is screen real estate — some Windows command screens do not fit into the visible portion; getting to Enter/Next prompt is a hassle. Admin of Classmate is 'problematic.' `[ps=0]` — [[study-classmate-pc-evaluation-notes-8-103667]]
- Overall: CMPC is a fine, workable device, especially in small hands of young people. Size, packaging attractive. A complete laptop in a small package — an ultra-mobile PC. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Operation Bug #2 (2.3.4 Virtual Classroom, page 9): icon color change from black to blue is hard to identify on a 7-inch screen — suggest contrasting colors. — [[study-classmate-pc-evaluation-notes-8-103667]]
