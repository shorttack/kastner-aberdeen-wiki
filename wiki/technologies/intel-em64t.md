# Intel EM64T (64-bit extensions)

> x86-64 extensions on Xeon and Pentium 4; 4GB memory ceiling on P4, 16GB on Xeon; uncompromised 32-bit performance; simultaneous 32- & 64-bit application execution.


## Top observations

- Intel did not ship x86-64 (EM64T/Intel 64) in volume until mid-2004 (Nocona Xeon) and 2005 desktop (Pentium 4 6xx) — corroborates AMD-early thesis since even the dominant x86 vendor held back 12-24 months `[ps=5]` — [[study-dct-memoir-athlon-64-prescience-2003]]
- Windows XP x64 Edition shipped April 25, 2005, approximately on target with the 2004 prediction timeframe. This was based on the Nocona (Xeon EM64T) platform launched June 2004. `[ps=5]` — [[study-dell-precision-workstations-3-581e89]]
- Broad 64-bit enablement begins with Windows XP 64-bit; application vendors continue delivering 64-bit apps throughout 2005. `[ps=4]` — [[study-dell-precision-workstations-3-581e89]]
- Q2 2004 launch: Xeon & P4 with EM64T; Linux 64-bit OS; Linux 64 device drivers. `[ps=0]` — [[study-dell-precision-workstations-3-581e89]]
- Xeon platforms: 16 GB; P4 platforms: full 4 GB. `[ps=0]` — [[study-dell-precision-workstations-3-581e89]]
- Windows XP 64-bit OS and drivers expected Q1 2005. — [[study-dell-precision-workstations-3-581e89]]
- Uncompromised 32-bit performance with simultaneous 32- & 64-bit application execution. — [[study-dell-precision-workstations-3-581e89]]
