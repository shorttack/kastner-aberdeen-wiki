# LDAP (Lightweight Directory Access Protocol)

> Aberdeen predicts all proprietary directories headed for extinction as LDAP becomes entrenched; Internet directory standard; core of public infrastructure; security and management backbone.


## Top observations

- Developed at University of Michigan as X.500 directory client; adopted as standard by major networking vendors in 1996; slated as core NT Server 5.0 directory technology `[ps=5]` — [[study-aberdeen-1996-microsoft-windows-nt-server-40]]
- Windows 2000 Server (released February 2000) shipped with Active Directory using LDAP as core directory technology as Aberdeen predicted `[ps=5]` — [[study-aberdeen-1996-microsoft-windows-nt-server-40]]
- Active Directory (Microsoft) and OpenLDAP became foundational enterprise infrastructure; directory-guided IT materialized `[ps=4]` — [[study-1999-aberdeengroup-newsletter-april-1999-d157ec]]
- Based on LDAP; models user/resource mappings; supports charging for resource access `[ps=3]` — [[study-netcompute-e6c378]]
- Most if not all proprietary directories headed for extinction as LDAP becomes entrenched; even LDAP-capable proprietary directories will need to become fully interchangeable `[ps=2]` — [[study-intern~1-45df51]]
- Deferred verification of LDAP dominance prediction. `[ps=0]` — [[study-intern~1-45df51]]
