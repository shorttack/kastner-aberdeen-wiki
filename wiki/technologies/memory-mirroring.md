# Memory Mirroring/Sparing/Scrubbing

> Mainframe-class memory RAS migrating to IA servers.


## Top observations

- Mainframe RAS features (memory mirroring, memory sparing, memory scrubbing) did migrate to industry-standard server platforms 2004-2006. Intel's Xeon MP platforms incorporated these features. HP's Superdome and IBM's x3950 added advanced RAS features to x86 servers by 2005-2006. `[ps=5]` — [[study-planningforemergingindustry-6-40decb]]
- Aberdeen expects mainframe-class memory technologies (memory mirroring, spare memory, memory scrubbing) to migrate from high-end Itanium 2 down to multiprocessor and volume servers in 2004. `[ps=4]` — [[study-planningforemergingindustry-6-40decb]]
