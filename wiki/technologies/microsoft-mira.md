# Microsoft Mira (Smart Display)

> Smart Display category killed in 2003; refuted prediction.


## Top observations

- Microsoft Mira shipped January 2003 as 'Windows Powered Smart Display'; commercial failure — Microsoft killed the category by early 2004 due to high price, poor battery life, Wi-Fi range limits, and Windows XP Pro-only compatibility. Functionality eventually resurfaced in tablets + wireless KVM + Remote Desktop on mobile, not in Mira's form factor. `[ps=5]` — [[study-dct-microsoft-homestation-notes-2002]]
- $300-$400 remote controller and lightweight Internet browser `[ps=3]` — [[study-dct-microsoft-homestation-notes-2002]]
- $79 remote ties PC to stereo, TV, and HomeStation (mostly the latter) `[ps=0]` — [[study-dct-microsoft-homestation-notes-2002]]
- Listed in Sony home product vision `[ps=0]` — [[study-dct-sony-personal-electronic-vision-2002]]
- Kastner 2002-2003 DCT commentary treated Mira as the first credible kitchen-screen form factor. — [[study-dct-memoir-ramp-vs-dct-prescience-2026]]
- Microsoft killed Smart Display in 2003; category did not return until iPad and Windows 8 tablets in 2010-2012. — [[study-dct-memoir-ramp-vs-dct-prescience-2026]]
