# Midrange Server

> Core subject; scaled from 1-1000 users; exceeds IBM ES/9000 in tech capability and reliability by 1993


## Top observations

- Midrange servers exceed IBM ES/9000 in technological capability and systems reliability — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- 1 to 1,000 active concurrent users; economical from single-employee brokerage to large datacenter — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- 50% average cost reduction in acquisition, maintenance, and support; application development up to 80% less costly — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- Midrange servers provide greater functionality in security, data integrity, availability than either mainframes or PC LANs — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- Three-tier-plus (client + distributed midrange + central production + analytical) is most successful distributed architecture — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- Today's midrange servers can be remotely backed up, applications propagated, batch scheduled, and crashes recovered without on-site operators — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- Users connected to midrange server hub have interoperable access to mainframes, PC users, databases worldwide including public data networks — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- Three classes of midrange servers will be chief building blocks: datacenter application servers, gateway servers, distributed production servers — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- [UNVERIFIED] — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- Surround strategy: mainframe as data repository while new OLTP and decision support apps developed on midrange; preserves investment and retrains staff — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- One significant cost component increased by migrating to distributed midrange servers: network management — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
- Distributed midrange server strategy is best match between technology and enterprise production computing requirements — [[study-nti-11-distributed-midrange-servers-1993-dedd19]]
