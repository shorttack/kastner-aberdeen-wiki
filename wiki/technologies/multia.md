# Digital Multia (Universal Client)

> Compact all-in-one enterprise desktop; photo-album footprint; discontinued ~1997


## Top observations

- IS admins can remotely configure desktops, control application availability, enable/disable hardware (e.g., floppy), schedule software updates, distribute software `[ps=5]` — [[study-aberdeen-1995-digital-multia]]
- Administrators can remotely manage downed desktops, obtain system configuration info, schedule software updates, and perform software distribution `[ps=5]` — [[study-aberdeen-1995-digital-multia]]
- IS management challenge: compromised corporate data security from lax distributed computing data management `[ps=5]` — [[study-aberdeen-1995-digital-multia]]
- Multia product line discontinued approximately 1997; Alpha processor line discontinued 2004 following HP acquisition of DEC via Compaq `[ps=5]` — [[study-aberdeen-1995-digital-multia]]
- Digital Equipment Corporation acquired by Compaq in 1998 for approximately $9.6 billion; Multia and Alpha product lines eventually discontinued `[ps=5]` — [[study-aberdeen-1995-digital-multia]]
- Failed: Digital was acquired by Compaq for $9.6B in June 1998; Multia product line discontinued ~1997 before acquisition; DEC never achieved enterprise client market leadership `[ps=5]` — [[study-aberdeen-1995-digital-multia]]
- IS management and support costs will decrease; fewer remote site administrators required `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- End-user efficiency increases because systems are made more available through central IS management `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- Single desktop device provides simultaneous access to mainframes, Unix servers, PC servers, and the World Wide Web via icon clicks `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- IS administrators can remotely enable or disable floppy drive; important for government and financial security `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- IS management challenge: hardware and software inventory redundancy `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- IS management challenge: Tower-of-Babel inter-company communications from lack of standardization `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- Aberdeen predicts the universal client concept (single desktop accessing mainframe, Unix, NT, Web simultaneously) addresses an IS market need that will drive purchasing `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- Concept validated but implementation shifted: thin clients (Sun Ray, Wyse, Citrix/RDP) and eventually VDI/virtual desktops became the enterprise answer to universal access, not hardware-integrated desktops `[ps=4]` — [[study-aberdeen-1995-digital-multia]]
- Organizations requiring turn-key access to multiple server types: multiple transports, diverse apps (Windows, Unix X, VT, 3270), and centralized IS configuration management `[ps=3]` — [[study-aberdeen-1995-digital-multia]]
- Unverifiable at product level: Multia discontinued ~1997; DEC acquired by Compaq 1998. Thin-client concept (which Multia anticipated) was validated by Oracle NC and Windows Terminal Server `[ps=3]` — [[study-aberdeen-1995-digital-multia]]
- turn-key universal enterprise client desktop; NOT positioned as a personal computer `[ps=2]` — [[study-aberdeen-1995-digital-multia]]
- ZIF socket design allows processor upgrades as new architectures become available `[ps=2]` — [[study-aberdeen-1995-digital-multia]]
- DIY assembly of equivalent third-party emulators and protocols would be less stable and less robust than integrated Multia `[ps=2]` — [[study-aberdeen-1995-digital-multia]]
- Digital is the only computer supplier that has listened to and acted on IS enterprise client requirements `[ps=1]` — [[study-aberdeen-1995-digital-multia]]
