# Mythware e-Learning Class v6.0

> Teacher classroom-management/broadcast software bundled with CMPC.


## Top observations

- Hardware worked as expected but e-Learning Class v6.0 software is buggy, though shows great promise. Functionally v6.0 enables teacher sharing/collaboration in direct, blackboard, and multimedia ways with individuals and classes. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Tutorial Guide error 1.1 (page 5): item 5 incorrect — CMPC in wireless mode works fine with wired-Ethernet teacher PC on the same network. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Tutorial Guide error 2.1.2 (page 7): initial login instructions incorrect — typing name+password fails; removing password allows login but creates unprotected user. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Operation Bug #1: during login, hitting Enter instead of clicking Accept defaults to 'close'; Class v6.0 runs invisibly; restart fails with 'program already running.' Suggest default = 'connect' not 'close.' — [[study-classmate-pc-evaluation-notes-8-103667]]
- e-Learning Class v6.0 Bug #1: Waiting Connection List — each student must be individually accepted; at class start this is a 'big pain' for teacher. Suggest 'Accept All' option. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Class v6.0 Bug #2 (4.1 Monitor, page 16): program crashed first two times (mixed wired/wireless LAN); third attempt on all-wired LAN. Cannot evaluate function. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Class v6.0 Bug #3: Screen Broadcast results in CMPC lockup that Ctrl-Alt-Delete will not remedy. Twice — second time on all-wired LAN. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Class v6.0 Bug #4: could not get Net Movie function to work on any .avi at any bandwidth, including Class v6.0 demo files. Error 'not enough bandwidth' even on wired LAN. Needs a setup wizard. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Class v6.0 Bug #5: clicking anywhere in upper left corner (and sometimes top bar) sent user to Chinese-language Mythware site. Happened often while trying to click top student in list. — [[study-classmate-pc-evaluation-notes-8-103667]]
- Class v6.0 Bug #6: software install problematic — some teacher-oversight features do not work or work inconsistently; tried wireless and wired LANs with different student/teacher PC combinations. — [[study-classmate-pc-evaluation-notes-8-103667]]
