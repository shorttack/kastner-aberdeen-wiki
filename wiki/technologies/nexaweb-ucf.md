# Nexaweb Universal Client Framework (UCF)

> Framework choosing Ajax or Java client at deploy time


## Top observations

- UCF and similar multi-runtime frameworks lost relevance as HTML5/JavaScript SPAs unified the client, and Java applets/WebStart deprecated; Nexaweb ceased 2012. `[ps=5]` — [[study-nexaweb-announces-ucf-nexaweb-dev-center-6b97d4]]
- Nexaweb ceased operating by 2012; UCF and the Nexaweb EW2.0 platform were discontinued as HTML5 and SPA frameworks unified client development. `[ps=4]` — [[study-outlook-series-david-mcfarlane-nexaweb-p-1dd1b4]]
- Nexaweb's Platform 4.5 will deliver a rich, cross-platform experience that improves user productivity while retaining the best of legacy IT assets. `[ps=3]` — [[study-outlook-series-david-mcfarlane-nexaweb-p-1dd1b4]]
- Nexaweb launched the industry-first Universal Client Framework — zero-install, lets developers use Ajax or Java technology to deploy enterprise-class composite apps over the Web. `[ps=2]` — [[study-nexaweb-announces-ucf-nexaweb-dev-center-6b97d4]]
- UCF allows enterprise developers to deploy using an Ajax- or Java-client based on business objectives; both clients download in seconds to a standard browser and cache on-demand. `[ps=2]` — [[study-nexaweb-announces-ucf-nexaweb-dev-center-6b97d4]]
- Implicit in Kastner endorsement: universal-client frameworks (write-once-deploy-many-runtimes) will be a durable enterprise-RIA strategy. `[ps=2]` — [[study-nexaweb-announces-ucf-nexaweb-dev-center-6b97d4]]
- Nexaweb Platform 4.5 (UCF + Internet Messaging Bus + Enterprise Data Services) generally available; adds Section 508 accessibility via Java accessibility package; enhanced SOAP/REST web-services support. `[ps=0]` — [[study-outlook-series-david-mcfarlane-nexaweb-p-1dd1b4]]
- There is a monumental application development and modernization movement happening across the global IT community; users demand richer experience and businesses face intense pressure to extend legacy apps by migrating to Web infrastructure. — [[study-nexaweb-announces-ucf-nexaweb-dev-center-6b97d4]]
- Aberdeen's research has found that composite applications can be built and implemented with Web services and SOA standards even if the organization has yet to fully develop an SOA. — [[study-outlook-series-david-mcfarlane-nexaweb-p-1dd1b4]]
- Nexaweb has successfully identified SOA, Web services, database integration, and rich Internet application capabilities provided by Ajax, Java, and .NET as key focus areas for its new Platform 4.5 release. — [[study-outlook-series-david-mcfarlane-nexaweb-p-1dd1b4]]
