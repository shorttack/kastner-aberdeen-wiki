# Microsoft Windows NT Server 4.0

> Kastner's Aberdeen had called NT Server 4.0 'a giant step forward' in July 1996; this study questions enterprise enterprise-class readiness.


## Top observations

- Aberdeen: NT jumped from workgroup to departmental (~250 users) by Nov 1995; NT Server 4.0 'a giant step forward' July 1996 `[ps=4]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- NT scalability will improve; many world's applications are now NT-capable but enterprise high-end requires Unix/AS400/mainframe for now `[ps=4]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- Windows 2000/2003 substantially improved enterprise scalability; NT Server licenses grew 50% faster than competitors in 1998 per IDC; Windows eventually captured server market share from Unix but Unix/Linux maintained enterprise high-end into 2000s; Linux won server market by 2010s `[ps=4]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- Microsoft pursuing 'all-Microsoft solutions' strategy from desktop to enterprise despite partner dependencies; schizophrenic about partnering `[ps=4]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- Microsoft corporate policy: will not modify NT Server for any hardware manufacturer — NT must be NT regardless of platform `[ps=4]` — [[study-aberdeen-1997-as400-nt-server-ibm-microsoft-working-together]]
- 'Any business of any size can now run its enterprise applications on Microsoft software and industry-standard hardware' — Bill Gates at Scalability Day, New York `[ps=3]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- Unstated reason for Scalability Day: address continuing NT scalability debacles where line-of-business projects push NT beyond real-world capabilities `[ps=3]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- NT will be 'better in 1998 than it is now' but remains best suited to departmental applications; unable to scale to Fortune 500 enterprise loads in mid-1997 `[ps=3]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- Scalability Day demonstrations will 'distance the company even further from scalability reality' and 'open up a hard-to-close trust gap' `[ps=3]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- NT Server not as tightly integrated with OS/400 as LAN Server/400 and NetWare; requires own operator console; cannot use AS/400 console `[ps=3]` — [[study-aberdeen-1997-as400-nt-server-ibm-microsoft-working-together]]
- Aberdeen had 'considerable difficulty finding sites with more than a few hundred users' on NT `[ps=2]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- Intel microprocessor performance improvements given 'scant credit' for NT scalability at Scalability Day `[ps=0]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- 'Let's not be distracted by marketing hype from reality — or caught by the Big Lie' `[ps=0]` — [[study-1997-microsoft-nt-scalability-day--the-e-6460e2]]
- NT Server 4.0 scheduled for general availability on AS/400 Integrated PC Server during Q1 1998 `[ps=0]` — [[study-aberdeen-1997-as400-nt-server-ibm-microsoft-working-together]]
- NT Server 4.0 was delivered on the AS/400 Integrated PC Server as planned in early 1998; IBM fulfilled commitment `[ps=0]` — [[study-aberdeen-1997-as400-nt-server-ibm-microsoft-working-together]]
