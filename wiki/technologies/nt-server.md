# Microsoft Windows NT Server

> NT Server 4.0 released July 1996; growing enterprise adoption but lacked built-in fault tolerance. Superseded by Windows Server 2000/2003/2008 line.


## Top observations

- Ever-increasing trend toward NT Server for enterprise applications including transaction processing, email, groupware, internet/intranet, network management — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- NT Server was never designed to run mission-critical applications without failing; no general purpose OS makes that claim — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- As more enterprise application 'jewels' hosted on NT servers, risk of significant business disruption rises exponentially as servers 'deployed like popcorn' — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- OLTP, system management, firewall applications in critical category; also many e-mail, file serving, groupware applications — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- No true fault-tolerant solution existed in NT cluster market at time of study; only Wolfpack (not yet shipped) or cluster middleware requiring special app versions — [[study-1997-marathon's-endurance-4000--imp-psk-f83368]]
- If BackOffice requires 2 more full-time IS staff than comparable AS/400 system, hundreds of thousands in additional cost over 5-year lifecycle — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Compaq ProLiant 4500 NT Server TPC-C showed good midrange OLTP performance but TPC-C V3 excluded end-user device costs — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Two DEC AlphaServer NT Server TPC-C tests showed excellent price/performance vs Unix; but required Unix front-end processors to multiplex data entry — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
- Best suited for enterprises with strong Unix/client-server expert IS organizations; not for AS/400-dedicated organizations — [[study-aberdeen-1996-ibm-as400-vs-microsoft-nt-server]]
