# Windows NT Wolfpack Clustering

> Codename Wolfpack; shipped as MSCS in Windows NT 4.0 Enterprise Edition 1997; evolved to Windows Server Failover Clustering


## Top observations

- Digital has clustering core expertise since VAX clusters (1980s); early NT cluster leader; high-availability clusters already at market debut `[ps=3]` — [[study-aberdeen-1996-digital-debunks-ntsmp-scalability-myth]]
- More than 100,000 NT high-availability/performance clusters deployed by year-end 1999; NT performance clusters exceed 20,000 tpmC by early 1999 `[ps=3]` — [[study-aberdeen-1996-digital-debunks-ntsmp-scalability-myth]]
- Microsoft Cluster Service (MSCS) shipped in Windows NT 4.0 Enterprise Edition 1997; Windows 2000 Advanced Server extended to 4-node clusters; HA clustering widely adopted by 1999 though performance clustering adoption was slower than 100,000 unit projection `[ps=3]` — [[study-aberdeen-1996-digital-debunks-ntsmp-scalability-myth]]
