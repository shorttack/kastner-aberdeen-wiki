# Online Analytical Processing (OLAP)

> Cited as best suited for client/server not browser model; confirmed — complex OLAP stayed thick-client until modern SaaS BI.


## Top observations

- Most financial management suppliers allied with decision-support/OLAP tools developers; delivered loosely integrated systems requiring manual synchronization and multiple maintenance routines — [[study-aberdeen-1996-khalix-financial-awareness-competitive-advantage]]
- $859 million; CAGR 39% to $2.307B by 2003 — [[study-data-know-69ab04]]
- Three areas: reduced maintenance/installation; cost avoidance (no fat-client); desktop platform independence — [[study-pilot-internet-publisher-51e601]]
- Microsoft OLAP Services (1999) and later SQL Server Analysis Services became dominant web-OLAP platform; Pilot's web-OLAP approach was commercially validated but market consolidated to Microsoft/Oracle/IBM — [[study-pilot-internet-publisher-51e601]]
- Adding new user requires only browser and network access — not fat-client software installation — enabling large-population deployment cost-justification — [[study-pilot-internet-publisher-51e601]]
