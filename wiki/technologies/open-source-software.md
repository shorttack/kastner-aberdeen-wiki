# Open Source Software (enterprise adoption)

> Kastner predicted early 2000s that open source would move from internet infrastructure into enterprise applications and middleware; adoption played out exactly as predicted across 2000-2006, though taking the full decade rather than projected 2-3 years.


## Top observations

- more than half (>50%) — [[study-2002-open-source-and-linux-2002-poster-children-for-sec-587674]]
- major source of elevated security vulnerabilities — [[study-2002-open-source-and-linux-2002-poster-children-for-sec-587674]]
- from Microsoft to open source/Linux — [[study-2002-open-source-and-linux-2002-poster-children-for-sec-587674]]
- open source will remain major security concern for IT buyers — [[study-2002-open-source-and-linux-2002-poster-children-for-sec-587674]]
- CERT advisory count methodology widely criticized; active disclosure seen as sign of health not weakness — [[study-2002-open-source-and-linux-2002-poster-children-for-sec-587674]]
- Predicted early 2000s that open source would move from internet infrastructure (Linux, Apache, MySQL) into enterprise applications and middleware. — [[study-volume-1-ch08-aberdeen-go-go-years-1998-2006]]
- No license fees, transparent code for security audit, community-driven innovation were compelling economic advantages for enterprise open source adoption. — [[study-volume-1-ch08-aberdeen-go-go-years-1998-2006]]
- Resistance to open source was less from technical concerns than from procurement processes; enterprise IT accustomed to paying vendors for software and bundled support contracts. — [[study-volume-1-ch08-aberdeen-go-go-years-1998-2006]]
- JBoss, MySQL, PostgreSQL, and eventually full LAMP stacks penetrated enterprise infrastructure across 2000-2006 — [[study-volume-1-ch08-aberdeen-go-go-years-1998-2006]]
