# Oracle Designer 2000

> Oracle CASE/modeling tool; Aberdeen rated weakest of the three in business process modeling; succeeded by Oracle Developer Suite


## Top observations

- Oracle Designer/2000 and Developer/2000 failed to become dominant Internet development tools; Java/J2EE, open source frameworks (Struts, Spring), and later .NET and JavaScript frameworks displaced Oracle's proprietary toolchain by mid-2000s; Oracle Designer reached end of life 2018 `[ps=5]` — [[study-1997-oracle-designer-2000-3201a7]]
- Market shifted from upper-CASE methodology tools to second-generation CADEs over prior 2 years `[ps=4]` — [[study-1997-oracle-designer-2000-3201a7]]
- Design-tool scalability, flexibility, methodology support, data/code/GUI-driven design `[ps=4]` — [[study-1997-oracle-designer-2000-3201a7]]
- Positioned as Oracle's key product for design and modeling of complex enterprise-scale distributed production systems `[ps=3]` — [[study-1997-oracle-designer-2000-3201a7]]
- Designer/2000 includes WebServer generator for rapid deployment of transactional Internet/Intranet applications without rewriting code `[ps=3]` — [[study-1997-oracle-designer-2000-3201a7]]
- VPE/GUI support, business modeling, application partitioning, integrated repository, BPR capabilities `[ps=3]` — [[study-1997-oracle-designer-2000-3201a7]]
- Integration with data dictionaries, forward generation, reverse engineering, application-management information flow `[ps=3]` — [[study-1997-oracle-designer-2000-3201a7]]
- Aberdeen recommends IS place Designer/2000 on short lists for both traditional CASE and Internet application development `[ps=3]` — [[study-1997-oracle-designer-2000-3201a7]]
- Designer/2000 + Developer/2000 + Web Cartridge will be the winning long-term Internet development toolset `[ps=1]` — [[study-1997-oracle-designer-2000-3201a7]]
- Designer/2000 bundled with 60% of Oracle Developer/2000 sales `[ps=0]` — [[study-1997-oracle-designer-2000-3201a7]]
- Designer/2000 comprises: Process Modeller, Systems Modeller, Systems Designer, Systems Generators, Model Management `[ps=0]` — [[study-1997-oracle-designer-2000-3201a7]]
- Designer/2000 supports Chinese, Korean, Thai, Japanese from single code base `[ps=0]` — [[study-1997-oracle-designer-2000-3201a7]]
- Least robust of the three; processes embedded in applications; intensive capture effort underway; graphical representation available for CPG `[ps=0]` — [[study-1997-vertical-industry-solutions-baan-leads-in-innovati-f12724]]
