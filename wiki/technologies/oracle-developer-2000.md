# Oracle Developer/2000

> Client-server application development tool; tight QACenter integration cited as future requirement


## Top observations

- Widest range of scalable application development capabilities among CADEs; targets medium-to-large data-intensive mission-critical client/server — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Developer/2000 enables application deployment with Java interfaces over World Wide Web — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Advanced 4GL including Forms/Graphics/GUIs, Reports, procedure building, connectivity tools, and server-based development tools — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Developer/2000 encompasses transaction processing, decision support, and multi-platform connectivity — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Oracle Forms provides forms generation with PL/SQL support; runs on Windows, Unix, and Web via Java — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Best suited for medium-scale to high-end data-intensive and mission-critical applications; effective down to workgroup level — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Developer/2000 with Web Cartridge and Java interfaces will position Oracle as leading Internet application development platform — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Oracle Developer/2000 (Forms/Reports) maintained large installed base but failed to win new Internet development projects; Java/J2EE, .NET, and PHP dominated web development by 2005; Forms extended support ended 2023 — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Aberdeen recommends Developer/2000 for medium-to-large data-intensive mission-critical applications; notes effective down to workgroup level — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Developer/2000 front-end runs on Windows 95/NT/3.x; server side on Unix and major platforms — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Developer/2000 is a refinement of Oracle's second-generation Cooperative Development Environment (CDE 2) — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Legacy client-server apps written in Developer/2000 can be translated to Internet with little effort — [[study-aberdeen-1996-oracle-network-computing-architecture]]
- Allows automatic software deployment across Internet; legacy apps translatable to Internet — [[study-aberdeen-1996-oracle-network-computing-architecture]]
