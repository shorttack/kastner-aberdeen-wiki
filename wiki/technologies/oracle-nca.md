# Oracle Network Computing Architecture (NCA)

> Ellison's vision of thin-client NC replacing PC; Java cartridge model; partially right on Java; NC hardware failed


## Top observations

- Oracle Network Computing Architecture uses cartridges for client/app server/database tiers to enable Internet deployment — [[study-1997-oracle-designer-2000-3201a7]]
- Developer/2000 is the CADE component of Oracle's Network Computing Architecture; uses cartridge approach for Internet deployment — [[study-1997-oracle-developer-2000-client-server-development-en-5f98ce]]
- Oracle NCA incorporates major standards including Java and CORBA with open interfaces — [[study-1997-oracle8-the-database-for-network-computing-674c9d]]
- ~35 observations 1996–2001 on Network Computing Architecture — [[study-2026-kastner-oracle-longitudinal]]
- Oracle NCA positioned Java as the universal application delivery runtime replacing Windows PC as client standard — [[study-2026-kastner-oracle-longitudinal]]
- Java as universal enterprise application runtime — NCA's core thesis — was substantially verified by 2000 — [[study-2026-kastner-oracle-longitudinal]]
- Oracle NCA defined a three-tier architecture: Oracle Web Application Server (app tier) + Oracle8 (data tier) + NC/browser (client tier) — [[study-2026-kastner-oracle-longitudinal]]
- Integrate multi-tier client-server + Internet + distributed-object via unified cartridge model — [[study-aberdeen-1996-oracle-network-computing-architecture]]
- Not a marketecture; straightforward extension of proven Oracle products — [[study-aberdeen-1996-oracle-network-computing-architecture]]
- Deploy on client platforms supporting Windows and Internet environments — [[study-aberdeen-1996-oracle-network-computing-architecture]]
- Enterprise-scale web-enabled application components; bypass CGI bottlenecks — [[study-aberdeen-1996-oracle-network-computing-architecture]]
- Database-level cartridges with direct access to Universal Server stored procedures and query optimizer — [[study-aberdeen-1996-oracle-network-computing-architecture]]

- Release of cartridges customized for business functions (finance) and vertical industries expected — [[study-aberdeen-1996-oracle-network-computing-architecture]]
- NCA succeeded in establishing Oracle as enterprise internet platform; Oracle grew to dominant position — [[study-aberdeen-1996-oracle-network-computing-architecture]]
- Relatively low risk: builds on proven Oracle products; wrapping legacy apps as cartridges — [[study-aberdeen-1996-oracle-network-computing-architecture]]
