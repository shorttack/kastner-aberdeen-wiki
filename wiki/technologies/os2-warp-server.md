# IBM OS/2 Warp Server

> NT Server competitor; IBM continued development after Microsoft exit; lost NOS market battle.


## Top observations

- OS/2 Warp Server integrates file/print/database/application server capabilities in single package; at least 1 year ahead of NetWare 4.x and NT Server 3.5x — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Lacking SMP at launch; free SMP upgrade entering beta; will allow adding CPUs instead of servers — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Beta users pleased with basic product; very enthusiastic about included utilities — [[study-aberdeen-1996-ibm-os2-warp-server]]
- IBM's plans for OS/2 Warp Server will be successful in 1996; market position will improve — [[study-aberdeen-1996-ibm-os2-warp-server]]
- IBM discontinued OS/2 support December 31, 2006; never achieved mainstream enterprise NOS adoption; lost to Windows NT — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Novell NetWare still market share leader; NT Server gaining in database/application server market; OS/2 Warp positioned as third choice — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Preemptive multitasking allows priority management and eliminates three-finger salute reboot; multithreading provides no-cost performance boost — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Integrated SystemView for OS/2 and NetFinity management; includes software inventory, asset management, performance monitoring, software distribution, and systems alert — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Includes TCP/IP, SLIP, PPP and remote LAN access for Internet server platform capability — [[study-aberdeen-1996-ibm-os2-warp-server]]
- IBM will put considerable marketing muscle behind OS/2 Warp Server products — [[study-aberdeen-1996-ibm-os2-warp-server]]
- IBM investment in OS/2 marketing was inadequate; internal IBM sabotage and budget cuts decimated OS/2 marketing; product withdrawn from mass market by 2001 — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Executives in non-IBM shops looking for NOS for workgroups/departments well advised to include OS/2 Warp Server on short list for 1996 — [[study-aberdeen-1996-ibm-os2-warp-server]]
- Is IBM going to abandon OS/2 Warp Server? — [[study-mockup~1-ca8fde]]
- IBM not anticipating significant market share gains; maintaining installed base; $30B IBM revenue relies on OS/2 — [[study-nospra~1-bd7d6a]]
- OS/2 Warp Server excellent for file/print; exceeds NT Server functionality even with NT extra-cost utilities — [[study-nospra~1-bd7d6a]]
