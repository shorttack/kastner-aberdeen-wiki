# Parallel-Scalable Server Hardware (SMP/MPP)

> NCR Worldmark, Tandem, etc; required for enterprise warehouse; direct precursor to cloud data warehouse compute clusters


## Top observations

- Web DSS demands: scalability (incremental CPUs/RAID), high availability (online backup/redundancy), RDBMS parallelization, systems/network management; same as traditional warehouse but at higher scale `[ps=5]` — [[study-aberdeen-1996-web-warehouses-dss-for-masses]]
- Web reapportions warehouse costs: savings on desktop software/deployment redirected to server hardware, RDBMS, and data preparation — exactly where investment belongs `[ps=4]` — [[study-aberdeen-1996-web-warehouses-dss-for-masses]]
- Traditional warehouse cost barriers: warehouse design + desktop software + hardware + connectivity + dedicated lines to suppliers/offices + replication costs as system grows — [[study-aberdeen-1996-web-warehouses-dss-for-masses]]
- Enterprise Web warehouse strategy: start small SMP, scale within SMP range if appropriate, or grow to MPP — same architecture at different scale without recompilation — [[study-aberdeen-1996-web-warehouses-dss-for-masses]]
