# SaaS (Software as a Service)

> Not named directly but the per-processor licensing crisis Kastner identified directly foreshadowed the SaaS subscription model shift.


## Top observations

- Software licensing shifted from per-processor to subscription/SaaS driven partly by server consolidation via virtualization; VMware's virtual CPU model further disrupted per-processor licensing `[ps=5]` — [[study-technology-themes-2003-04]]
- VMware ESX/vSphere drove dramatic server consolidation 2006-2015; server count reduced while capacity grew; per-processor licensing crisis intensified as Kastner predicted `[ps=5]` — [[study-technology-themes-2003-04]]
- SaaS is a genuine technical transition that will encounter organizational inertia and misaligned incentives, same as prior transitions. `[ps=5]` — [[study-volume-1-epilogue-argument-with-reality]]
- 30% annual server technology deflation; today's servers have fewer processors than predecessors creating real problem for per-processor software licenses `[ps=4]` — [[study-technology-themes-2003-04]]
- ~30% annual technology deflation for servers; IT buyers replacing older boxes with more powerful machines at same or lower prices `[ps=4]` — [[study-technology-themes-2003-04]]
- Great ROI only relevant if technology addresses executive's top 3-5 pain points; executive committee demands high-ROI projects implementing in weeks not months `[ps=4]` — [[study-technology-themes-2003-04]]
- Largest firms own dozens of redundant overlapping software pieces; smart CIOs/CFOs rationalizing IT purchases; remote data centers being consolidated `[ps=4]` — [[study-technology-themes-2003-04]]
- Aberdeen final years (2004-2008) saw consumerization of IT and SaaS emergence. `[ps=4]` — [[study-volume-1-appendix-career-timeline]]
