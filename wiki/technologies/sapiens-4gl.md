# Sapiens (4GL application development platform)

> Object-oriented 4GL for IBM mainframes; evolved to multi-platform SaaS insurance suite


## Top observations

- No significant technical concerns; technology is differentiated from competitors — [[study-1992-sapiens-and-metadata-0608b6]]
- Capable of managing multiple heterogeneous databases simultaneously; supports distributed database computing — [[study-1992-sapiens-and-metadata-0608b6]]
- Isolates programmers from IBM systems software enabling easier migration across MVS/VM/VSE — [[study-1992-sapiens-and-metadata-0608b6]]
- Modern — perhaps state-of-the-art — architecture with encapsulated data and message-passing — [[study-1992-sapiens-and-metadata-0608b6]]
- Competitive win in Computerworld application development benchmark versus 3GL and 4GL alternatives — [[study-1992-sapiens-and-metadata-0608b6]]
- Most unique and differentiated area of technology; reduces programming to only 20% positive logic with automatic negative/reversal handling — [[study-1992-sapiens-and-metadata-0608b6]]
- Typically only 20% of application coding is 'positive'; rest is negative/reversal logic handled automatically — [[study-1992-sapiens-and-metadata-0608b6]]
- Published 152-user benchmark; several customers have as many as 450 simultaneous active users — [[study-1992-sapiens-and-metadata-0608b6]]
- 15-30% performance penalty compared to tuned 3GL (COBOL) application — [[study-1992-sapiens-and-metadata-0608b6]]
- Applicable to over 80% of mainframe applications — except where maximum users or minimum response time required — [[study-1992-sapiens-and-metadata-0608b6]]
- DB1 DBMS bundled with product but buyers free to use their own databases; DBMS on VSAM adequate for mainframe needs — [[study-1992-sapiens-and-metadata-0608b6]]
