# SOA Lite

> Kastner-coined term. Defined as building composite applications using web services and lightweight SOA tools WITHOUT enterprise middleware (ESB, repository, management, governance, lifecycle tools). Half of survey participants using this approach. Kastner critiques as not standing test of time for enterprise applications.


## Top observations

- SOA Lite projects may not sustain common IT failures or follow company or mandated policies due to absence of ESB, repository, management, governance, and lifecycle tools `[ps=3]` — [[study-ma-ibm-webify-5e0d4b]]
- ~50% of survey participants building SOA applications using web services and lightweight SOA tools (SOA Lite) `[ps=0]` — [[study-ma-ibm-webify-5e0d4b]]
