# Solaris 2.5

> Fine-tuned SMP: 3-8% CPU overhead vs 15-30% for NT; threaded I/O and networking; SMP scalability 92-97% efficiency; succeeded by Solaris 2.6, 7, 8...


## Top observations

- 92-97% SMP scalability (depending on RDBMS) as CPUs added; only 3-8% overhead per added CPU vs 15-20% for typical Unix SMP and up to 30% for NT Server — [[study-aberdeen-1996-sun-microsystems-decision-warehouse]]
- Solaris 2.5 fine-tuned for multiprocessor; threaded I/O and networking; constant query response time as dataset and user count grow; 3-8% CPU overhead (vs up to 30% for NT) — [[study-aberdeen-1996-sun-microsystems-decision-warehouse]]
