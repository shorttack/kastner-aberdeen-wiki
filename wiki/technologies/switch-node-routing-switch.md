# Bay Networks Switch Node Routing Switch

> Announced March 3, 1997. Layer 3 switching with dual 1.2 Gbps buses, IP AutoLearn, 5-slot chassis; wire-speed IP/IPX routing. Discontinued after Bay's acquisition by Nortel.


## Top observations

- March 3, 1997 — [[study-1997-bay-networks--switch-node-routing-s-4d9885]]
- Data plane (forwarding) and control plane (topology) run on separate 1.2 Gbps buses — [[study-1997-bay-networks--switch-node-routing-s-4d9885]]
- Micro-second latency with wire speed switching performance — [[study-1997-bay-networks--switch-node-routing-s-4d9885]]
- Easy integration into existing networks with minimal configuration requirements — [[study-1997-bay-networks--switch-node-routing-s-4d9885]]
- Capability to deliver scalable performance from subnet to subnet — [[study-1997-bay-networks--switch-node-routing-s-4d9885]]
