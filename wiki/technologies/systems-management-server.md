# Microsoft Systems Management Server (SMS)

> Microsoft desktop/server inventory, software distribution, and remote-control tool; renamed System Center Configuration Manager 2007; later Microsoft Intune cloud


## Top observations

- Microsoft had begun final testing of Systems Management Server 2.0 as of Aug 1998 — a significant upgrade intended to deliver software distribution, inventory, and remote-control capabilities tied to the Zero Admin vision. — [[study-systems-management-delayed-promise-1bc587]]
- Microsoft Systems Management Server was renamed System Center Configuration Manager (SCCM) with the 2007 release; later co-evolved with Microsoft Intune cloud MDM; rebranded Microsoft Endpoint Configuration Manager (2019) and Microsoft Intune (2022) in the Endpoint Manager family. — [[study-systems-management-delayed-promise-1bc587]]
