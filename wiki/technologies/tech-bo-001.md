# BusinessObjects 4.0

> Complete re-architecture of BusinessObjects; integrated Reporter, Explorer, Document Agent Server, Designer, Supervisor modules; foundation for subsequent releases; became SAP BusinessObjects after 2008


## Top observations

- BusinessObjects 4.0 development required approximately 150 person-years and $15 million investment — [[study-1997-dev-expanding-universes-for-busines-c42c71]]
- BusinessObjects 4.0 Reporter (query and reporting): $595; Explorer (OLAP): $695; Designer module: $1,995; Supervisor module: $1,995; Document Agent Server: $4,995 — [[study-1997-dev-expanding-universes-for-busines-c42c71]]
- SAP designated BusinessObjects 4.0 as the sole decision-support tool provider in the SAP Complementary Software Partner Program — a highly privileged and exclusive designation — [[study-1997-dev-expanding-universes-for-busines-c42c71]]
- Business Objects holds privileged position in Microsoft Alliance for Data Warehousing — [[study-1997-dev-expanding-universes-for-busines-c42c71]]
- Large user with 5,000-copy rollout plans concluded that combination of strong technology and maturity would translate into a sustainable platform for competitive advantage — [[study-1997-dev-expanding-universes-for-busines-c42c71]]
- Business Objects executives report over 90% code reuse from BusinessObjects 4.0 in Project Darwin development — [[study-1997-dev-expanding-universes-for-busines-c42c71]]
- Enterprise users report helpdesk support as comparatively lackluster during 4.0 beta but improved; one user with 3,000 licenses claims helpdesk is weak link; another says Web interface improved support — [[study-1997-dev-expanding-universes-for-busines-c42c71]]
