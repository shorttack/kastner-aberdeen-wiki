# I2O (Intelligent I/O) Architecture

> Specification for OS-independent intelligent I/O subsystem; aimed to separate device-specific and OS-specific driver code


## Top observations

- I2O failed to achieve broad adoption; I2O SIG dissolved; standard abandoned by early 2000s `[ps=5]` — [[study-1997-intelligent-i-o-initiative--scaling-aae222]]
- IA-64 (Itanium) failed to achieve mainstream server adoption; I2O IA-64 relevance never materialized `[ps=5]` — [[study-1997-intelligent-i-o-initiative--scaling-aae222]]
- I2O will be an important functional capability for servers in the near future `[ps=1]` — [[study-1997-intelligent-i-o-initiative--scaling-aae222]]
- I2O is the key enabler for I/O on IA-64 platforms; develop drivers now for IA-64 compatibility `[ps=1]` — [[study-1997-intelligent-i-o-initiative--scaling-aae222]]
- Leading Intel server suppliers now shipping I2O-Ready products `[ps=0]` — [[study-1997-intelligent-i-o-initiative--scaling-aae222]]
