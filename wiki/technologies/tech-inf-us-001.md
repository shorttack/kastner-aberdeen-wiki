# Informix Universal Server

> Combines Informix-OnLine with Illustra DataBlade object-relational extensions. Evolved into IBM Informix IDS.


## Top observations

- Informix Universal Server combines RDBMS with object-relational DataBlade extensions `[ps=0]` — [[study-1997-migrating-from-sybase-sql-server-4.-d7b1d0]]
- 25 DataBlade modules available — [[study-1997-migrating-from-sybase-sql-server-4.-d7b1d0]]
- Phil White (CEO): 'Informix redefines database performance, extending it into new dimensions' — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Shipped to 20-30 customers Sept 30 1996; general availability today (Dec 1996); 'twelve to eighteen months ahead of anybody in the industry' — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Colton + Simmons: Universal Server completes telecom billing-discount query in 6 sec vs ~60 sec on middleware (~10x faster, 'not even using CORBA') — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Universal Server claimed 10x to 1000x faster than equivalent middleware approaches across workloads — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Colton: middleware approach to ORDBMS is 'like playing chess by US mail' -- multiple round trips between app and DB — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Universal Server in production in 1500+ applications at Dec 1996 launch — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- End of December 1996: GA on Sun and SGI; mid-1997: Windows NT and other Unix — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Chobnick (GE VP): GE Information Services builds e-commerce, photo finder app, and financial-transaction capture on Universal Server — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Brewer (CitySearch VP Tech): www.citysearch.com built on text + 2D + custom temporal DataBlades for local city info — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Nied (CAA New Media): Independence Day, 101 Dalmatians, ER, 90210; Planet Hollywood Online JV (Informix + Tandem + Planet Hollywood) -- 20M visitors/yr; Intel media lab Beverly Hills Dec 12 — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Kinneken (Dir Server Product Mgmt): Horizon Insurance demo uses web + text + 2D spatial DataBlades to drive insurance underwriting — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Simmons + Itzkowitz: built DB Expo intranet app in 72 hours -- spatial, image, text, audio DataBlades + dynamic maps + Java integration — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
- Stonebraker: types (spatial, text, time-series) belong INSIDE the database engine, not in middleware -- query optimizer must see them — [[study-informix-universal-server-launch-object-relational-fb2cd4]]
