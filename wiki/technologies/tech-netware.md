# Novell NetWare

> NetWare 3.x/4.x held 70%+ LAN OS share in 1990; displaced by Windows NT/2000 Server by ~2000. EOL NetWare 6.5 in 2015.


## Top observations

- IT managers standardizing on Windows NT Workstation as desktop; expect NT Server to replace NetWare file/print — [[study-aberdeen-1995-novell-predicament]]
- 3 principal failures: annual tactic changes, technical execution failures, ISV attrition — [[study-aberdeen-1995-novell-predicament]]
- further erosion of Novell enterprise position projected — [[study-aberdeen-1995-novell-predicament]]
- acquired by Attachmate Group for $2.2B in April 2011; 882 patents sold to Microsoft consortium for $450M — [[study-aberdeen-1995-novell-predicament]]
- SMP, distributed print, systems management, improved IP support — [[study-aberdeen-1995-novell-predicament]]
- Portable NetWare, AppWare, Tuxedo acquisition, UnixWare, WordPerfect—all failed — [[study-aberdeen-1995-novell-predicament]]
- Volume 9/Number 14, August 9, 1995 — [[study-aberdeen-1995-novell-predicament]]
- few ISVs actively porting applications to NetWare; ISVs look elsewhere — [[study-aberdeen-1995-novell-predicament]]
- revenue declines confirmed; Aberdeen analysis confirms declining trend — [[study-aberdeen-1995-novell-predicament]]
- IT executives advised to carefully evaluate NetWare use for medium and long term — [[study-aberdeen-1995-novell-predicament]]
- enviable marketshare, strong worldwide service/support, established indirect channel, fast file/print servers — [[study-aberdeen-1995-novell-predicament]]
- Attachmate (2011) acquired by Micro Focus (2014) acquired by OpenText (2023) — [[study-aberdeen-1995-novell-predicament]]
