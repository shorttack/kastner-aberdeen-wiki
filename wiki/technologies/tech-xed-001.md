# Access Point (Xedia)

> Xedia's managed broadband access device; combines high-speed IP routing with Class Based Queuing bandwidth management; first release supports Frame Relay; 50% below cost of competing connectivity-only solutions


## Top observations

- Xedia Access Point currently at 50% below cost of connectivity-only based solutions currently on the market — [[study-1997-managing-corporate-internet-access--ae26d9]]
- Web browser with Java presentation for management; ability to monitor usage of traffic classes and bandwidth; relevant as RMON probe equivalent for IT managers — [[study-1997-managing-corporate-internet-access--ae26d9]]
- Aberdeen strongly encourages IT administrators building internet into business strategy to seriously consider adding Xedia's Access Point — [[study-1997-managing-corporate-internet-access--ae26d9]]
- Xedia uses RISC-based software architecture delivering flexibility and affordability at 50% below connectivity-only solutions with Frame Relay first then ATM support — [[study-1997-managing-corporate-internet-access--ae26d9]]
- Access Point can be configured at central site and shipped to enterprise site; supports OSPF2 and RIP2; compatible with installed hubs routers switches — [[study-1997-managing-corporate-internet-access--ae26d9]]
- Aberdeen views Class Based Queuing and Xedia's IQ approach as giant step forward in providing quality access and cost savings for internet-centric enterprise networks — [[study-1997-managing-corporate-internet-access--ae26d9]]
