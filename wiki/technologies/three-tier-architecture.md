## Top observations

- Three-tier architecture became the standard for web-based enterprise applications and BI tools by 2000-2005; prediction proved accurate `[ps=5]` — [[study-aberdeen-1996-iq-software-www-reporting]]
- Visual Basic, PowerBuilder, Delphi, SQLWindows; best for departmental/simple/client-centric apps not needing scale `[ps=5]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- 3-tier architecture became the standard enterprise application pattern throughout the late 1990s and 2000s, exactly as Aberdeen predicted; web tier, application server, database tier became ubiquitous `[ps=5]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- Three-tier plus is state-of-the-art (carried into 1992 PSK SNR slides + 1993 MFA deck) `[ps=5]` — [[study-aberdeen-trends-90s-logan-1991-648c68]]
- Decision-support implementations grow 3-5x every 18 months; three-tier architecture required to avoid scalability/performance problems `[ps=4]` — [[study-aberdeen-1996-iq-software-www-reporting]]
- First-gen CADEs provide little application partitioning, query optimization, or load balancing; applications slow drastically as users/database size increase `[ps=4]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- Automate business information flows, improve productivity, add revenue opportunities, cut costs; replace batch mainframe with real-time processes `[ps=4]` — [[study-aberdeen-1996-object-oriented-three-tier-plus-computing]]
- Graceful evolution to new technologies; investment protection; SMP clustering and board-level upgrades increasingly popular `[ps=4]` — [[study-aberdeen-1996-object-oriented-three-tier-plus-computing]]
- Hardware, RDBMS platforms now stable, reliable, well-understood; missing pieces from 1992 (OOP tools, TP performance, data replication, network management) now in production `[ps=4]` — [[study-aberdeen-1996-object-oriented-three-tier-plus-computing]]
- First-gen CADEs provide little software for scaling development process or automating unfamiliar tasks for training; communication problems increase as square of programmer count `[ps=3]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- Absence of automated deployment/maintenance software requires physical installation at each site, local admin burden, repeated redeployment on upgrades `[ps=3]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- First-gen CADEs lack repositories and application-repartitioning GUIs for adapting to 3-tier and Intranet architectures `[ps=3]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- Oracle, Sybase, Informix, CA-Ingres, Progress CADEs; useful for installed RDBMS base for upgrading from 4GL and data-intensive applications `[ps=3]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- We have sufficient evidence for IS executives to proceed with confidence. Technology direction is clearer now. Products are more powerful and less expensive than ever. `[ps=3]` — [[study-aberdeen-1996-object-oriented-three-tier-plus-computing]]
- Forte, Dynasty, Seer Technologies; best for very complex and very data-intensive new applications with multiple suppliers' databases `[ps=2]` — [[study-aberdeen-1996-moving-effectively-next-gen-client-server]]
- Residual value of mainframe software portfolio will continue to decline during second half of 1990s as PCs handle more processing `[ps=2]` — [[study-aberdeen-1996-object-oriented-three-tier-plus-computing]]
- Approximately 25 million business client workstations shipped worldwide in 1995 `[ps=0]` — [[study-aberdeen-1996-object-oriented-three-tier-plus-computing]]
- IQ has had a Unix and NT three-tier architecture since 1995; one year of refinement gives it advantage over would-be competitors — [[study-aberdeen-1996-iq-software-www-reporting]]
- WWW-enabled applications will require sophisticated three-tier architectures; will create a flurry of announcements among suppliers — [[study-aberdeen-1996-iq-software-www-reporting]]
- Senior management consensus: productivity, customer satisfaction, revenue enhancement from effective IS strategy; 3-Tier architecture enables this — [[study-aberdeen-1996-object-oriented-three-tier-plus-computing]]
