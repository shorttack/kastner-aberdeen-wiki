# Tiered Storage

> Pools of storage at different cost/performance tiers managed by ILM policy; now the universal storage architecture.


## Top observations

- Enterprise storage decisions once simple (GB per disk); now complicated by compliance new data types and ILM policy-based tiers — [[study-technology-themes-2003-04]]
- New thinking about pools of storage controlled by ILM policy opening doors to lower-cost storage devices and architectures — [[study-technology-themes-2003-04]]
- Tiered storage became universal; ILM embedded in all major storage platforms (NetApp EMC IBM); cloud tiering (AWS S3 Glacier) extended the model — [[study-technology-themes-2003-04]]
- Storage budgets skyrocketing due to compliance issues data replication for real-time/DSS and PC/project data proliferation — [[study-technology-themes-2003-04]]
- IT buyers realizing not every data byte has same value to enterprise and that value changes over time — core ILM thesis — [[study-technology-themes-2003-04]]
- AWS S3/Glacier Intelligent-Tiering Azure blob tiers Google Nearline extended Kastner's pools-of-storage model to cloud; ILM policies now automated by ML — [[study-technology-themes-2003-04]]
