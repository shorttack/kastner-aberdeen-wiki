# VLM (Very Large Memory) Technology

> 64-bit architecture enabling 5+ GB main memory; Aberdeen defines as >5GB system memory with DB support


## Top observations

- 64-bit VLM (>4GB RAM) enables higher performance for data warehousing and mixed OLTP/DSS Internet applications — [[study-aberdeen-1996-computer-telephony-integration]]
- 10-100x performance improvement for in-memory database operations over non-VLM systems — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
- 32-bit architectures address less than 1GB main memory; 64-bit Alpha increases addressable memory by several orders of magnitude — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
- VLM costs less than adding another system or solid-state disk; boosts topped-out SMP systems — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
- VLM technology extends high-performance database to broader enterprise applications; orders-of-magnitude improvements achievable — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
- In-memory databases (SAP HANA 2011, Redis, Memcached, VoltDB) became mainstream; Aberdeen's directional prediction proved accurate — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
- VLM enables ultra-high-performance OLTP by keeping hot data in main memory — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
- VLM enables effective end-user access to larger databases with complex queries — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
- VLM delivers competitive advantage for ERP including SAP R/3 at medium enterprise scale — [[study-aberdeen-1996-software-ag-digital-high-performance-solutions]]
