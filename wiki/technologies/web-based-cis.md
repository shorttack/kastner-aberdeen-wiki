# Web-Architected CIS Applications

> Shift from client-server to internet-based CIS deployment; Aberdeen dedicates a chapter to this transition; became the dominant architecture by 2002-2005; the web paradigm eventually gave way to SaaS (Salesforce model, 1999+).


## Top observations

- Fundamental shift in how CIS applications are architected and deployed; transition underway — [[study-1997-cis-report-ba825e]]
- Internet represents fundamental shift in how CIS applications are architected; web transition is critical — [[study-1997-cis-report-ba825e]]
- Web became the dominant CIS/CRM delivery architecture by 2001-2003; Salesforce.com (1999) validated fully cloud-based CRM; all major vendors migrated to web/SaaS by 2010 — [[study-1997-cis-report-ba825e]]
- Web-architected CIS represents the future of the market — [[study-1998-cis-report-customer-interaction-software-631068]]
