# Windows NT Server 4.0

> NT platform for which professional services are provided; 5 Ss: scalability/stability/systems mgmt/storage mgmt/security.


## Top observations

- NT Server 4.0 being overused for enterprise-scale implementations it cannot support; NOS use mostly workgroup — [[study-nospra~1-bd7d6a]]
- NT Server has almost non-existent security at Windows desktop level vs. very adequate Unix and IBM/Novell NOS — [[study-nospra~1-bd7d6a]]
- Vast majority of NT Server NOS sales are in workgroup; few network managers seriously consider it as enterprise NOS — [[study-nospra~1-bd7d6a]]
- NT 4.0 compliant with minor issues; requires Service Pack 3 plus Site Server Express 3.0 plus QFE fixes; NT 3.51 must upgrade — [[study-nospra~1-bd7d6a]]
- Microsoft is mindshare leader; leveraging desktop dominance to push NT Server; massive ISV/channel recruitment — [[study-nospra~1-bd7d6a]]
- $3 billion in NT Professional Services on $750 million NT platform revenue ($4 services per $1 platform) — [[study-ntpspr~1-728dc3]]
- Reached almost $20 billion; $12 services per $1 NT platform; driven by move to application servers — [[study-ntpspr~1-728dc3]]
- ~$110 billion by 2001 based on 8x platform cost multiplier; platform revenues growing at astounding rate — [[study-ntpspr~1-728dc3]]
- Verify actual 2001 IT services market size; likely substantially below $110B projection. — [[study-ntpspr~1-728dc3]]
- NT has 5 critical weaknesses: scalability — [[study-ntpspr~1-728dc3]]
- ~$6 billion in hardware revenue; NT application revenues ~$2 billion — [[study-ntserv~1-56bd94]]
- 50% annual growth for next 4 years; hardware market to grow to $9 billion by 2000 — [[study-ntserv~1-56bd94]]
- NT application revenues ~$2B in 1997; will grow to ~$13 billion by 2001 — [[study-ntserv~1-56bd94]]
- Windows NT servers part of strategic plans for more than 90% of Fortune 1000 IS executives — [[study-ntserv~1-56bd94]]
- NT deployments increasingly require professional services; IS without staff NT experience common — [[study-ntserv~1-56bd94]]
- NT Server OS shipments to increase 88% in 1998; over 100% in 1999 — [[study-ntserv~1-56bd94]]
- NT remains less robust/scalable/enterprise-ready than mature Unix platforms; second choice for larger mission-critical apps — [[study-ntserv~1-56bd94]]
- NT essentially supports one application per OS copy; keeps NT servers on periphery of larger database environments — [[study-ntserv~1-56bd94]]
- Misconception that NT/Intel servers are a Y2K safe harbor is false; require software updates at application/OS/hardware levels — [[study-ntserv~1-56bd94]]
