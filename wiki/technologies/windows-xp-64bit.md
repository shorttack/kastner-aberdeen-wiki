# Microsoft Windows XP 64-bit Edition / Windows XP Professional x64 Edition

> Microsoft 64-bit Windows XP; Itanium edition 2001, AMD64/x64 edition 2005; released in beta Feb 2004; limited driver/application support; displaced by Windows Vista/7 x64


## Top observations

- Let's say I have a 64-bit operating system; I have to run all of the applications like Photoshop and even Word in 32-bit. Windows XP 64-bit will not be helpful for customers unless the most popular applications are available. — [[study-technology-news-future-tech-microsoft-la-625f49]]
- Microsoft released the beta 64-bit Windows XP (for AMD64/Opteron/Athlon 64) on CD-ROM and 450MB download Feb 2004; production version expected end of 2004; Itanium version not supported in this AMD64 build. — [[study-technology-news-future-tech-microsoft-la-625f49]]
- Microsoft released Windows XP Professional x64 Edition on April 25 2005 — roughly 14 months after the beta covered here; adoption remained niche through XP's lifetime due to the app-ecosystem gap Kastner diagnosed. — [[study-technology-news-future-tech-microsoft-la-625f49]]
- Apple developers are sure to develop programs quickly to take advantage of 64-bit computing. But for Athlon64, the market is still unknown because Microsoft's 64-bit version of Windows XP has yet to arrive. — [[study-technology-news-hardware-amd-beats-apple-5399ec]]
- Microsoft shipped Windows XP Professional x64 Edition Apr 25 2005 — roughly 18 months after this article, matching Kastner's 'tune in a year from now' call. But mainstream 64-bit consumer adoption waited until Windows 7 (Oct 2009). — [[study-technology-news-hardware-amd-beats-apple-5399ec]]
- Very few consumer desktops can take advantage of 64-bit. Intel has to drop the other shoe and deem that the broad, mass market for consumers is ready for 64-bit. I predict that will not be this year. — [[study-technology-news-hardware-intel-updates-i-a018d7]]
