# Microsoft Wolfpack (Cluster Server)

> Became Windows Server Failover Clustering; original Wolfpack limited to 2 nodes; significantly enhanced in later Windows Server releases


## Top observations

- Microsoft Windows Server 2003 Cluster Service improved to 8 nodes; Windows Server 2008 reached 16 nodes; enterprise-grade WSFC emerged but Tandem's prediction of third-party HA need proved accurate for 1997-2003 period `[ps=5]` — [[study-1997-tandem-s-nonstop-software-enterprise-clustering-fo-815776]]
- Wolfpack Phase 1 limited to 2 nodes; only simple failover model; insufficient enterprise manageability; cannot guarantee around-the-clock uptime; better positioned for workgroup/departmental apps only `[ps=4]` — [[study-1997-tandem-s-nonstop-software-enterprise-clustering-fo-815776]]
- Wolfpack alone will merely better NT Server's position in workgroup/departmental applications; for the foreseeable future Wolfpack alone is no panacea for enterprise `[ps=4]` — [[study-1997-tandem-s-nonstop-software-enterprise-clustering-fo-815776]]
- Enterprises should wait ~2 years before betting on Microsoft-only Wolfpack `[ps=4]` — [[study-leader-of-the-pack-23-nov-1996-computing-f2353f]]
- No single Wolfpack vendor had the whole clustering toolkit at launch; 'all at the starting gate' `[ps=3]` — [[study-leader-of-the-pack-23-nov-1996-computing-f2353f]]
- Microsoft Cluster Server two-node shipped 1997; full 4-node capability only with Windows 2000 Advanced Server (2000) `[ps=3]` — [[study-leader-of-the-pack-23-nov-1996-computing-f2353f]]
- Two factions: Servernet backers (Compaq, Dell, Tandem) vs Microsoft-centric `[ps=2]` — [[study-leader-of-the-pack-23-nov-1996-computing-f2353f]]
