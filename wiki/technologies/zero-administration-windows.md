# Microsoft Zero Administration initiative

> Microsoft's Zero Admin Windows (ZAW) initiative: reduce total cost of PC ownership via IntelliMirror, SMS, Windows Terminals, Terminal Server; core promise was folded into IntelliMirror/Active Directory/Group Policy in Windows 2000


## Top observations

- Full benefits [of Zero Administration] accrue only to companies with homogeneous NT 5.0 environments. Cost savings Microsoft promises will happen very slowly, in an evolutionary fashion, as companies upgrade to NT 5.0. `[ps=5]` — [[study-systems-management-delayed-promise-1bc587]]
- Zero Admin Windows as a branded initiative dissolved, but its substance — Group Policy, IntelliMirror, SMS/SCCM, Remote Desktop — became mainstream only as NT 5.x homogeneity emerged in enterprise desktops 2003-2005, directly validating Kastner's evolutionary-not-revolutionary call. `[ps=4]` — [[study-systems-management-delayed-promise-1bc587]]
